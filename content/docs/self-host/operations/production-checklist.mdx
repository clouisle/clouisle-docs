上线前按本清单逐项确认，全部关键项通过后再开放用户访问。

## 安全

- [ ] 密码策略最短 8 位并要求复杂度，管理员启用双因素。
- [ ] JWT 密钥唯一且足够强；会话超时按策略配置（站点设置 `session_timeout_days` 默认 30 天）。
- [ ] 登录失败 5 次锁定账户，新账户需邮箱验证；API Key 有轮换计划。
- [ ] 全站 HTTPS，有效证书，TLS 1.2 起，启用 HSTS。
- [ ] CORS 只写明确 origin，生产环境不用通配符；限流覆盖全部端点。
- [ ] 防火墙只开必要端口，数据库/Redis/向量库端口不对外暴露。
- [ ] 密钥全部走环境变量或密钥管理器，无硬编码、无默认值，`.env` 不进版本库。
- [ ] 数据库连接加密，敏感数据静态加密，备份加密存储。
- [ ] 安全头（CSP、`X-Frame-Options` 等）、输入校验、CSRF 防护齐备；依赖漏洞已扫描修复。

## 性能与负载测试

- [ ] 数据库慢查询已优化，常用查询有索引，连接池按并发配好。
- [ ] Redis 作缓存，maxmemory 与淘汰策略已设；静态资源走 CDN，开 Gzip/Brotli。
- [ ] Worker 进程数按 CPU 核数配置，队列消费并发已压测。
- [ ] 流式链路超时配好：代理读超时不小于 300 秒，`proxy_buffering off`，Redis `maxclients` 与系统 `nofile` 按峰值 SSE 连接数放大。
- [ ] 已做负载测试与压力测试：p95 小于 500ms，并发用户数达到目标（最小 100，目标 500），瓶颈已消除。
- [ ] 目标值：API p50 小于 100ms、p95 小于 500ms；聊天首 token 小于 2 秒；向量检索小于 500ms；CPU 均值低于 60%，内存均值低于 70%。

## 可靠与备份

- [ ] 后端至少 3 实例，负载均衡配健康检查（`GET /api/v1/health`），无单点。
- [ ] 数据库复制、Redis Sentinel 或集群、Qdrant 集群（如用）已配并演练过自动切换。
- [ ] 每日自动备份，保留 30 天以上，异地加密存放；恢复流程已文档化并实际演练，RTO/RPO 已定义。
- [ ] 重试带指数退避，外部调用有超时与熔断，失败任务有死信队列。

## 监控与告警

- [ ] 集中日志（排除 token 与密码）、日志轮转与保留策略齐备。
- [ ] 关键指标可查：RPS、延迟、错误率、CPU/内存/磁盘、数据库与队列指标。
- [ ] 告警覆盖健康检查失败、认证异常、队列积压、磁盘耗尽、备份失败；值班与升级流程明确。
- [ ] 后端没有 Prometheus `/metrics` 端点，用管理端可观测接口与基础设施监控代替，不要把该项当作内置能力。

<Callout type="info">
Clouisle 使用 Tortoise ORM，后端启动时自动建表与更新结构，没有 Alembic 这类需要手动执行的迁移命令。
</Callout>

## 配置与部署

- [ ] 生产环境变量全部设置，无示例默认值；环境配置分离且启动时校验。
- [ ] LLM Key、邮件、对象存储、CDN、DNS、证书自动续期已配并测通。
- [ ] 镜像已打 tag 推到仓库，CI 测试、安全扫描通过，回滚步骤已文档化并在预发布验证。
- [ ] 预发布环境与生产一致，回滚已在预发布演练。

## 上线当天与首周

- [ ] 上线当天：健康端点、数据库、Redis、外部集成、证书、DNS、流量分发全部正常；冒烟覆盖注册、登录、建 Agent、聊天、上传、工作流、检索。
- [ ] 首周：错误率低于 1%，响应时间达标，无内存泄漏，备份验证完成，容量规划复核。
- [ ] 上线决策人（技术、安全、运维、产品）已签字，回滚预案就绪，值班表生效。
