## 引导式安装

```bash
curl -fsSL https://raw.githubusercontent.com/clouisle/Clouisle/main/deploy/install.sh | bash
```

安装器提供 Docker Compose、Kubernetes Helm 和安全单文件 manifest 选项。Docker 默认目录为 `/opt/clouisle`；升级时保留已有 `.env`。单文件 manifest 默认只生成 `./clouisle-k8s.yaml`，不会自动 `kubectl apply`。
