Clouisle 提供引导式安装器、手动 Docker Compose、Helm、生成单文件 Kubernetes manifest、手动 Kubernetes 模板、源码运行方式和 Sealos 社区模板。


## 总纲

Clouisle 使用 **3 个镜像**运行 **5 个应用服务** + **3 个基础设施服务**：`clouisle-backend`（api、worker、beat）、`clouisle-sandbox-worker`（sandbox-worker）、`clouisle-frontend`（frontend），基础设施为 PostgreSQL、Redis、Qdrant。前端容器直接运行 Next.js standalone（`node server.js`，`:3000`），不含 Nginx；`/api/*` 由 Next.js rewrites 代理到后端；`deploy/nginx/default.conf` 只是可选的外部反代示例。

服务启动命令与副本：api 用 `python main.py server -H 0.0.0.0 -w 4 --no-reload`（1+ 副本）；worker 用 `python main.py worker -c 4 -Q default,agent,knowledge,workflow`（1+ 副本）；sandbox-worker 用 `python main.py sandbox-worker -c ${SANDBOX_WORKER_CONCURRENCY:-1}`（1+ 副本）；beat 用 `python main.py beat`，**必须恰好 1 个副本**，多 beat 会导致定时任务重复执行。

构建全部镜像（项目根目录执行）：

```bash
docker build -f deploy/dockerfiles/backend.Dockerfile -t clouisle-backend:latest .
docker build -f deploy/dockerfiles/sandbox-worker.Dockerfile -t clouisle-sandbox-worker:latest .
docker build -f deploy/dockerfiles/frontend.Dockerfile -t clouisle-frontend:latest .
```

## 引导式安装

```bash
curl -fsSL https://raw.githubusercontent.com/clouisle/Clouisle/main/deploy/install.sh | bash
```

安装器提供 Docker Compose、Kubernetes Helm 和安全单文件 manifest 选项。Docker 默认目录为 `/opt/clouisle`；升级时保留已有 `.env`。单文件 manifest 默认只生成 `./clouisle-k8s.yaml`，不会自动 `kubectl apply`。
