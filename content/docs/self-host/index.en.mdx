A Clouisle deployment consists of the frontend, a FastAPI API, Celery Worker, Sandbox Worker, Beat, and PostgreSQL, Redis, and Qdrant. For a single server, prefer the guided installer and Docker Compose; for production clusters, prefer Helm.

## Support matrix

| Scenario | Recommended approach | Best for |
| --- | --- | --- |
| Single-server trial or small-scale production | Docker Compose | One server, external reverse proxy |
| Scalable production cluster | Helm | Kubernetes, Ingress, shared storage |
| Controlled review deployment | Generated single-file manifest | Reviewing Secrets and resources before `apply` |
| Local development | Backend + frontend source code | Contributing code, debugging the product |

<Callout type="error">
  Production deployments must replace the example `SECRET_KEY`, database passwords, Redis/Qdrant credentials, and the internal Worker gateway Token. Do not expose the API service port directly to the public internet.
</Callout>
