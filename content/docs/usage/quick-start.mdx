Clouisle 是一个多智能体协作平台与工作流引擎，团队是资源边界。完成本页后，你会在团队工作台中打开一个已发布 Agent、发送消息并找到对应会话记录。

<Callout type="info" title="开始之前">
  需要一个可访问的 Clouisle 站点和有效账户。创建 Agent 还需要团队已获授权的 `chat` 模型；普通成员看不到的菜单由角色与权限决定。
  需要自己搭一套站点？按 [Docker Compose 部署](/self-host/deploy/docker-compose) 启动，最低 4GB 内存，浏览器入口为 `http://localhost:3000`。
</Callout>

## 步骤 1：登录并选择团队

1. 打开站点根地址，进入**登录**。
2. 使用用户名或邮箱与密码登录；站点也可能只开放 SSO。
3. 若出现邮箱验证、TOTP、密码过期或管理员审核提示，按页面完成后再继续。
4. 在工作台顶部团队切换器中选择目标团队。Agent、工作流、知识库与模型均按当前团队隔离。

## 步骤 2：确认可用模型

前往**模型**。这里仅显示管理员授权给当前团队的模型，可按供应商、模型类型和状态筛选。至少需要一个启用的**对话**模型才能配置 Agent。

<Callout type="warn">
  如果列表为空，联系团队所有者或管理员在管理后台为团队授权模型。此页只读：任何用户都不能在这里添加模型或填写供应商凭据。
</Callout>

## 步骤 3：打开或创建 Agent

1. 前往**应用**，切换到 **Agent**。
2. 若已有已发布 Agent，在卡片右上角的 **⋯** 菜单中选择**对话**，或打开编排页后点击工具栏的**对话**。
3. 若具备 `agent:create` 权限（管理员与成员角色默认具备），选择**创建应用**，在**选择类型**中选择**智能 Agent**，填写名称后进入编排页。
4. 在**编排**页填写**提示词**；在 **Agent 设置**的**模型配置**中选择模型，然后保存。
5. 发布需要 `agent:publish` 权限。草稿与已发布的区别只在发布状态本身：iframe 嵌入只在已发布时可用；通过 API 调用只需调用方具备该 Agent 的访问权限并携带有效凭据。

## 步骤 4：发送第一条消息

1. 在右侧**调试与预览**输入问题，或点击工具栏 **对话** 在新标签页打开**公开页面**继续完整对话。
2. 输入消息并发送。流式响应可能包含思考过程、知识来源、工具执行与媒体结果；可用 **Agent 设置**里的**隐藏思考过程**和**隐藏工具调用**控制展示。
3. 需要停止时，选择输入区的**停止**按钮。手动停止的轮次会以已停止状态保留，不再继续输出。
4. 在应用侧栏打开**日志**，确认会话与消息、Token 与耗时统计、知识来源。

## 验收

- 当前团队已选中。
- **模型**页至少有一个启用的对话模型。
- Agent 状态为**已发布**，且能返回消息。
- Agent **日志**中能找到刚才的会话。
