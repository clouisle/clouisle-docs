工作流当前编辑器注册了以下节点。节点的精确输入输出字段以编辑器配置和[节点参考](/reference/workflow-nodes)为准。

| 类别 | 节点 |
| --- | --- |
| 开始与输出 | 用户输入、触发器、输出、注释 |
| 模型与应用 | LLM、Agent、媒体生成、问题分类、参数提取 |
| 知识与扩展 | 知识库检索、工具、MCP/自定义能力、子工作流 |
| 逻辑 | 条件分支、迭代、循环及其开始/退出节点 |
| 转换 | 代码执行、模板转换、变量赋值、变量聚合、文件转 URL |

## 选择节点的原则

- 需要对话模型推理时使用 **LLM**；需要复用完整 Agent 行为时使用 **Agent**。
- 需要依据知识库回答时使用**知识库检索**，再把结果映射到 LLM 或输出。
- 需要调用已有 HTTP/MCP/代码能力时使用**工具**，不要在工作流中重复保存凭据。
- 需要处理每个数组项时用**迭代**；需要在条件满足前重复时用**循环**。
- 需要隔离可复用流程时用**子工作流**，配置输入输出映射和失败策略。

## 节点级失败

每个运行节点记录输入、输出、模型、Token、耗时、重试次数、错误类型和错误信息。HTTP、代码、MCP 和媒体节点应配置可接受的超时；对不可重试的副作用接口，避免无条件重复调用。
