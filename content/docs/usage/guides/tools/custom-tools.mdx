自定义工具属于当前团队。创建工具名称只能包含字母、数字和下划线，且必须以字母开头，例如 `lookup_order`。

## HTTP API 工具

1. 在**能力** > **工具**中选择**创建工具** > **HTTP API**。
2. 设置工具名称、显示名称、描述和参数定义。
3. 配置 HTTP 方法（默认 `GET`）、URL、请求头、查询参数、JSON 请求体和响应路径。
4. 在 URL、请求头、查询参数和正文中使用 `{参数名}` 占位符。
5. 超时默认 `30` 秒，范围 `1-300` 秒。
6. 保存后选择**运行测试**，确认结果路径和错误行为。

## 代码工具

代码工具支持 Python 与 JavaScript。Python 包必须使用精确 `package==version`；JavaScript 包必须使用 `package@version`。可配置命令 argv、包源地址、产物和资源限制。

默认资源限制：超时 `30` 秒、磁盘 `1024MB`、标准输出 `256KB`、标准错误 `256KB`。产物路径必须位于 `/workspace`，可标记为可选。

## 凭据与共享

凭据由服务端保存，调用时注入。自定义工具可以共享给其他团队，权限为**只读**或**读取并执行**。内置工具不能删除或共享；共享工具不能由接收团队修改所有者配置。

## 失败处理

HTTP 工具测试失败时检查 URL、TLS、认证、请求体 JSON 和响应路径。代码工具失败时检查固定版本、标准输出上限、磁盘上限、超时和产物路径。
