Clouisle 的工具分三类：**内置工具**（平台注册，无需创建，详见 [内置工具](/usage/guides/tools/built-in)）、**MCP 服务**（连接外部 MCP Server，详见 [MCP 服务](/usage/guides/tools/mcp)）和**自定义工具**（团队创建）。自定义工具属于当前团队，支持 HTTP API、代码和数据库三种类型，可配置参数、测试执行并共享给其他团队。

## 工具类型

在**能力** > **工具**的**创建工具**菜单里可以选择四种入口（MCP 服务单独成页）：

| 类型 | 说明 | 适用场景 |
| --- | --- | --- |
| **HTTP API** | 调用外部 HTTP 接口，支持 GET/POST/PUT/PATCH/DELETE | 查询 CRM、创建工单、调用第三方 API |
| **代码工具** | 在受限沙箱中执行 Python 或 JavaScript 代码 | 数据转换、文本处理、自定义计算 |
| **数据库工具** | 连接外部关系型/缓存数据库，先看表结构再执行**只读**查询 | 让 Agent 基于业务数据回答问题 |

## 命名规则

创建工具名称只能包含字母、数字和下划线，且必须以字母开头，例如 `lookup_order`。名称在团队内唯一。

## 创建 HTTP API 工具

1. 在**能力** > **工具**中选择**创建工具** > **HTTP API**。
2. 设置工具名称、显示名称、描述和分类。
3. 配置 HTTP 方法（默认 `GET`）、URL、请求头、查询参数、JSON 请求体和响应路径。
4. 在 URL、请求头、查询参数和正文中使用 `{参数名}` 占位符。
5. 超时默认 `30` 秒，范围 `1-300` 秒。
6. 保存后选择**运行测试**，确认结果路径和错误行为。

<Callout type="warn" title="URL 必须是静态的">
  自定义 HTTP 工具的 **URL 不允许任何占位符**：只要 URL 中出现 `{参数名}`、`{{参数名}}` 或裸的 `{{` / `}}`，执行时都会被直接拒绝。把变量放到**查询参数**、**请求头**或**请求体模板**里——这三处才支持 `{{参数名}}` 替换。
</Callout>

<Callout type="info">
  URL 还会经过站点安全校验：内网地址默认被拦截，只有通过校验的地址才会实际发起请求。需要访问私网服务时，请联系管理员把目标加入允许列表。
</Callout>

### HTTP 工具配置示例：查询客户信息

```yaml title="CRM Lookup 工具配置"
Name: CRM Lookup
Description: 在 CRM 系统中查询客户信息
Category: Data
Type: Custom

Endpoint Configuration:
  URL: https://api.crm.example.com/customers
  Method: GET
  Authentication: API Key
  API Key Header: X-API-Key
  API Key: crm_...
  Query Parameters:
    customer_id: "{customer_id}"
  Timeout: 30 seconds

Input Parameters:
  - name: customer_id
    type: string
    required: true
    description: 要查询的客户 ID

Response Format:
  type: json
  schema:
    customer_id: string
    name: string
    email: string
    phone: string
    status: string
```

### HTTP 工具配置示例：创建工单（POST）

```yaml title="Create Support Ticket 工具配置"
Name: Create Support Ticket
Description: 在工单系统中创建支持工单
Category: Communication
Type: Custom

Endpoint Configuration:
  URL: https://api.tickets.example.com/tickets
  Method: POST
  Authentication: Bearer Token
  Token: Bearer tk_...
  Content-Type: application/json
  Timeout: 30 seconds

Input Parameters:
  - name: title
    type: string
    required: true
    description: 工单标题

  - name: description
    type: string
    required: true
    description: 工单描述

  - name: priority
    type: enum
    required: false
    default: medium
    options: [low, medium, high, urgent]
    description: 工单优先级

  - name: assignee
    type: string
    required: false
    description: 处理人邮箱

Response Format:
  type: json
  schema:
    ticket_id: string
    status: string
    created_at: string
```

## 创建代码工具

代码工具支持 Python 与 JavaScript，在受限沙箱中执行。Python 包必须使用精确 `package==version`；JavaScript 包必须使用 `package@version`。可配置命令 argv、包源地址、产物和资源限制。

默认资源限制：

| 资源 | 默认值 | 说明 |
| --- | --- | --- |
| 超时 | 30 秒 | 最大执行时间 |
| 磁盘 | 1024MB | 可用磁盘空间 |
| 标准输出 | 256KB | stdout 上限 |
| 标准错误 | 256KB | stderr 上限 |

产物路径必须位于 `/workspace`，可标记为可选。

## 创建数据库工具

数据库工具让 Agent 直接查询外部数据库。连接信息（主机、端口、账号、密码、连接 URL）**对模型保密**——Agent 只看到工具名称和描述，因此描述要写清这个库存了什么、适合回答哪类问题。

1. 在**能力** > **工具**中选择**创建工具** > **数据库工具**。
2. 选择数据库类型：PostgreSQL、MySQL、Redis 或 MongoDB。
3. 填写连接信息，二选一：
   - **字段模式**：主机、端口、数据库名、用户名、密码、SSL。
   - **连接 URL 模式**：直接填连接地址（Redis / MongoDB 常用）；Redis 可再指定逻辑库序号，MongoDB 可指定认证库。
4. 设置**查询超时**（默认 `15` 秒，范围 `1-120` 秒）和**最大返回行数**（默认 `100`，范围 `1-1000`）。
5. 点击**测试连通性**验证配置（同样经过站点安全校验），成功后保存。

### Agent 能做什么

| 数据库类型 | 能力 |
| --- | --- |
| PostgreSQL / MySQL | 先读取表结构（可指定表，或附带样例行），帮模型弄清有哪些表和字段；再执行**只读** SQL 查询 |
| Redis | 扫描键（可指定匹配模式，每批默认 20 个、最多 100 个，最多扫描 100 批）；读取单个键（列表/集合/有序集合最多返回前 50 个元素）；执行只读命令白名单中的命令（如 `GET`、`HGETALL`、`LRANGE`、`ZRANGE`） |
| MongoDB | 列出集合与估算文档数，或推断某个集合的字段结构；按条件查询文档、统计匹配数量，或执行聚合 |

返回条数始终受**最大返回行数**约束，Agent 自己要求的条数只能更小；查询默认返回 50 行，MongoDB 查询与聚合默认返回 20 行。

<Callout type="warn">
  数据库工具只允许只读访问。
  - PostgreSQL / MySQL 的写入语句（`INSERT` / `UPDATE` / `DELETE` / DDL）和危险关键字会被直接拒绝；一次只允许一条语句，SQL 最长 `65536` 字符。
  - Redis 会拦截 `FLUSHALL`、`CONFIG`、`EVAL`、`SCRIPT`、`KEYS` 等危险命令，白名单之外的命令一律拒绝。
  - MongoDB 的聚合不允许把结果写回集合。

  需要写操作时改用 HTTP API 工具或代码工具。
</Callout>

<Callout type="info" title="超时与返回量">
  **查询超时**（默认 `15` 秒，`1-120`）是**单次查询**的等待上限，连接与执行都算在内；**最大返回行数**（默认 `100`，`1-1000`）是任何操作单次返回记录数的硬上限。Redis 扫描另有“每次最多 100 个、最多 100 批”的限制，避免在大库上无限扫描。
</Callout>

<Callout type="error">
  连接信息保存在服务端，不会下发给模型；但请务必使用**只读**数据库账号，并按最小权限授权。测试连通性需要创建工具的权限。
</Callout>

## 编辑与删除工具

### 编辑自定义工具

1. 选择自定义工具
2. 选择**编辑**
3. 修改工具详情、端点配置、参数或响应格式
4. 测试工具
5. 保存更改

### 删除自定义工具

1. 选择自定义工具
2. 选择**删除**
3. 检查影响：正在使用该工具的 Agent 和工作流
4. 确认删除

<Callout type="error" title="删除影响">
  删除自定义工具后，引用该工具的 Agent 和工作流将无法执行该工具。请在删除前确认无依赖。
</Callout>

## 测试工具

### 运行测试

1. 选择工具
2. 选择**测试**按钮
3. 输入测试参数
4. 选择**运行测试**

### 测试结果示例

网页搜索测试：选择引擎（站点默认或某个已启用引擎），填写查询词与结果条数。

```yaml title="Web Search 测试结果"
Tool: Web Search
Test Parameters:
  query: "artificial intelligence"
  num_results: 5
  engine: site default

Status: Success
Response:
  results:
    - title: "Artificial Intelligence - Wikipedia"
      url: "https://en.wikipedia.org/wiki/Artificial_intelligence"

    - title: "What is AI? | IBM"
      url: "https://www.ibm.com/topics/artificial-intelligence"
      content: "Artificial intelligence leverages computers..."
```

<Callout type="info">
  工具测试页会为网页搜索显示引擎下拉，只列出已启用的引擎加站点默认。搜索凭据由站点统一管理，不能在这里填写；引擎未启用或调用失败时会直接显示错误，不会静默回退到其他引擎。
</Callout>

## 凭据与共享

凭据由服务端保存，调用时注入。自定义工具可以共享给其他团队，权限为**只读**或**读取并执行**。

| 权限 | 说明 |
| --- | --- |
| **只读** | 接收团队可查看工具配置，但不能执行 |
| **读取并执行** | 接收团队可查看并执行工具 |

<Callout type="warn" title="共享限制">
  - 内置工具不能删除或共享
  - 共享工具不能由接收团队修改所有者配置
</Callout>

工具列表会显示共享状态与已共享的团队数量。

## 工具状态管理

工具有启用/禁用两种状态：

| 状态 | 说明 |
| --- | --- |
| **启用** | 工具可正常使用，显示在工具选择中 |
| **禁用** | 工具不可使用，对用户隐藏 |

<Callout type="info">
  工具仅有启用/禁用状态，没有“测试中”或“已废弃”状态。在工具列表的菜单中选择**启用**/**禁用**即可切换。
</Callout>

## 失败处理

### HTTP 工具测试失败

检查以下方面：
- URL 是否正确
- TLS 证书是否有效
- 认证凭据是否过期
- 请求体 JSON 格式是否正确
- 响应路径是否匹配实际响应结构

### 代码工具测试失败

检查以下方面：
- 包是否使用固定版本（`package==version`）
- 标准输出是否超过 256KB 上限
- 磁盘使用是否超过 1024MB 上限
- 执行是否超时（默认 30 秒）
- 产物路径是否位于 `/workspace`

## 最佳实践

### 工具配置

**✅ 推荐做法：**
- 启用前先测试工具
- 定期轮换凭据
- 记录工具用途
- 保持工具更新
- 使用错误处理

**❌ 避免做法：**
- 启用未经测试的工具
- 长期使用静态凭据
- 跳过文档记录
- 忽略错误

### 安全

**✅ 推荐做法：**
- 使用安全认证方式
- 定期轮换 API 密钥
- 限制工具访问范围
- 启用审计日志
- 监控异常使用
- 仅使用 HTTPS
- 验证响应数据

**❌ 避免做法：**
- 使用弱认证方式
- 长期使用静态 API 密钥
- 允许无限制访问
- 禁用审计日志
- 忽略可疑活动
- 允许 HTTP 连接
- 盲目信任响应

### 性能

**✅ 推荐做法：**
- 设置合理的超时时间
- 尽可能使用缓存
- 监控响应时间
- 优化工具调用
- 优雅处理错误

**❌ 避免做法：**
- 使用过长超时
- 跳过缓存
- 忽略性能指标
- 进行不必要的调用
- 忽略错误

## 工具命名规范与思考状态展示

Agent 在对话过程中调用工具时，顶部的**思考折叠栏无需展开**即可自动识别并展示当前工具的操作意图。为了让前台展示最自然、直观，建议遵循以下工具命名规范：

### 1. 命名规范与推荐动词前缀

| 操作类型 | 推荐命名动词/词根示例 | 折叠栏外层直观感知效果 |
| :--- | :--- | :--- |
| **数据/信息查询** | `query_`、`fetch_`、`get_`、`search_`、`find_`、`check_`、`查_`、`获取_` | `正在查询：{工具名称}...` |
| **发送与通知** | `send_`、`post_`、`push_`、`notify_`、`mail_`、`发_`、`推送_` | `正在发送：{工具名称}...` |
| **创建与新增** | `create_`、`add_`、`insert_`、`new_`、`build_`、`建_`、`新增_` | `正在创建：{工具名称}...` |
| **外部接口请求** | `api_`、`http_`、`rest_`、`request_`、`接口_`，或参数含 `url`/`endpoint` | `正在请求接口：{工具名称}...` |
| **计算与分析** | `calc_`、`math_`、`count_`、`analyze_`、`计算_`、`统计_` | `正在计算与分析...` |
| **产物收集与导出** | `artifact`、`artifacts`、包含 `生成下载链接` | `正在收集产物...` |
| **文件与文档操作** | `read_`、`write_`、`open_file`、`save_file` | `正在读取/编辑文件...` |

### 2. 展示名称建议

- **优先设置中文展示名称**：创建工具时，若填写了友好的展示名称（如 `查询股票行情`、`发送飞书通知`），前端外层状态栏将直接优先展示该名称（如 `正在查询：查询股票行情...`）。
- **英文标识符自动美化**：若工具仅有标识符（如 `fetch_user_orders` 或 `syncCrmAccount`），系统会自动转换为自然单词组并应用到状态中（如 `正在查询：Fetch User Orders...`）。
- **并发调用智能聚合**：当 Agent 在一轮思考中同时并发执行多个工具时，外层折叠栏会自动聚合为 `正在并行调用 {N} 个工具...`，保持界面整洁。

## 故障排除

### 工具调用失败

1. **检查工具配置：** 验证凭据、端点 URL，测试连通性
2. **检查审计日志：** 查看工具所属团队的审计日志条目
3. **常见错误：**
   - **认证失败：** 凭据无效
   - **超时：** 增加超时时间或检查端点
   - **参数无效：** 检查参数格式
4. **测试工具：** 使用测试面板查看结果

### 响应缓慢

1. 使用工具测试面板测量响应时间
2. 优化：增加超时、减少数据传输、优化端点
3. 检查外部服务状态，确认无中断
