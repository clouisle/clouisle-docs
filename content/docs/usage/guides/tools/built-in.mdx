内置工具由平台注册，不需要创建或删除。在**能力** > **工具**中选择工具即可测试；工具详情会展示参数名、类型、必填、枚举和默认值。内置工具的凭据统一由站点管理员在服务端配置，普通成员和 Agent 都不能写入或覆盖。

<Callout type="info">
  网页搜索是唯一的例外配置入口：它不在团队或 Agent 里保存密钥，而由管理员在站点级统一启用和配置，详见下文「网页搜索（站点托管）」。
</Callout>

## 可选内置工具

以下工具会出现在工具目录中，可直接绑定到 Agent：

| 工具 | 用途 | 使用前提 |
| --- | --- | --- |
| 获取当前时间 | 获取指定时区的当前日期、时间、星期和时间戳，时区默认 `UTC` | 无 |
| 格式化时间 | 按指定格式输出时间戳，缺省使用当前时间，默认格式 `%Y-%m-%d %H:%M:%S` | 无 |
| 数学计算 | 计算数学表达式 | 无 |
| 单位换算 | 在长度、重量、温度等单位之间换算 | 无 |
| 网页搜索 | 检索网页，默认返回 `5` 条、最多 `10` 条；可选择站点默认引擎或某个已启用引擎 | 管理员已在站点启用并配置搜索引擎 |
| 网页抓取 | 抓取网页、提取正文并保存为受保护文档 | 无 |
| 订阅源读取 | 解析 RSS / Atom 订阅源，默认返回 `10` 条、最多 `30` 条 | 无 |
| 文档转换 | 将上传的 PDF / Word / Excel / PPT / 文本文件转换为文本 | 无 |
| 沙箱文件工具 | 在代码沙箱中管理产物、读写文件 | 沙箱运行时可用 |

## 网页搜索（站点托管）

网页搜索的引擎选择和全部凭据都归站点所有，只有一份配置，不按团队或 Agent 拆分。管理员从平台**能力**页的**配置搜索**按钮，或仪表盘**能力** > **工具** > **Web Search** > **配置**进入，不需要先选择团队。

### 可用引擎

| 引擎 | 说明 | 配置前提 |
| --- | --- | --- |
| Tavily | Tavily 搜索服务 | 管理员填写 Tavily API Key |
| 博查（Bocha） | 博查搜索服务 | 管理员填写博查 API Key |
| SearXNG | 管理员自建的 SearXNG 实例 | 实例地址可在实例内开启 JSON 输出 |
| DeepSeek Search | DeepSeek 自带的搜索服务 | 管理员填写 DeepSeek API Key |

管理员逐个启用引擎，并指定一个**默认引擎**。默认引擎必须是已启用的引擎，否则保存会被拒绝。Agent 与工作流里的 `auto` 表示“使用站点默认引擎”，**不会**根据哪把密钥恰好存在来推断。

允许关闭全部引擎作为明确的停机操作；此时网页搜索会直接返回本地化错误，而不是改用其他来源。

<Callout type="warn" title="没有免 Key 引擎，也没有自动回退">
  系统不提供 DuckDuckGo、Bing 等免 Key 搜索，也没有“A 引擎失败自动换 B 引擎”的回退链。引擎未启用、未配置凭据或上游调用失败都会把错误信息返回给 Agent 或工作流，由它们呈现给调用方；不会悄悄换引擎，也不会返回看起来正常的空结果。
</Callout>

### 凭据的写入与轮换

搜索凭据由管理员在站点配置里填写，保存后界面只显示“已配置”，不会回显原文。更新时：

| 你提交的内容 | 效果 |
| --- | --- |
| 不填写 | 保留现有凭据不变 |
| 显式清空 | 清除该引擎的凭据 |
| 填写新值 | 用新值替换（轮换） |

启用某个需要凭据的引擎却没有填写凭据，或把默认引擎指向未启用的引擎，保存时直接报错。旧版本按团队或 Agent 保存的搜索凭据不会继续生效，也不会被自动启用为站点配置。

### Agent 与工作流如何选择引擎

Agent 编排和工作流的网页搜索节点共用一个“仅已启用”的引擎下拉：默认项继承站点默认，其余选项只列出当前已启用的引擎。已有的保存值即使对应引擎后来被禁用也会保留，不会被静默改写；但**执行时会重新校验站点配置**，因此禁用某个引擎也会阻断此前保存的选择。

### SearXNG 实例

在同一个站点配置对话框里填写实例根地址，例如 `https://search.example.com`，或带反向代理前缀的 `https://example.com/searxng/`。服务端会保留该前缀并追加 `/search`，所以：

- 可以包含子路径；末尾 `/` 会被去掉。
- 不能包含 `/search`、查询参数、片段或用户名密码。
- 绝对地址最长 `2048` 字符。

如果实例前有网关鉴权，可以另填一个 Bearer Token；此时地址必须是 HTTPS。未鉴权的实例不需要 Token。已有 Token 时修改实例地址，必须在同一请求里显式替换或清除 Token，否则保存被拒绝，避免把旧 Token 重放到新地址。

实例必须在自身的 `settings.yml` 中开启 JSON 输出：

```yaml
search:
  formats:
    - html
    - json
```

运行行为：每次搜索都把查询提交到实例的 `/search` 并请求 JSON 结果。超时为 `30` 秒；**不跟随重定向**；不重试；不回退到其他引擎。SearXNG 的引擎覆盖面和算子支持取决于实例自身配置，Clouisle 不保证每个查询或 `site:` 算子都可用。私网地址默认被拦截，需要管理员先把目标加入站点允许列表；云元数据地址始终被阻断。

### DeepSeek Search

启用 DeepSeek Search 并填写 API Key 后，Clouisle 直接调用 DeepSeek 自己的搜索服务，不会把搜索伪装成一次对话模型调用。它只取模型可读的长摘要（约 600–800 字，缺失时使用更短的片段），不下载整页正文。搜索按**成功请求**计费，与返回条数无关，并与账号级搜索请求限额共用；这笔费用与聊天模型的 Token 额度相互独立。

### 验证配置

配置保存后，在工具测试页选择网页搜索，选一个引擎（或站点默认）并执行一次真实检索。建议至少覆盖一个中文多词查询（如 `上海天气 今天`）、一个多词技术查询和一个 `site:` 查询，并检查结果相关性而不只是“有返回”。如果实例返回 403，通常是实例未开启 JSON 输出，或网关拒绝了访问。

## 网页抓取

网页抓取只接受一个网址参数：HTTP(S) 页面、`data:` 地址，或当前会话/工作流运行范围内受保护的附件地址。

- 本地文件路径和其他协议（如 `file://`、`ftp://`）一律拒绝；不会去读服务器本地文件。
- HTML 页面先抽取正文并转为 Markdown：保留链接与表格、不内嵌图片，同时取出页面标题；抽取结果为空时回退到文档解析器。
- 完整正文会保存为当前执行范围内的受保护文档，界面与模型只先拿到有界预览和引用；需要更多内容时可以继续读取到结尾，或按关键词定位，不会静默截断。
- 单页抽取文本过大时直接返回错误，而不是截断后继续。

## 订阅源

订阅源读取解析 RSS / Atom 并返回结构化文章列表：默认 `10` 条、上限 `30` 条，请求超时 `20` 秒并跟随重定向。每篇文章的标题必然返回；链接、发布时间、作者和摘要只在源里存在时才出现——空字段直接省略，不会用空字符串占位。摘要会先剥离 HTML 标签、反转义实体并合并多余空白。

## 由能力开关注入的工具

以下工具**不会**出现在工具目录里，也无法手动绑定——它们由 Agent 上的独立能力开关自动注入：

| 能力 | 注入的工具行为 |
| --- | --- |
| **用户输入** | 向用户发起交互式提问表单，等待用户作答后继续 |
| **生图** | 调用已授权的图片模型生成图片 |
| **生视频** | 调用已授权的视频模型生成视频 |

### 记忆工具

启用 Agent 记忆后，模型会自动获得记忆相关的能力：检索相关记忆、沿关系读取关联实体，并在“自动提取记忆”开启时写入新的实体与关系。关闭自动提取后只保留读取能力，不会新增记忆。具体行为与配置见[记忆与上下文](/usage/guides/agent/memory)。
