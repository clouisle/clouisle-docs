内置工具由平台注册，不需要创建或删除。部分工具需要站点级或团队级配置。

| 工具标识 | 用途 | 额外配置 |
| --- | --- | --- |
| `get_current_time` | 获取当前时间 | 无 |
| `format_datetime` | 格式化日期时间 | 无 |
| `calculate` | 数学计算 | 无 |
| `unit_convert` | 单位转换 | 无 |
| `web_search` | 网页搜索 | `TAVILY_API_KEY` |
| `fetch_webpage` | 抓取网页 | 无 |
| `markitdown` | 文件/文档转换 | 无 |
| `generate_image` | 图片生成 | 图片模型 |
| `generate_video` | 视频生成 | 视频模型 |
| `artifact` / `bash` / `edit` / `read` / `write` | 沙箱产物与文件操作 | 沙箱运行时 |

### 记忆工具


启用 Agent 记忆后，模型可以读取用户记忆图，并在允许时写入记忆。关闭自动提取时，读取工具仍然可用；写入工具受 Agent 记忆配置控制。

| 工具 | 用途 | 限制 |
| --- | --- | --- |
| `search_memory` | 查找相关记忆实体 | `top_k` 限制在 `1-10`，支持时间窗口和实体类型 |
| `get_memory_subgraph` | 读取关联实体和关系 | 最多 5 个种子，深度 `1-3`，方向 `incoming`、`outgoing` 或 `both` |

先用 `search_memory` 找候选实体；只有回答依赖关系时再调用 `get_memory_subgraph`。


在**能力** > **工具**中选择内置工具进行测试。需要配置的工具会显示“需要配置”，选择**配置**填写团队凭据。工具详情会显示参数名、类型、必填、枚举和默认值。
