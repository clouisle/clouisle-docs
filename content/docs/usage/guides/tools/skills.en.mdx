Skills are reusable instructions, resources, and execution conventions. The platform provides the **Capabilities** > **Skills** page; administrators can also review and manage imported packages in the admin panel.

## Import a Skill Package

1. On the **Capabilities** page, select the **Skills** tab.
2. Select **Import** and upload or choose a Clouisle package.
3. Review the package's name, version, description, resources, and dependencies.
4. After importing, enable the Skill for the current team.
5. Bind the Skill you need in the Agent's **Tools** selector, or use it in a Workflow node.

## Lifecycle

Importing, enabling, disabling, and deleting are separate operations. Disabling does not delete historical references; before deleting, confirm that no published Agent or Workflow depends on it. Skill versions should be recorded together with the package content, and production changes should be validated in a draft app first.

## Troubleshooting

Import fails when the package format is invalid, resources are missing, dependencies are unsatisfied, or permissions are insufficient. Keep the error message returned by the server and the package version so administrators can diagnose the issue.
