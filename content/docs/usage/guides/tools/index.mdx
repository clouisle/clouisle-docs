工具让 Agent 和工作流执行文本生成之外的动作：查时间、算数、搜索网页、调用外部 API、查询数据库或在沙箱里跑代码。按来源分为内置工具（平台注册，网页搜索由站点管理员统一配置）、团队自定义工具（HTTP、代码、数据库）、MCP 服务与 Skill 包。工具定义之外，还需要**连接**决定以谁的账号执行，以及**审批**决定是否需要调用者确认。

## 常见使用场景

- **日常小工具**：查时间、做单位换算、算表达式，不需要任何配置。
- **查业务数据**：用数据库工具以只读账号查询订单、库存或报表。
- **连接外部系统**：用 HTTP 或 MCP 工具创建工单、发消息、查日历。
- **复用团队流程**：把固定步骤写进 Skill，让不同 Agent 按同一套规范工作。
