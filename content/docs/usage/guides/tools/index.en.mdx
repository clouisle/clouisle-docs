Tools let Agents and workflows do more than generate text: read the time, do math, search the web, call external APIs, query a database, or run code in a sandbox. By origin they are built-in tools (registered by the platform; web search is configured once by the site administrator), team custom tools (HTTP, code, database), MCP servers, and Skill packages. Beyond the definition, a **connection** decides which account executes, and **approval** decides whether the caller must confirm.

## Common scenarios

- **Everyday utilities**: time lookup, unit conversion, and expression math need no configuration.
- **Business data**: query orders, inventory, or reports through a read-only database tool.
- **External systems**: create tickets, send messages, or read calendars through HTTP or MCP tools.
- **Reusable team process**: put a fixed procedure into a Skill so different Agents follow the same rules.
