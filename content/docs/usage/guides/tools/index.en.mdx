Tools let Agents and workflows do more than generate text: read the time, do math, search the web, call external APIs, query a database, or run code in a sandbox. By origin they are built-in tools (registered by the platform; web search is configured once by the site administrator), team custom tools (HTTP, code, database), MCP servers, and Skill packages.

<Cards>
  <Card title="Built-in Tools" href="/usage/guides/tools/built-in">Enable system capabilities such as time, computation, web search, page fetching, and feeds; this is where site-managed search engines are configured.</Card>
  <Card title="Custom Tools" href="/usage/guides/tools/custom-tools">Create HTTP API, code, and database tools (PostgreSQL / MySQL / Redis / MongoDB), define parameters, test connectivity, and share them with other teams.</Card>
  <Card title="MCP Servers" href="/usage/guides/tools/mcp">Connect MCP Servers over stdio, SSE, or HTTP.</Card>
  <Card title="Skills and Packages" href="/usage/guides/tools/skills">Import Skill packages from Zip or Git, run sandbox tests, and bind them to Agents.</Card>
</Cards>
