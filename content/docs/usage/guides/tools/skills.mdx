Skills 是可复用的指令、资源和执行约定。平台提供**能力** > **Skills**页；管理员还可以在管理后台审核和管理已导入包。

## 导入 Skill 包

1. 在**能力**页选择 **Skills** 标签。
2. 选择**导入**，上传或选择一个 Clouisle 包。
3. 检查包中的名称、版本、描述、资源和依赖。
4. 导入后为当前团队启用 Skill。
5. 在 Agent 的**工具**选择器中绑定需要的 Skill，或在工作流节点中使用它。

## 生命周期

导入、启用、禁用和删除是不同操作。禁用不会删除历史引用；删除前确认没有已发布 Agent 或工作流依赖它。Skills 的版本应与包内容一起记录，生产变更先在草稿应用中验证。

## 排查

包格式无效、资源缺失、依赖不满足或权限不足时，导入会失败。保留服务端返回的错误信息和包版本，便于管理员定位。
