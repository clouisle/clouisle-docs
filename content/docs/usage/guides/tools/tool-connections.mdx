工具定义回答“能做什么”，**工具连接**回答“以谁的身份做”。同一个 GitHub 工具，可能用你的个人账号，也可能用团队的机器人账号；同一个数据库工具，可能连测试库，也可能连生产库。连接把凭证从工具定义里拆出来，避免把密码写进 Agent。

## 什么时候需要连接

- **MCP 服务要求登录**：远程 MCP 用 OAuth 授权，或需要 API Key、请求头。
- **自定义 HTTP 工具带鉴权**：调用第三方工单、CRM、内部 API。
- **数据库工具**：PostgreSQL、MySQL、Redis、MongoDB 的账号密码或连接串。
- **个人账号与团队账号不同**：你希望 Agent 以个人身份操作，而不是借用别人的凭证。

不需要鉴权的工具（时间、计算、公开网页搜索）不需要连接。

## 两个层级

| 层级 | 谁能看到 | 谁能管理 | 适合 |
| --- | --- | --- | --- |
| **个人连接** | 你自己 | 你自己 | 个人 GitHub、个人数据库账号、只属于你的 OAuth 授权 |
| **团队连接** | 当前团队成员 | 团队所有者 / 管理员 | 团队共享的机器人账号、统一的生产只读库 |

个人设置里的列表只显示**当前团队**下的连接。切换团队后，列表随之变化；个人连接不会跨团队共享。

## 管理个人连接

1. 点击右上角头像，选择**个人资料**。
2. 切换到**工具连接**标签。
3. 列表显示工具名称、账号标签、层级（个人/团队）、状态与默认标记。

### 添加连接

1. 点击**添加连接**。
2. 从工具选择器中选择需要连接的工具或服务。只列出声明了连接字段的工具。
3. 按工具要求填写：
   - **OAuth 服务**：点击**授权登录**，在弹出页完成授权。
   - **API Key / 请求头 / 数据库字段**：填写声明的字段；密码与密钥只写不读。
4. 保存。新连接出现在列表中，状态为**可用**。

如果工具声明了多个连接字段，界面会按字段逐个校验；必填项缺失时不会保存。

### 设为默认

一个工具可能有多条连接（例如两个 GitHub 账号）。点击**设为默认**把其中一条标记为默认；默认连接旁会出现**默认**徽标。

Agent 和工作流没有显式指定连接时：

1. 优先使用**默认连接**。
2. 没有默认时，如果只有**一条个人连接**，自动使用它。
3. 有多条个人连接且没有默认时，运行会提示需要选择或设置默认，不会擅自借用另一条。

### 重新授权与删除

| 状态 | 含义 | 可以做什么 |
| --- | --- | --- |
| **可用** | 凭证有效 | 设为默认、断开 OAuth、删除 |
| **需要重新授权** | OAuth 令牌过期或被撤销 | 点击**重新授权**重新走登录流程 |
| **已失效** | 凭证被服务端拒绝 | 重新授权或删除后重建 |

- **断开连接**只撤销 OAuth 授权，保留连接记录；之后必须重新授权才能使用。
- **删除连接**会移除已保存的凭证，依赖它的用户将无法继续使用，且不可恢复。两个操作都会要求确认。

## Agent 如何使用连接

在 Agent 的工具配置里，连接模式通常有两种：

- **自动（当前用户）**：运行时按上面的默认/唯一规则选择连接。适合个人助手，让每个用户用自己的账号。
- **固定连接**：作者显式指定某一条连接。适合共享 Agent、后台任务和定时运行，因为它们没有“当前用户”。

工作流、嵌入、定时任务等非交互入口只能使用**固定连接**；没有固定连接时，运行会失败并提示配置，而不是借用某个人的账号。

## 安全边界

- 凭证保存在服务端并加密，接口不会把密钥、密码或 OAuth 令牌返回给浏览器。
- 列表只显示账号标签和状态，不显示内部字段名或密文。
- 个人连接只有本人能管理；团队成员能看到团队连接，但不能修改别人的个人连接。
- 共享工具只读：由共享方团队管理连接与策略。
- 连接被撤销、过期或不属于当前团队时，运行会给出明确提示，不会静默跳过工具。

## 常见问题

### Agent 说“需要配置连接”

打开工具连接页，确认当前团队下存在该工具的可用连接；如果有多条，设置一条默认。共享 Agent 可能被固定到某条连接，需要由作者修改编排。

### OAuth 授权后仍提示需要重新授权

令牌可能被服务商撤销，或授权时使用的账号已失去权限。点击**重新授权**重新登录；仍然失败时删除连接后重建。

### 为什么看不到团队连接的新增入口？

团队连接由团队所有者或管理员创建。普通成员可以查看和使用，但不能新增或修改团队级凭证。
