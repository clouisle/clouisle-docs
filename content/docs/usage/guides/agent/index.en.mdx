The Agent guide covers the full lifecycle from creation to post-launch operation.

## Common scenarios

- **Support answers**: put product manuals and ticket history into a knowledge base so the Agent handles common questions first and hands off when it cannot.
- **Document assistant**: upload contracts, reports, or spreadsheets and ask about specific clauses, numbers, and differences.
- **Internal automation**: use tool connections to query business databases, create tickets, or send notifications, turning repetitive work into a sentence.
- **External service**: after publishing, [embed](./embed-and-share.mdx) it into a site or connect it to your app with the [API](./api-access.mdx).
