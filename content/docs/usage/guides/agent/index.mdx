Agent 指南覆盖从创建到上线后的完整生命周期。

## 常见使用场景

- **客服答疑**：把产品手册和工单记录放进知识库，让 Agent 先回答常见问题，答不了再转人工。
- **文档助手**：上传合同、报告或表格，让 Agent 读取并回答具体条款、数字和差异。
- **内部流程自动化**：用工具连接查询业务库、创建工单或发送通知，让重复操作变成一句对话。
- **对外服务**：发布后用[网页嵌入](./embed-and-share.mdx)放进官网，或用 [API](./api-access.mdx)接进自己的应用。
