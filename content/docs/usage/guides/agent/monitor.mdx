监控看板汇总单个 Agent 的会话量、Token 消耗、响应时间、工具调用、执行结果分布和用户干预情况。数据来自该 Agent 已产生的会话与运行记录，是判断「要不要调提示词、加知识库或换模型」的依据。

<Callout type="info">
  监控页按**写权限**校验：超级管理员、该 Agent 的创建者，或所属团队的**所有者/管理员**才能访问。普通团队成员与观察者即使可以使用该 Agent，也看不到监控数据，会被重定向回应用列表。私有 Agent 仅创建者可访问；创建者缺失的历史私有 Agent 由团队管理员访问。
</Callout>

## 管理台应用列表

管理员在**应用**（管理台 **Apps**，**资源**分组下）看到的是全部团队的 Agent 列表，与单个 Agent 的监控页是两个入口：

| 列表列 | 说明 |
| --- | --- |
| **名称与描述** | Agent 名称与描述 |
| **团队** | 所属团队 |
| **状态** | 草稿或已发布 |
| **模型** | 使用的对话模型 |
| **使用统计** | 会话数与消息数，没有单独的统计页签 |
| **创建时间 / 最近活跃** | 创建日期与最后活跃时间 |

列表支持按状态、可见性、团队、创建者筛选，并按名称或描述搜索。

<Callout type="note">
  管理台列表只展示会话数与消息数；时间范围内的会话量、Token、延迟、工具分布和执行健康度请看单个 Agent 的监控页。
</Callout>

## 打开监控页

1. 前往**应用**或工作台，打开目标 Agent。
2. 在 Agent 侧边栏选择**监控**（与**编排**、**API**、**日志**并列）。
3. 页面标题为**监控**，副标题为「查看此 Agent 的使用统计和性能指标」。

## 时间范围

页面顶部的时间范围选择器默认选中**最近 7 天**，只提供三档：

| 选项 | 趋势粒度 |
| --- | --- |
| 最近 24 小时 | 按小时，24 个点 |
| 最近 7 天 | 按天，7 个点 |
| 最近 30 天 | 按天，30 个点 |

点标签按站点时区对齐，显示为 `HH:00`（按小时）或 `MM/DD`（按天）。

监控页**没有刷新按钮**，也没有手动粒度控制。切换时间范围是唯一的刷新方式，切换时会同时重新加载概览、趋势和工具使用。

## 概览卡片

页面顶部有 6 张指标卡。数值大于等于 `1K` 显示为 `K`、大于等于 `1M` 显示为 `M`；耗时小于 `1` 秒显示毫秒，否则显示两位小数的秒数。

| 卡片 | 说明 |
| --- | --- |
| **对话数** | 区间内创建的会话总数 |
| **消息数** | 用户消息、助手消息与工具消息之和 |
| **Token 用量** | 总 Token，并分别展示提示词 Token（`↑`）与补全 Token（`↓`） |
| **平均响应时间** | 端到端的平均耗时 |
| **活跃用户** | 区间内产生过会话的去重用户数 |
| **工具调用** | 助手消息中工具调用的总次数 |

## 使用趋势

三张面积图共用同一时间范围：

| 图表 | 说明 | 纵轴 |
| --- | --- | --- |
| **对话趋势** | 对话数和消息数随时间变化 | 计数 |
| **Token 用量** | 总 Token 消耗随时间变化 | `K`/`M` 紧凑格式 |
| **响应时间** | 平均响应时间随时间变化 | 秒 |

趋势数据补齐了完整的时间点，没有数据的时间段显示为 0，因此曲线连续，不会因某段时间无会话而断开。

## 工具调用分布

**工具使用**卡片用环形图展示该 Agent 的工具调用分布，按调用次数降序。图例显示工具的本地化名称和调用次数，悬浮提示为**调用次数**。

- 最多显示前 `8` 个工具，其余合并为**其他工具**并保留合计次数。
- 无工具调用时显示**暂无工具使用数据**。
- 工具名称按站点语言本地化。
- 统计不会实时枚举 MCP 服务器的工具，因此 MCP 工具可能不出现在分布里。

## 执行健康度

**执行健康度**环形图展示该 Agent 已结束运行的结果分布，悬浮提示显示次数与占比。

| 结果 | 含义 |
| --- | --- |
| **成功** | 运行正常执行完毕 |
| **失败** | 运行以失败结束 |
| **停止** | 用户主动停止 |
| **中断** | 执行该运行的服务中断（崩溃、重启或被驱逐），运行没有走到完成 |

成功率为**成功 ÷ 已结束运行**，卡片内提示为「成功 ÷ 已结束运行」。卡片颜色随成功率变化：

| 成功率 | 颜色 |
| --- | --- |
| `≥ 95%` | 绿色 |
| `≥ 80%` 且 `< 95%` | 琥珀色 |
| `< 80%` | 红色 |

<Callout type="warn">
  **中断是终态**，会让成功率下降，而不是「仍在进行中」。进行中的运行不计入分母，页面会显示「另有 N 个进行中，未计入」。从未有运行结束时，卡片显示**暂无运行记录**。
</Callout>

## 首 Token 延迟

**首 Token 延迟**卡片给出中位数（`p50`）、`p95` 和平均值，并用折线图按时间分桶展示走势。没有样本的时间段折线断开不连线，卡片同时显示样本数；完全没有样本时显示**暂无延迟样本**。

首 Token 延迟反映「用户等待第一个字出现」的体感，与**平均响应时间**（端到端总耗时）是两个指标：延迟高通常与模型首字速度、上下文长度或排队有关；总耗时高还可能是工具调用多。

## 用户干预

**用户干预**柱状图统计用户对运行的三类介入行为（只显示非零项）：

| 标签 | 含义 |
| --- | --- |
| **中途引导** | 生成过程中插入补充指令 |
| **主动停止** | 用户手动停止生成 |
| **追问** | 针对上一轮结果继续追问 |

卡片同时给出**干预率** = 干预总量 ÷ 已结束运行数，保留两位小数，提示为「基于 N 次已结束运行」。

<Callout type="note">
  干预总量为 0 时显示空状态；若柱状图有数据但没有任何已结束运行，则不显示干预率。干预率高通常意味着提示词、工具描述或知识库召回不够明确，用户需要反复纠偏。
</Callout>

## 数据口径与已知限制

- 时间范围支持最近 24 小时、7 天和 30 天；默认 7 天。
- 统计失败时页面**静默保留上一次或空数据**，不显示错误提示。图表长时间为空但会话明显存在时，先刷新页面，再联系运维检查统计服务。
- 卡片数量少于 6 张或图表区域空白，通常是数据尚未返回；加载过程中显示骨架屏。
- 统计按已保存的会话与运行计算，草稿预览不产生正式统计，直接调用模型不经过 Agent 也不会被统计。

**不可用（Roadmap）：** 成本/费用拆分、更多响应时间百分位、统计导出（CSV/PDF）与定时报表、Prometheus 指标。

## 排查

### 监控页打不开或跳回应用列表

1. 确认你是该 Agent 的创建者，或所属团队的所有者/管理员（私有 Agent 仅创建者可访问，创建者缺失的历史私有 Agent 由团队管理员访问）。
2. 确认 Agent 未被删除；已删除的 Agent 会跳回应用列表。
3. 团队 Agent 请确认仍是该团队成员。

### 指标全部为 0

1. 确认时间范围内确实有会话（先看**对话数**）。
2. 确认查看的是已发布版本的会话；草稿预览不产生正式统计。
3. 确认调用方走的是 Agent 会话，而不是直接调用模型。

### 成功率偏低

1. 查看**执行健康度**中**失败**与**中断**的占比。**中断**占比高说明运行环境不稳定，应联系运维，而不是改提示词。
2. 打开**日志**页按失败状态筛选，定位失败运行的报错。
3. 结合**用户干预**的**主动停止**比例，判断是否是超时或回复过长导致用户放弃。

### 首 Token 延迟偏高

1. 检查模型供应商的首字速度与当前负载。
2. 缩短系统提示词与注入的知识库上下文。
3. 对比不同模型的首 Token 延迟，必要时更换更快的对话模型。
