Agent Studio（`/app/apps/{agent_id}`）在桌面端以双列布局显示编排区和实时预览：
- **左侧编排区（Orchestration Editor）**：配置模型、系统提示词、变量、知识库、工具与运行参数。
- **右侧即时预览面板（Live Preview Panel）**：在不离开页面或发布更改的情况下，与草稿 Agent 进行对话测试。
- **顶部操作栏**：展示 Agent 元数据、发布状态（`草稿 / 已发布`）、嵌入入口（`Embed`）与高级设置（`Settings`）。

手机端隐藏并排预览，避免压缩编排区。点击顶部工具栏的 **预览**，即可在全屏抽屉式面板中打开对话；关闭预览即可返回编辑。

<Callout type="info">
  当前团队必须已授权一个启用的对话模型。创建需要创建 Agent 的权限；发布需要发布 Agent 的权限。
</Callout>

## 创建 Agent

1. 前往**应用**，选择**创建应用** > **Agent**。
2. 填写名称（`1-100` 字符）与描述（最多 `500` 字符）。
3. 选择所属团队。
4. 进入 Agent Studio 编排页后选择右上角 **Agent 设置**，配置模型、开场消息、建议问题与可见性。
5. 可见性默认为**私有**（仅创建者可访问），可切换为**团队**。

**最大迭代次数** 决定 Agent 在一次回复里最多执行多少轮工具调用：默认 `5`，可设 `1-200`。设得过低会让复杂任务提前结束，设得过高则可能在工具反复失败时消耗大量 Token。

<Callout type="info">
  Agent 不暴露逐次生成的采样参数（Temperature、Max Tokens、Top P、Frequency/Presence Penalty）。采样默认值配置在模型本身；Agent 只选择模型、编写系统提示词、设置最大迭代次数，并关联工具与知识库。字段级说明见 [Agent 配置参考](/reference/agent-config)。
</Callout>

## 编写提示词与变量

1. 在**提示词**中明确角色、任务、约束、工具使用条件和失败处理。
2. 输入 `{` 打开变量选择器。`{query}` 为当前用户消息。
3. 在**变量**中添加用户输入字段。变量名最长 `50` 字符；可配置显示名、必填、隐藏、默认值、选项、数值范围或最大长度。
4. 在右侧预览中填入变量，确认替换结果。

## 配置知识库与 RAG

1. 在**知识库**区域选择**添加**。
2. 选择知识库以及**向量**、**全文**或**混合**检索方式。
3. 设置返回结果数（`1-100`，默认 `5`）和相似度阈值（`0-1`，默认 `0.3`）。
4. 可选启用**重排序（Rerank）**以提高召回精度。
5. 设置整体 RAG 模式：**关闭**、**自动（Auto）** 或 **智能体（Agentic）**。

单知识库的检索方式默认**混合**；多个知识库按列表顺序进入检索上下文，编辑 Agent 时可拖动调整顺序。未关联知识库时 RAG 会自动关闭，编辑器也会隐藏 RAG 模式选择器；关联后才显示。

检索模式的含义、混合检索的团队灰度与调参方法见[检索与质量调优](/usage/guides/knowledge/retrieval)。

## 添加工具和能力

在**工具**区域选择内置工具、自定义工具、MCP 或 Skill。

| 工具类型 | 说明 | 前置条件 |
| --- | --- | --- |
| Web Search | 站点托管的网页搜索：可选择 Tavily、博查、SearXNG 或 DeepSeek，默认项使用站点默认引擎 | 管理员已在站点**能力** > **配置搜索**中启用并配置引擎 |
| Calculator | 数学计算 | 无 |
| Date/Time | 日期与时间查询 | 无 |
| Unit Converter | 单位换算 | 无 |
| Custom Tool | 自定义工具 | 先在**能力**中创建并测试 |
| MCP | Model Context Protocol 工具 | 先在**能力**中配置 |
| Skill | 预定义技能 | 无 |

<Callout type="warn" title="不要在 Agent 里配搜索密钥">
  Agent 不保存搜索凭据，也不能覆盖搜索地址。网页搜索的引擎下拉只列出站点已启用的引擎；即使保存过某个引擎，执行时也会重新校验站点配置，引擎被禁用后该选择即无法运行。搜索凭据与引擎管理见[内置工具](/usage/guides/tools/built-in#网页搜索站点托管)。
</Callout>

自定义工具先在**能力**中创建和测试，再按 Agent 启用。工具显示“需要配置”时，先前往**能力**完成凭据（网页搜索除外，它由站点统一配置）。

工具真正执行时还需要**身份**：个人或团队的工具连接决定了以谁的账号调用。连接模式可选**自动（当前用户）**或**固定连接**；没有可用连接时运行会提示配置，而不是静默跳过。需要防止误操作的工具可以设为**需要调用者确认**，对话会在执行前暂停。配置见[工具连接](../tools/tool-connections.mdx)与[工具审批](../tools/tool-approvals.mdx)。

工具调用的超时与迭代上限在 Agent 设置中调整：单次工具调用超时默认 `30` 秒，工具调用迭代上限与最大迭代次数一致（默认 `5`）。

## 配置附件、媒体与记忆

启用附件、生图、生视频和跨会话记忆前，先在 Agent **编排**中开启对应能力：

| 能力 | 配置位置 | 默认与限制 |
| --- | --- | --- |
| 附件 | **文件与图片** | 单文件 `10MB`（`1KB-50MB`），每条消息 `5` 个（`1-10`）；支持 PDF、Word、PowerPoint、Excel、TXT、Markdown、CSV、JSON、HTML 和图片 |
| 生图 | **生图** | 默认 `1024×1024`（`256-4096`），单次最多 `4` 张（`1-10`），允许参考图默认开启 |
| 生视频 | **生视频** | 默认 `5` 秒（`1-30` 秒），宽高比 `16:9` |
| 记忆 | **记忆** | 每次最多注入 `10` 条记忆（`1-50`），自动提取默认开启 |

另有两个展示开关在 **Agent 设置**里：**引用**（默认关闭）开启后在回复中附来源引用；**隐藏产物列表**（默认关闭）开启后隐藏助手消息下方的生成文件列表，只影响展示，不会删除生成的文件。

媒体生成只覆盖**图片和视频**两种（没有音频/TTS 生成能力）。生图与生视频都会调用团队已授权的对应模型；关闭开关后模型看不到这些能力。

关于上下文：长对话使用**分层压缩**——较早历史生成摘要、已完成工具结果折叠为可回读的引用，工具很多时还会按需发现。原始消息和工具记录仍保留，压缩只改变模型看到的内容；它只作用于当前会话，**不**等同于跨会话记忆。记忆是独立的**实体/关系**知识图谱，跨会话持久保存。

压缩在**上下文压缩**区域配置：默认开启；摘要 Token 预算默认 `1000`（`128-8000`）；**显示压缩进度**默认开启。详见[记忆与上下文](./memory.mdx)。

详细配置请参阅[附件与媒体](./media.mdx)和[记忆与上下文](./memory.mdx)。

## 设置可见性与发布

1. 选择**私有**或**团队**可见性。
2. 选择**发布**。发布后状态变为**已发布**，Agent 可接收消息。
3. 发布后可打开**公开页面**、**嵌入**和**访问 API**。

<Callout type="info">
  **公开**可见性仅保留用于历史记录，新建 Agent 应使用**私有**或**团队**。
</Callout>

<Callout type="warn">
  Agent 仅有**草稿**和**已发布**两种状态。没有启用/停用或归档状态，也没有归档/恢复流程。要让 Agent 停止使用，取消发布或删除即可。
</Callout>

## 保存、调试与发布

1. 选择**保存**。验证错误会列出具体字段。
2. 在**调试与预览**发送覆盖正常和失败路径的问题。
3. 有工具时验证工具参数、失败提示与最大迭代终止行为。
4. 选择**发布**。

展示类开关（**引用**、**隐藏产物列表**）见上文「配置附件、媒体与记忆」，它们只影响界面展示。

## 监控与统计

每个 Agent 有独立的**监控**页（`/app/apps/{agent_id}/monitor`），在 Agent 侧边栏选择**监控**打开。页面按 `24h`、`7d`（默认）、`30d` 展示概览卡片、使用趋势、工具调用分布、**执行健康度**、**首 Token 延迟**和**用户干预**。

| 指标 | 说明 |
| --- | --- |
| 会话与消息数 | 总会话数、总消息数、活跃用户数 |
| Token 用量 | 输入 Token、输出 Token 与总用量 |
| 平均响应时间与首 Token 延迟 | 端到端平均耗时；首 Token 的 `p50`/`p95`/`avg` |
| 执行健康度与用户干预 | 运行结果分布、成功率与干预次数 |
| 工具调用 | 各工具调用次数统计 |
| 使用趋势 | 按时间聚合的使用量变化 |

<Callout type="info">
  图表口径、成功率算法与限制见 [Agent 监控看板](./monitor)。
</Callout>

<Callout type="warn">
  未实现/路线图：逐 Agent 成本拆分、首 Token 之外的请求级响应时间百分位、统计导出（CSV/PDF）、定时使用报告。运维层面也没有 Prometheus 指标端点。
</Callout>

## 最佳实践

### Agent 设计

- ✅ 编写清晰、具体的系统提示词
- ✅ 部署前充分测试
- ✅ 为任务选择合适的模型
- ✅ 启用 RAG 以提高事实准确性
- ✅ 通过监控页观察使用量
- ✅ 收集用户反馈并迭代

- ❌ 使用模糊的系统提示词
- ❌ 部署未经测试的 Agent
- ❌ 简单任务使用昂贵模型
- ❌ 忽略错误率
- ❌ 不监控成本

### 性能

- ✅ 启用流式输出提升体验
- ✅ 优化知识库搜索
- ✅ 设置合理的超时时间

- ❌ 长任务使用同步处理
- ❌ 给 Agent 加载过多知识库
- ❌ 设置过高的输出上限

## 故障排查

### Agent 无响应

1. **检查 Agent 状态**：确认已发布；检查模型可用性。
2. **检查模型配置**：验证 API 密钥有效；测试模型连通性；检查速率限制。
3. **检查知识库**：确认已索引；确认搜索正常。
4. **检查审计日志**：筛选资源类型为 `agent` 且资源 ID 匹配的错误。

### 回复质量差

1. **审查系统提示词**：让指令更清晰；添加示例；设定边界。
2. **改善知识库**：添加相关文档；更新过时内容；优化分块策略。
3. **启用 Agentic RAG**：让 Agent 自主决定何时检索，提升事实准确性。

### 成本过高

1. **审查用量**：在监控页查看 Token 用量和会话数，定位高用量 Agent。
2. **优化提示词**：缩短系统提示词；减少上下文长度；简单任务使用更便宜的模型。

<Callout type="warn">
  未实现/路线图：逐 Agent Token 限制、每日用量上限、成本告警均不可用；监控页的使用量为只读展示。
</Callout>

## 常见问题

- **模型列表为空**：团队未获对话模型授权，或模型已禁用。
- **工具未调用**：检查模型函数调用能力、工具是否启用，以及提示词是否定义调用条件。
- **发布失败**：确认拥有发布权限，且模型、变量引用和能力配置有效。
- **公开页无法访问**：确认 Agent 已发布；私有/团队可见性仍受登录和团队访问控制影响。
