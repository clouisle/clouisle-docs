已发布 Agent 提供完整聊天页；编辑器右侧预览用于构建期调试。会话在第一条消息发送时创建，并保存变量、消息数和 Token 用量。

## 开始对话

1. 从**应用**打开 Agent，选择**对话**或**公开页面**。
2. 若 Agent 定义了必填变量，先完成变量表单。
3. 输入消息。`Enter` 发送，`Shift+Enter` 换行。
4. 若启用附件，可附加文件和图片；每条消息的数量和大小由 Agent 配置决定。

## 理解回复

回复可能由以下部分组成：

- **正文**：以流式增量显示。
- **思考过程**：仅当模型提供且 Agent 未隐藏时显示。
- **参考文档**：RAG 返回的分块、文档名和相关度。
- **工具调用**：参数、结果、日志和产物；可由 Agent 隐藏详情。
- **媒体结果**：图片或视频直接渲染到助手正文。
- **消息操作栏**：复制、版本、Token、速度等；可由 Agent 隐藏。

## 停止、编辑和重新生成

- 流式生成时选择**停止**。消息状态记录为手动停止。
- 编辑历史用户消息会从该消息创建新分支，并流式生成新回复。
- 重新生成助手消息会创建新版本。版本切换只改变活动分支，不删除旧版本。
- 删除消息会处理其后续分支；删除会话会永久删除所有消息。

## 管理会话

会话抽屉支持选择、重命名和删除自己的会话。标题最多 `200` 字符。应用的**日志**页可按时间和搜索词查看会话，并显示变量、模型、Token、响应耗时、思考与知识来源。

<Callout type="warn">
  当前实现没有归档、多人协作评论或 PDF 导出流程。不要把删除当作归档；删除操作不可恢复。
</Callout>
