已发布 Agent 提供完整聊天页；编辑器右侧预览用于构建期调试。会话在第一条消息发送时创建，并保存变量、消息数和 Token 用量。

<Callout type="info">
  没有全局**对话**页或**新对话**选择器。每个 Agent 的聊天页只包含该 Agent 的最近会话。
</Callout>

## 开始对话

### 从应用页开始

1. 前往**应用**（`/app/apps`）。
2. 选择 **Agent** 标签，找到要使用的 Agent。
3. 打开 Agent 卡片菜单，选择**对话**。
4. Agent 聊天页打开于 `/chat/{agent_id}`，发送第一条消息即创建会话。

### 从现有聊天页继续

1. 打开 Agent 的聊天页。
2. 使用该页的会话控件继续最近会话或开始新会话。
3. 输入消息并发送。

## 聊天界面

### 布局

```
┌─────────────────────────────────────────────────┐
│  Agent 名称                    [设置] [...]      │
├─────────────────────────────────────────────────┤
│                                                  │
│  Agent: 你好！我能为你做些什么？                   │
│                                                  │
│  你: Clouisle 是什么？                            │
│                                                  │
│  Agent: Clouisle 是一个企业级...                  │
│  [来源: doc1.pdf, doc2.md]                        │
│                                                  │
├─────────────────────────────────────────────────┤
│  [📎] 输入消息...            [发送]              │
└─────────────────────────────────────────────────┘
```

### 关键元素

| 元素 | 说明 |
| --- | --- |
| **Agent 名称** | 当前对话的 Agent |
| **消息历史** | 可滚动的对话历史 |
| **输入框** | 输入消息的区域 |
| **附件按钮** | 上传文件（Agent 启用附件时可用） |
| **发送按钮** | 发送消息 |
| **停止按钮** | 流式生成时中断回复 |
| **来源** | 知识库检索返回的参考文档（启用知识库时显示）；点击可在预览面板查看对应分块 |
| **产物列表** | 该轮生成的文件，显示在助手消息正文下方 |
| **预览面板** | 点击产物、图片或来源打开的右侧面板；桌面可拖拽调宽，移动端全屏 |

## 发送消息

### 文本消息

**基本消息：**
1. 在输入框输入消息
2. 按 **Enter** 或点击**发送**
3. 等待 Agent 回复（流式）

**多行消息：**
1. 输入消息
2. 按 **Shift+Enter** 换行
3. 按 **Enter** 发送

### 文件上传

若 Agent 启用附件：

1. 点击 **📎 附件**按钮
2. 从电脑选择文件
3. 支持的格式取决于 Agent 配置（PDF、DOCX、TXT、MD、CSV、XLSX、PPTX、图片等）
4. 等待文件上传/解析
5. 添加关于文件的提问
6. 点击**发送**

**上传限制：**
- 所有聊天上传单文件限制 **10 MB**（服务端强制）
- 每条消息最大文件数由 Agent 配置决定（默认 5）

详细文件支持与安全说明请参阅[附件与媒体](./media)。

## 理解回复

### 流式响应

Agent 实时流式输出回复：
- 文本逐词出现，Agent 仍在生成时即可阅读
- 点击**停止**按钮中断生成

### 回复组成

回复可能包含以下部分：

- **正文**：以流式增量显示。
- **思考过程**：仅当模型提供且 Agent 未隐藏时显示。
- **参考文档**：知识库检索返回的分块、文档名和相关度。
- **工具调用**：参数、结果、日志和产物；可由 Agent 隐藏详情。
- **媒体结果**：图片或视频直接渲染到助手正文。
- **消息操作栏**：复制、版本、Token、速度等；可由 Agent 隐藏。

### 思考时间线与来源引用

进度按实际发生的顺序显示。检索、上下文压缩、推理、工具调用、媒体结果和正文可能交错出现，界面不会固定把检索放在最前面。


<figure>
  <img src="/images/agent-chat-thought-trace.png" alt="对话中的思考时间线与工具调用" />
  <figcaption>思考时间线：检索、工具调用与产物按发生顺序展开</figcaption>
</figure>

回答正文里的来源标记紧跟被支撑的句子；**来源列表只列出被实际引用的来源**，无法对应到已知来源的标记不会渲染成编号。Agent 关闭**引用**开关时，正文标记与来源列表都不显示；Agent 只在具备知识库检索、附件或联网工具时才产生引用。

### 交互式提问

Agent 开启**编排** > **交互式提问**（默认关闭）后，模型可以在回答中途暂停并提问，而不是猜测缺失信息。

1. 模型发起提问，本轮运行进入等待状态，输入框被禁用。
2. 表单出现在输入框上方，但**不写入消息历史**；一次可以包含 `1-20` 个问题，逐题翻页，带选项的题目可直接点选，也可以自由输入，非必答题可留空。
3. 提交后，同一轮运行从暂停点继续，问题与答案以工具步骤出现在执行轨迹中。
4. 也可以整体**跳过**本轮提问，让模型按现有信息继续。

限制：每题题干最长 `2000` 字符，选项最多 `50` 个、单个选项最长 `500` 字符。答案只消费一次：重复提交同一次提问不会产生第二条结果。等待中的提问会随运行一起保存，刷新页面或切回该会话时会重新显示表单，因此**不要通过刷新来取消提问**——要放弃请提交答案或点击停止。

### 工具确认

当 Agent 要调用的工具被团队设为**需要调用者确认**时，运行会在执行前暂停：

<figure>
  <img src="/images/chat-tool-confirmation.png" alt="对话中的工具确认卡" />
  <figcaption>工具确认卡：工具名称、说明、脱敏后的操作详情，以及允许/拒绝</figcaption>
</figure>

1. 输入框上方出现 **确认此操作** 卡片，显示工具名称、说明与**查看操作详情**；敏感参数已脱敏。
2. 选择**允许**执行这次调用，或选择**拒绝**取消。
3. 多个工具同时暂停时，每个调用单独确认，按原顺序恢复。

只有**发起这次运行的你**能决定；团队成员、团队管理员和超级管理员都不能代确认。刷新页面或切回会话会恢复待确认卡片，不要用刷新来取消——请明确拒绝或停止运行。停止等待中的运行会取消待处理确认。API 密钥发起的运行只能由同一把密钥决定；飞书/微信里用 `/approve <execution UUID>` 或 `/reject <execution UUID>`。工作流不会触发确认。

完整策略、旧版配置与审计说明见[工具审批与调用者确认](../tools/tool-approvals.mdx)。

### 回复质量

**高质量回复包括：**
- 直接回答问题
- 相关上下文与细节
- 来源引用（使用知识库时）
- 清晰的结构与格式

**若回复质量不佳：**
- 更清晰地重述问题
- 提供更多上下文
- 将复杂问题拆分为简单部分
- 检查 Agent 是否关联了相关知识库

## 附件与媒体

附件为 Agent 提供用户上传的文档和图片；媒体生成让 Agent 调用已授权的图片或视频模型。两者都需在 Agent **编排**中显式启用。

默认附件限制：单文件 `10 MB`（`1KB-50MB`），每条消息 `5` 个（`1-10`）。图片只有在聊天模型支持视觉时才直接进入模型。

详细配置请参阅[附件与媒体](./media)。

## 变量与表单

若 Agent 定义了必填变量，发送消息前需先完成变量表单。变量在提示词中以 `{变量名}` 引用，`{query}` 为当前用户消息。

1. 聊天页顶部显示变量表单
2. 填写必填字段
3. 输入消息并发送

## 停止、中途引导与重新生成

- **停止（Stop）**：流式生成时点击**停止**按钮，会立即中断本轮回复，消息状态标记为手动停止。
- **中途引导（Steering / User Guidance）**：在 Agent 流式生成或思考的过程中，无需强行停止，用户可直接在输入框输入补充说明或修正意图并发送。输入框上方会显示浮动胶囊，提示排队中的引导指令；引导内容会进入本轮上下文，并在思考时间线中以「用户引导」步骤展示。
- **编辑（Edit）**：编辑历史用户消息会从该节点创建新分支，并以此上下文流式生成新回复。
- **重新生成（Regenerate）**：重新生成助手消息会创建该轮次的新版本。多版本之间通过左右箭头切换活动分支，系统完整保留历史所有生成记录。
- **删除（Delete）**：删除消息会递归清理其后续活动分支；删除会话会删除该会话及其全部历史消息。

### 滚动跟随与交互优化

- **发送即置底**：点击发送后界面立即锁定并平滑滚动到最新用户气泡，无需等待首个流式片段。
- **思考过程折叠条**：支持展开/收起思考链路，流式推送时自动跟踪滚动状态；工具调用卡片支持实时参数折叠、日志查看与生成文件一键下载。
- **追问与排队**：在上轮运行完成瞬间或流式末尾输入追问（Follow-up），系统会保存该消息并继续驱动下一轮推理。

### 产物列表与预览

- 每条助手消息结束后，正文下方汇总该轮生成的文件，按路径去重并保留最新一次；文件本身不会因为隐藏列表而删除。
- Agent 开启**隐藏产物列表**时，这一列表不显示，产物仍可从工具卡片中打开或下载。
- 点击产物、图片或来源会打开预览面板，支持图片、视频、音频、PDF、DOCX、PPTX、表格（CSV/XLSX 等）、HTML、Markdown、Mermaid 与纯文本。PDF 只读；DOCX 支持缩略图、页码与缩放；CSV 会先按 UTF-8 解码，失败时回退 GB18030。
- 预览是**认证请求**：受保护的产物、生成图片与视频必须携带当前会话凭证获取，未登录或无权限时不会回退到原始地址。
- 预览无法显示时，界面会明确区分：文件过大（默认 20 MiB 上限）、未登录、无权限、类型不支持、内容解析失败。
- 桌面端预览在右侧面板打开，默认可拖拽调整宽度（最小 400px）；视口较窄时预览变为全屏覆盖层，拖拽条隐藏。

### 后台运行与断线恢复

运行在服务端持续执行，关闭页面、刷新或切换会话都不会中断模型循环。

- 重新打开某个会话时，界面会先确认该会话是否还有未完成的回复，再决定继续接收剩余输出或直接加载完整历史。
- 续接的回复不会重复渲染已经显示的内容；等待用户作答的提问也会随运行一起恢复。
- 想真正结束运行请点击**停止**，刷新只是暂时离开页面。

### 消息分支

对话可包含多个分支：

```
主对话:
你: 告诉我关于 AI
Agent: AI 是...

分支 1（编辑消息）:
你: 告诉我关于 ML
Agent: ML 是...

分支 2（重新生成）:
Agent: AI，即人工智能...
```

使用箭头按钮在分支间导航。

## 管理会话

会话侧栏支持新建、选择、重命名和删除**自己的**会话。标题最多 `200` 字符，也是会话唯一可编辑的设置。

### 新建

点击侧栏顶部的**新建对话（SquarePen）**按钮开始一个新会话；发送第一条消息时才会真正创建会话。

### 重命名

在会话侧栏打开某条会话的 **...** 菜单，选择**重命名**。

### 删除

打开会话的 **...** 菜单，选择**删除**并确认。删除会移除会话及其消息，且不可恢复。

### 搜索

<Callout type="warn">
  Agent 聊天页（`/chat/{agent_id}`）**没有**会话搜索框——侧栏只提供新建、选择、重命名、删除。要按关键词查找会话，请改用下面的**日志**页或管理端的**活动日志**页。
</Callout>

两处会话搜索都以**关键词匹配会话标题或会话编号**，**不搜索消息正文**：

| 位置 | 路径 | 范围 |
| --- | --- | --- |
| Agent **日志**页 | `/app/apps/{agent_id}/logs` | 该 Agent 下**你自己**的会话；另可按创建时间过滤、按更新时间/创建时间/消息数排序，需要查看会话的权限 |
| 管理端**活动日志**页 | `/activities`（**对话**标签） | 平台内**所有用户**的会话，可按团队、Agent、用户过滤，需要管理端查看对话的权限 |

### 日志页

Agent 的**日志**页（Agent 侧边栏的**日志**）按时间和搜索词列出会话，选中会话后展示变量、模型、Token 用量、响应耗时、思考过程与知识来源。

<Callout type="warn">
  当前实现没有归档、多人协作评论或 PDF 导出流程。不要把删除当作归档；删除操作不可恢复。
</Callout>

## 最佳实践

### 编写有效的提示词

**✅ 推荐：**
```
好的：「在管理面板中重置密码的步骤是什么？」
好的：「总结 Q3 报告中关于营收增长的关键点」
好的：「以表格形式比较方案 A 和方案 B 的功能」
```

**❌ 避免：**
```
差的：「密码？」
差的：「告诉我一切」
差的：「帮忙」
```

**技巧：**
- 明确表达需求
- 需要时指定格式（表格、列表、总结）
- 提供相关上下文
- 复杂话题一次问一个

### 管理上下文

**开始新会话：**
- 切换到无关话题
- Agent 似乎对上下文感到困惑
- 想要重新开始

**继续会话：**
- 提出后续问题
- 基于之前的回答继续
- 需要保持上下文

### 有效使用知识库

**✅ 推荐：**
- 针对文档提出具体问题
- 请求来源：「根据手册...」
- 已知文档名时提及
- 跟进澄清

**❌ 避免：**
- 询问知识库中不存在的信息
- 期望 Agent 知道实时信息
- 假设所有文档都已索引

详细上下文管理请参阅[记忆与上下文](./memory)。

## 故障排查

### Agent 无响应

**问题**：发送消息后没有回复

**解决方案：**
1. 检查网络连接
2. 刷新页面
3. 检查 Agent 是否已发布
4. 尝试其他 Agent
5. 联系管理员

### 响应缓慢

**问题**：Agent 回复耗时过长

**解决方案：**
1. 检查网速
2. 简化问题
3. 避开高峰时段
4. 联系管理员了解服务负载

### 回复不相关

**问题**：Agent 给出无关回答

**解决方案：**
1. 更清晰地重述问题
2. 提供更多上下文
3. 开始新会话（清除上下文）
4. 检查 Agent 是否关联相关知识库
5. 尝试其他更专业的 Agent

### 来源不显示

**问题**：知识库问答没有来源引用

**解决方案：**
1. 确认 Agent 已关联知识库
2. 检查 Agent 的 RAG 模式不是「关闭」，且**引用**开关已开启
3. 提出更具体的问题
4. 确认文档处理已完成（状态为已完成）

### 提问表单没有出现

**问题**：Agent 说需要更多信息，但没有出现提问表单

**解决方案：**
1. 确认 Agent **编排**中已开启**交互式提问**，并已重新发布
2. 检查是否已经提交过答案或跳过——同一提问只消费一次
3. 刷新页面，仍在等待作答的运行会重新显示表单

### 刷新后回复停在半截

**问题**：刷新或切换会话后，回复看起来中断了

**解决方案：**
1. 等待片刻：运行仍在后台执行，界面会继续接收剩余输出
2. 如果运行已经结束，历史消息会整体重新加载，不会丢内容
3. 确实要中止时点击**停止**，而不是依赖刷新

### 文件上传失败

**问题**：无法上传文件

**解决方案：**
1. 检查文件大小（须小于 10 MB）
2. 确认文件格式受支持
3. 检查 Agent 是否允许文件上传
4. 尝试其他文件
5. 联系管理员
