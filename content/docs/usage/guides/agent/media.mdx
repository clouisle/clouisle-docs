附件为 Agent 提供用户上传的文档和图片；媒体生成让 Agent 调用已授权的图片或视频模型。两者都需要在 Agent 编排中显式启用。

<Callout type="info">
  媒体生成只包含**图片**和**视频**两类，不含音频生成或语音合成。开关打开后，模型可以使用生图和生视频能力；关闭后模型看不到这些能力。
</Callout>

## 配置附件

在 Agent **编排** > **文件与图片**中启用附件。默认限制：

| 项目 | 默认值 | 可配置范围 |
| --- | --- | --- |
| 单文件大小 | `10MB` | `1KB-50MB` |
| 每条消息文件数 | `5` | `1-10` |
| 单文件解析内容 | `100,000` 字符 | `1,000-500,000` |
| 截断策略 | `end`（保留开头） | `end`、`start`、`middle` |

默认扩展名包括 PDF、Word、PowerPoint、Excel、TXT、Markdown、CSV、JSON 和 HTML。附件保存为受保护的会话文件，不会自动把全文塞进对话；Agent 按需读取解析结果。图片只有在聊天模型支持视觉时才直接进入模型。

## 配置生图

1. 开启**生图**并选择图片模型，或使用系统默认模型。
2. 默认尺寸为 `1024×1024`，宽高范围 `256-4096`。
3. 单次最多生成默认 `4` 张，可配置 `1-10`。
4. **允许参考图**默认开启；需要编辑或参考生成时保留此项。

## 配置生视频

1. 开启**生视频**并选择视频模型。
2. 默认时长 `5` 秒，单次最大默认 `10` 秒；两者范围均为 `1-30` 秒。
3. 默认宽高比 `16:9`。
4. 状态轮询间隔默认 `3000ms`（范围 `500-30000ms`），同步等待上限默认 `120` 秒（范围 `5-600` 秒）。超过同步等待上限时，返回的可能仍是「处理中」状态而不是失败；稍后可以让 Agent 查询该视频任务，取回最终结果。

## 生成媒体的保存与访问

- 图片或视频生成成功后，会保存到站点存储并关联到**当前会话或本次工作流运行**；离开会话后仍可在历史消息里看到。
- 生成结果只能由**有权访问该会话或该次工作流运行的人**下载。未登录、无权限或资源不存在时，界面会明确提示，不会回退到供应商的公开地址。
- 模型之后引用参考图或继续编辑时，使用平台保存的版本，而不是供应商的临时链接。
- 助手消息下方会汇总本轮生成的文件；开启**隐藏产物列表**只隐藏列表，不删除文件，也不改变下载权限。
- 预览无法显示时会区分原因：文件过大（默认 `20 MiB`）、未登录、无权限、类型不支持、解析失败。任何情况下都不要复制未经授权的内部下载地址。

## 安全与失败处理

- 图片/视频模型必须已授权给团队且启用。
- 参考图片和生成产物按会话/工作流权限访问控制，不应复制未经授权的内部下载地址。
- 文件过大、扩展名不允许或视觉能力不足会在发送前或后端返回明确错误。
- 视频供应商任务失败时查看工具结果和 Agent 日志中的供应商错误。
