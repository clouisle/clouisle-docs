附件为 Agent 提供用户资产；媒体生成让 Agent 调用已授权的图片或视频模型。两者都需要在 Agent 编排中显式启用。

<Callout type="info">
  媒体生成只包含**图片**和**视频**两类，不含音频生成或语音合成。开关打开后，平台会把 `generate_image` / `generate_video` 工具注入模型；关闭后模型看不到这些工具。
</Callout>

## 配置附件

在 Agent **编排** > **文件与图片**中启用附件。默认限制：

| 项目 | 默认值 | 可配置范围 |
| --- | --- | --- |
| 单文件大小 | `10MB` | `1KB-50MB` |
| 每条消息文件数 | `5` | `1-10` |
| 单文件解析内容 | `100,000` 字符 | `1,000-500,000` |
| 截断策略 | `end`（保留开头） | `end`、`start`、`middle` |

默认扩展名包括 PDF、Word、PowerPoint、Excel、TXT、Markdown、CSV、JSON 和 HTML。附件保存为 Asset，不会自动把全文塞进对话；Agent 按需调用解析能力。图片只有在聊天模型支持视觉时才直接进入模型。

## 配置生图

1. 开启**生图**并选择图片模型，或使用系统默认模型。
2. 默认尺寸为 `1024×1024`，宽高范围 `256-4096`。
3. 单次最多生成默认 `4` 张，可配置 `1-10`。
4. **允许参考图**默认开启；需要编辑或参考生成时保留此项。

## 配置生视频

1. 开启**生视频**并选择视频模型。
2. 默认时长 `5` 秒，单次最大默认 `10` 秒；两者范围均为 `1-30` 秒。
3. 默认宽高比 `16:9`。
4. 状态轮询间隔默认 `3000ms`（范围 `500-30000ms`），同步等待上限默认 `120` 秒（范围 `5-600` 秒）。超过同步等待上限后返回的可能是「仍在处理」的任务状态，而不是失败——稍后可由状态查询工具或 `GET /api/v1/agents/{agent_id}/media/video-status` 取回结果。

## 安全与失败处理

- 图片/视频模型必须已授权给团队且启用。
- 参考图片和生成产物受 Asset 访问控制，不应复制未经授权的内部下载地址。
- 文件过大、扩展名不允许或视觉能力不足会在发送前或后端返回明确错误。
- 视频供应商任务失败时查看工具结果和 Agent 日志中的供应商错误。
