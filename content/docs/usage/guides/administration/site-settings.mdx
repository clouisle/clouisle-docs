站点设置决定未登录页面、认证流程、资源限制和运行时策略。只有拥有站点设置查看权限的管理员或超级管理员才能看到对应设置分类。

本页只讲界面上的开关、字段与可见效果；精确默认值、完整字段清单与匹配规则见[站点设置参考](../../../reference/site-settings.mdx)。

## 访问系统设置

1. 以管理员身份登录。
2. 前往**管理后台** > **站点设置**（侧边栏「设置」分区）。
3. 从设置子导航选择分类。

设置分类：

- **常规**
- **安全**
- **通知渠道**
- **存储**
- **解析**
- **记忆**
- **集成**（登录身份源、邮件、Webhook、飞书、微信 iLink）

登录集成与内置服务配置分别授权：能改登录方式的人不一定能改邮件、Webhook 或消息集成，反之亦然。

## 常规设置

### 站点信息

配置站点名称、URL、描述、图标、默认语言和认证页布局：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 站点名称 | `Clouisle` | 显示在登录页、浏览器标题和通知中 |
| 站点 URL | 空 | 对外访问地址，用于生成回调与分享链接 |
| 站点描述 | 空 | 登录页与分享卡片的简介 |
| 站点图标 | 空 | 站点图标图片地址 |
| 默认语言 | 英文 | 新访客与未设置语言的用户看到的界面语言 |
| 认证页布局 | 居中 | 可选居中或左右分栏 |

修改后点击**保存更改**，公开页面立即使用新值。

### 主题与显示

配置默认主题模式、主色和品牌展示方式：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 主题模式 | 跟随系统 | 用户可在个人设置中覆盖 |
| 主题主色 | 空 | 留空使用内置默认配色 |
| 品牌展示 | 图标和名称 | 可选图标和名称、仅名称、仅图标、隐藏 |

还可自定义主色前景、背景、卡片、侧边栏、导航栏、强调色与图表色等颜色。颜色使用十六进制格式，例如 `#3b82f6`。

### 语言设置

默认语言决定未登录访客看到的语言。登录用户可在个人设置中切换界面语言，通知消息也会按接收者的语言生成。

### 法律与合规

配置 ICP 备案、服务条款和隐私政策：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| ICP 备案号 / 链接 | 空 | 填写后显示在页面底部 |
| 启用服务条款 | 关闭 | 开启并填写链接或正文后，登录页与注册页显示入口 |
| 服务条款链接 / 正文 | 空 | 没有链接时使用正文（支持 Markdown） |
| 启用隐私政策 | 关闭 | 同服务条款 |
| 隐私政策链接 / 正文 | 空 | 没有链接时使用正文 |
| 注册时要求接受条款 | 关闭 | 开启后注册必须勾选同意才能继续 |

## 安全设置

### 注册与审批

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 允许注册 | 开启 | 关闭后登录页不再显示注册入口，已有账号不受影响 |
| 新用户需管理员审批 | 开启 | 新注册账号处于待审批状态，审批前不能登录 |
| 邮箱验证 | 开启 | 注册后需完成邮箱验证才能使用 |
| 允许删除账户 | 开启 | 关闭后用户个人设置中不再提供删除账户入口 |
| 默认角色 | 观察者（Viewer） | 新用户自动获得的全局角色 |
| 默认团队 / 默认团队角色 | 空 / 成员 | 新用户自动加入的团队与角色 |

### 密码策略

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 最小长度 | `8` | 低于该长度的新密码被拒绝 |
| 需要大写字母 | 开启 | 至少一个 `A-Z` |
| 需要数字 | 开启 | 至少一个 `0-9` |
| 需要特殊字符 | 关闭 | 开启后要求标点等符号 |

密码策略只约束新设置的密码；修改策略不会让已有密码失效。

密码过期：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用密码过期 | 关闭 | 开启后密码到期需修改后才能继续使用 |
| 密码有效期 | `90` 天 | 到期时间 |
| 过期前提醒 | `7` 天 | 登录时提示的天数 |
| 记住密码历史 | `5` 次 | 不允许重复使用最近使用过的密码 |
| 密码最短使用天数 | `0` 天 | 大于 0 时短期内不能再次修改密码 |
| 首次登录强制修改密码 | 关闭 | 新账号或重置密码后的账号首次登录必须改密 |

### 会话与登录锁定

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 会话有效期 | `30` 天 | 超过后需要重新登录 |
| 仅允许单一会话 | 关闭 | 开启后同一账号新登录会踢出先前会话 |
| 最大登录尝试次数 | `5` | 连续失败达到该次数后锁定账户 |
| 锁定时长 | `15` 分钟 | 锁定期间即使密码正确也无法登录，页面提示账户已锁定 |

登录成功后失败计数清零。

没有「最大并发会话数」设置；并发会话由单一会话开关和会话有效期控制。

### 双因素认证

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 要求所有用户启用 TOTP | 关闭 | 开启后未绑定 TOTP 的用户登录时必须先完成绑定 |

管理员可在用户管理里查看每个用户是否已绑定，并可为其重置或停用 TOTP。

### 人机验证

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用人类验证 | 关闭 | 在登录页显示点击式验证 |

启用后，用户登录前需要完成一次点击验证；未完成或验证过期时登录被拒绝，页面提示需要重新完成验证。

<Callout type="warn" title="只有这一个验证码开关">
  安全页没有失败次数阈值、有效时长或难度配置。人机验证是降低自动化尝试的补充手段，不能替代登录锁定与 TOTP：暴力破解防护由最大登录尝试次数、锁定时长和 TOTP 承担。
</Callout>

### 网络访问限制：三个独立开关

安全页有三个相互独立的限制开关，均默认开启，可分别关闭而不影响其他策略：

| 开关 | 关闭后的效果 |
| --- | --- |
| 模型端点白名单 | 保存或测试模型时不再校验请求地址是否在名单内 |
| 出站网络白名单 | 自定义 HTTP 工具、HTTP 请求节点、网址导入和数据库连接可以访问内网地址 |
| 沙箱出口白名单 | 新启动的代码任务可以访问任意网络目标 |

关闭开关不会清空已保存的列表：列表仍可查看和编辑，重新开启并保存后立即恢复拦截。

#### 模型端点白名单

模型供应商的请求地址必须与名单中的一项完全匹配（协议、主机名和端口一致，路径忽略）。名单默认预置 OpenAI、Anthropic、DashScope、硅基流动等已知供应商以及本机 `http://localhost:11434`，最多保存 `200` 条。

保存或测试使用新地址的模型前：

1. 前往**设置** > **安全**。
2. 将请求地址添加到**模型端点白名单**，每行一个。
3. 只填写协议、主机名和非默认端口，例如 `https://gateway.example.com` 或 `http://ollama.internal:11434`。
4. 保存安全设置，然后再次保存或测试模型。

名单外的地址会让模型保存或连接测试失败，提示端点不在白名单内。移除一项会立即阻止后续的模型发现、连接测试和对话请求，无需重启服务。

远程地址优先使用 HTTPS。仅对可信私有网络中的地址使用 HTTP，因为 API 密钥和模型流量会以明文发送。

#### 出站网络白名单（内网访问豁免）

Clouisle 默认拒绝访问内网、回环和云元数据地址。以下操作在目标被拒绝时直接失败：

- 自定义 HTTP 工具
- 工作流中的 HTTP 请求节点
- 知识库的网址导入与网页预览
- 数据库工具的连接测试

需要调用内网 API、微服务或内网数据库时，在**设置** > **安全** > **出站网络白名单**中逐行添加被批准的目标：

| 写法 | 示例 | 匹配规则 |
| --- | --- | --- |
| 单个 IP | `192.168.1.50` | 精确匹配该地址 |
| CIDR 网段 | `10.10.0.0/16` | 解析到的地址属于该网段即放行 |
| 精确域名 | `api.internal.service` | 域名必须含 `.`，大小写不敏感 |
| 通配域名 | `*.corp.internal` | 匹配该后缀的所有子域以及基域本身 |

<Callout type="error" title="永远无法加入白名单的目标">
  保存时即被拒绝：`*`、`0.0.0.0`、`::`、`169.254.169.254`、`metadata.google.internal`，以及与云元数据、组播、未指定地址网段重叠的网段（含 `0.0.0.0/0`、`::/0`）。非法条目会直接报错，不会被静默忽略。
</Callout>

其他行为：

- 最多 `200` 条，重复项自动去重；不含 `.` 的主机名（如 `localhost`）不能作为条目，请改用 IP 或网段。
- 留空等于拦截全部内网目标。
- 校验在每次请求时重新读取设置，改完立即生效，不需要重启服务。
- 关闭开关后，私网、回环和云元数据目标都可访问；URL 与端口的格式校验仍然执行，但它不是安全边界。关闭期间这些能力可被用于探测内网或读取云实例凭据，优先收紧白名单而不是关闭开关。

#### 沙箱出口白名单

沙箱出口白名单是另一套策略，与上面的出站网络白名单互不生效：它只控制代码沙箱内程序的出网。

- 只接受精确主机名，逐条大小写不敏感匹配；通配符、IP 地址和网段一律拒绝。
- 默认 `pypi.org`、`files.pythonhosted.org`、`pypi.python.org`、`registry.npmjs.org`；最多 `200` 条，重复项自动去重。
- 空白名单阻断全部外网；只允许通过 HTTPS 的 `443` 端口访问名单内主机。
- 自定义包源必须使用 HTTPS，且主机名必须在名单内。
- 修改后对下一个任务生效，无需重启服务。
- 关闭开关只影响**新任务**；已运行任务保持原策略，文件系统隔离与资源限制仍然生效，列表保留可恢复。

<Callout type="warn">
  关闭沙箱出口白名单后，沙箱代码可以访问任意目标、协议与端口；节点的网络策略仍然约束实际可达范围。细节见[代码沙箱](../../concepts/sandbox.mdx)。
</Callout>

## 通知设置

### 邮件（SMTP）

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用 SMTP | 关闭 | 开启并填完服务器信息后才会外发邮件 |
| 服务器 / 端口 | 空 / `587` | 邮件服务器地址与端口 |
| 加密方式 | TLS | 可选无、SSL 或 TLS |
| 用户名 / 密码 | 空 | 邮件服务器凭据 |
| 发件人名称 / 地址 | `Clouisle` / 空 | 收件人看到的发件信息 |

配置步骤：前往**设置** > **集成** > **邮件**，填写服务器信息，点击**测试**确认能收到测试邮件，再点击**保存更改**。

未配置或未启用 SMTP 时，邮件通知**静默地只留在站内**：不会报错，也不会事后补发。

### 外部通知渠道

外部通知渠道只有三个：**邮件**、**Webhook** 与**飞书**，在**设置** > **集成**中配置。旧版的钉钉、企业微信与 Slack 渠道已移除；微信 iLink 属于消息集成（Agent 会话与知识采集），不是通知渠道。

| 渠道 | 配置内容 | 测试方式 |
| --- | --- | --- |
| 邮件 | 邮件服务器、发件人与凭据 | 集成页的**测试**按钮发送测试邮件 |
| Webhook | 地址、方法、请求头、正文模板与签名密钥 | 集成页的**测试**按钮 |
| 飞书 | 飞书集成卡片上的通知能力、机器人凭据与测试接收人 | 卡片上的测试消息按钮 |

飞书通知是飞书集成上的显式能力，启用集成本身不会自动发送通知。详见[飞书集成](../integrations/feishu.mdx)。

### 自动通知

**自动通知**（**设置** > **通知渠道**）控制哪些事件会创建通知，以及哪些外部渠道接收通知。详见[通知与外部渠道](./notifications.mdx)。

### 邮件模板

<Callout type="note">未实现。没有邮件模板编辑器；通知正文由内置的多语言文案生成。</Callout>

## 通知偏好

通知的投递渠道由管理员全局配置，没有每用户通知偏好。普通用户不能自定义接收哪些通知。

用户可以在通知中心查看通知、标记单条或全部为已读，并按类型、级别、范围、未读状态和关键词筛选。通知范围分为全局、团队和指定用户三种。

管理员在**设置** > **集成**配置外部渠道，在**设置** > **通知渠道**的**自动通知**里选择事件类型。渠道只有在全局配置中选中且已启用/配置时才发送；未配置时通知只停留在站内。通知量大时，建议只启用需要跟进的类型，避免噪音。

可用事件类型包括团队成员与角色变更、团队模型授权变更、账户启用/停用、管理员重置密码、新注册待审批、知识库文档处理结果、工作流失败、工作流等待审批、API Key 即将过期/已过期、异常登录、账户锁定和密码变更。

## 记忆设置

**记忆**页控制后台记忆提取：用户在对话中产生的内容会在冷却时间后被提取为记忆，或在待处理轮次达到阈值时立即提取。Agent 自身也必须启用记忆；任一开关关闭都不会产生提取。

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用后台提取 | 关闭 | 开启后才会在对话之外提取记忆 |
| 提取模型 | 空 | 留空时按顺序回退：Agent 分配的模型 → 系统默认对话模型 → 第一个可用对话模型 |
| 冷却时间 | `180` 秒 | `10-3600`，避免频繁提取 |
| 待处理轮次上限 | `6` | `1-50`，达到后立即提取 |

## 存储设置

### 文件存储

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 存储方式 | 本地 | 可选本地文件或 S3 兼容对象存储 |
| 知识库单文件上传上限 | `50MB` | `1-1024`，超过后上传被拒绝 |

### 对象存储（S3 兼容）

选择对象存储后需要填写：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 接入点 | 空 | 对象存储服务地址 |
| 存储桶 / 区域 | 空 | 目标桶与区域 |
| Access Key / Secret Key | 空 | 访问凭据，仅服务端保存 |
| 路径样式访问 | 开启 | 兼容不支持虚拟主机样式桶名的服务 |
| 使用 HTTPS | 开启 | 关闭时凭据与文件以明文传输 |

保存后上传与下载改用对象存储。

### 审计日志保留

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 审计日志保留天数 | `365` 天 | `30-3650`，超过期限的日志可归档 |
| 归档文件存储路径 | `/var/log/clouisle/audit_archives` | 归档 JSON 文件写入的本地路径 |

超过保留期限的日志由管理员手动触发归档，归档后从数据库中删除。详见[审计日志管理](./audit-logs.mdx)。

### 审计告警

设置页没有可用的审计告警功能：没有失败登录或批量删除的自动检测，也没有告警投递。需要安全告警时使用[自动通知](./notifications.mdx)中的安全事件与外部渠道。

## 解析设置

**解析**页（`/site-settings/parsing`）控制知识库文档里的图片是否交给视觉模型或 OCR 模型。能力默认关闭，且只影响**开启后新处理**的文档；已有文档不会自动重跑。

| 设置项 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 启用文档图片解析 | 关闭 | 开/关 | 关闭时图片不会发送给任何模型 |
| 视觉模型 | 空 | 已启用的图片输入模型 | 生成文字与视觉描述，必须对文档所属团队授权 |
| OCR 模型 | 空 | 已启用的图片输入模型 | 只提取文字；留空时复用视觉模型 |
| 获取外部图片 | 关闭 | 开/关 | 是否抓取文档中引用的外部图片 URL，仍受 SSRF 校验 |
| 每篇最大图片数 | `8` | `1-20` | 超过的图片不再分析 |
| 单图最大字节 | `10485760` | `1-52428800` | 超过则拒绝该图片 |
| 单图最大像素 | `20000000` | `1-40000000` | 超过则拒绝该图片 |
| 并发图片请求 | `2` | `1-8` | 单篇文档同时分析的最大请求数 |

- 开启时视觉模型和 OCR 模型至少要有一个；清空最后一个模型会保存失败。
- 图片会发送给模型供应商，产生费用并可能涉及数据出境；敏感文档请先确认组织政策。
- 处理结果包含 OCR 文字与事实描述，按页码、幻灯片或工作表位置写入分块；原图仍通过受保护接口展示。

完整的使用流程、支持来源与失败处理见[图片与扫描件解析](../knowledge/image-understanding.mdx)。

## 站点搜索

内置**网页搜索**工具由管理员在站点级统一配置，团队和 Agent 不再各自保存搜索密钥。

1. 前往管理台**能力**，找到内置的**网页搜索**工具。
2. 点击配置，打开站点搜索对话框。
3. 选择要启用的搜索引擎，填写对应凭据，设置默认引擎。
4. 点击**测试**确认能返回结果，再保存。

- 支持的引擎：Tavily、博查（Bocha）、SearXNG、DeepSeek。没有免密钥的搜索引擎，也不会在引擎失败时自动切换到其他供应商。
- 引擎可以在站点级逐个启用或停用；只有已启用的引擎会出现在工具配置中。
- 密钥保存后只显示为已配置，不会回显；留空表示保留原值，填写新值则替换。
- 关闭某个引擎后，使用该引擎的工具调用立即失败，需要在工具或 Agent 中改为其他已启用引擎。

引擎能力与限制见[内置工具](../tools/built-in.mdx)。

## 集成设置

登录身份源、邮件、Webhook、飞书与微信 iLink 在**设置** > **集成**统一管理。登录集成与内置服务分别授权：管登录的人负责 SSO 与登录方式，管内置服务的人负责邮件、Webhook、飞书、微信 iLink 以及消息投递记录。

### 全局 SSO 策略

在**设置** > **安全**的 SSO 分区配置：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用 SSO | 关闭 | 开启后登录页显示已启用的身份源按钮 |
| 允许密码登录 | 开启 | 关闭后只能通过 SSO 登录，务必先确认至少一个身份源可用 |
| 自动创建用户 | 开启 | 首次 SSO 登录时自动建立账号 |
| 需要审批 | 关闭 | 开启后自动创建的账号需管理员批准 |
| 通过邮箱匹配已有账号 | 开启 | 关闭后同一邮箱不会自动关联到已有账号 |

### 登录集成与飞书登录

登录集成（OAuth2/OIDC、SAML2、CAS）在集成页创建与管理。飞书登录是飞书集成上的可选能力，显式开启后登录页才会显示飞书按钮。详见[配置单点登录](./sso.mdx)。

### 飞书通讯录同步

在**设置** > **集成** > **飞书通讯录同步**中，用应用的 App ID 与 App Secret 把选中飞书部门的成员同步为 Clouisle 账号。同步是单向的：不同步回飞书，飞书侧离职或停用不会自动禁用本地账号。

1. 在飞书开发者后台创建自建应用，授予通讯录读取权限，并把需要同步的部门加入应用的数据范围（含成员）；读根部门需要全员范围。
2. 需要读取公司名、成员 ID、姓名和邮箱：`tenant:tenant:readonly`、`contact:user.employee_id:readonly`、`contact:user.base:readonly`、`contact:user.email:readonly`。
3. 在飞书集成卡片保存 App ID 与 App Secret，浏览部门树并保存同步范围。顶层**公司**节点即根部门，选中它等于选全员；其他部门只含自身及下属部门。
4. 点击**同步所选部门成员**，导入账号并创建或更新对应团队（含公司团队）。结果报告新建、更新、跳过的账号数与新建团队数。

新账号没有本地密码，使用默认角色与默认团队。已有本地账号不会仅按邮箱合并；重复同步按飞书成员 ID 匹配更新，邮箱冲突时跳过。

同步失败先看卡片上的飞书原始错误码：

| 飞书错误 | 含义 | 处理 |
| --- | --- | --- |
| `41050`（no user authority） | 成员超出应用通讯录数据范围 | 在飞书后台把该用户或部门加入数据范围后重试 |
| `40004`（no dept authority） | 部门超出数据范围 | 把该部门加入数据范围 |
| `40011` / `40012` | 分页参数非法 | 重试；重复出现时联系技术支持 |
| 提示缺少成员 ID | 没有成员 ID 读取权限 | 补上 `contact:user.employee_id:readonly` |
| 提示密钥无法解密 | 站点密钥已更换 | 重新保存 App Secret |

### 飞书 Agent 会话

飞书集成的 **Agent 会话**能力是显式开关，启用集成本身不会让机器人回答消息。开启能力、用户完成身份绑定并发布 Agent 后，用户可以在飞书中与该 Agent 对话。

接收消息有两种方式：

- **HTTP 回调**：把飞书事件订阅指向站点提供的回调地址，由飞书推送消息。
- **长连接**：在飞书 Agent 会话配置中选择长连接，由平台主动连接飞书，无需公网回调地址。

两种方式可以同时使用。个人设置里可以暂停接收新消息、排队和未发送的回复；暂停不会删除历史会话。

飞书发送产物的上限：图片 `10 MiB`、MP4 `30 MiB`、其他文件 `30 MiB`。详见[飞书集成](../integrations/feishu.mdx)。

### 飞书知识同步

飞书 Wiki 空间可以定时同步到指定知识库（仅超级管理员可配置）。选择来源空间与目标知识库后，设置同步间隔（`1-43200` 分钟），也可以随时点击立即同步。同步使用飞书集成中保存的应用凭据。

### 微信 iLink

微信 iLink 是单例集成，包含 **Agent 会话**与**知识采集**两个平台开关；个人还需要扫码授权，平台开关与个人授权相互独立。

- 绑定用途可选：无、知识采集、单个已发布 Agent，同一时间只有一个生效。
- 平台开关关闭时，暂停接收新消息、执行和回复；已有连接、凭据与待处理记录保留，重新开启后继续处理。
- 知识采集会把微信中的内容保存到知识库，并保留每次提交记录与支持的原件。

详见[微信 iLink 集成](../integrations/wechat.mdx)。

## 团队设置

团队用于分组用户和资源（Agent、工作流和知识库）。团队管理员可以管理**成员**与**团队基本信息**；**模型授权只能由超级管理员修改**。

### 访问团队管理

有两个入口，权限与能力不同：

| 入口 | 位置 | 谁能进入 | 能做什么 |
| --- | --- | --- | --- |
| 后台团队管理 | 团队切换器 → **管理全部团队（系统后台）** | 有团队管理查看权限的管理员或超级管理员 | 跨团队查看、创建、编辑、删除团队；**模型授权仅超级管理员可改** |
| 团队设置 | 团队切换器 → **管理当前团队** | 团队管理员或所有者 | 管理当前团队成员、基本信息与只读的模型授权 |

普通成员与观察者看不到**管理全部团队**入口，只能进入当前团队设置；且没有团队管理权限时，当前团队设置里也不能改成员。

### 团队信息

仅可编辑三个字段：

| 字段 | 说明 |
| --- | --- |
| **名称** | 团队显示名称（必填） |
| **描述** | 可选描述（最多 500 字符） |
| **头像 URL** | 可选头像图片地址 |

没有团队 slug 或自定义 URL，团队在界面上按名称引用。

### 模型授权

**团队模型授权只能由超级管理员操作。** 在**管理当前团队** > **模型授权**中，团队管理员和所有者看到的是只读视图：已授权模型、启用状态，以及「今日用量 / 限额」进度。限额由超级管理员分配，`无限制` 表示未设上限。

授权后的模型才会出现在团队的 Agent 与知识库模型选择器中。需要新增或调整授权时联系超级管理员。

### 成员管理

成员必须已有 Clouisle 账号；没有邮箱邀请或加入请求流程。

**添加成员**

1. 打开**管理全部团队**或**管理当前团队**并选择团队。
2. 打开**成员**标签。
3. 点击**添加成员**。
4. 选择现有用户和角色（管理员、成员或观察者；所有者不能在此分配）。
5. 确认。

**改变成员角色**：在成员列表中选择**改变角色**，选择新角色。只有团队所有者可以改变他人角色。

**移除成员**：在成员列表点击**移除**并确认。所有者不能被移除，也不能被其他成员移除。

**离开团队**：在**成员**中确认离开。所有者必须先转让所有权。

**转让所有权**：在**成员**中确认转让。前所有者变为管理员，新所有者获得完整控制权。

### 团队角色

角色固定为**所有者**、**管理员**、**成员**、**观察者**，没有每团队自定义角色。完整权限矩阵见[团队与成员](./teams.mdx)与[角色与权限](./roles-permissions.mdx)。

### 未实现的功能

以下团队级功能未实现：团队 slug / 自定义 URL、团队可见性与发现、邀请审批与邮箱域名限制、成员数量上限、团队资源配额、每团队密码/2FA/会话/IP 策略、团队 API 与速率限制、计费、数据保留/导出/删除、审计告警、自定义域名与品牌。

## 功能标志与其他设置

<Callout type="note">以下**不是**可配置的站点设置：</Callout>

- 功能标志（启用/禁用 Agent、工作流、知识库）
- 邮件模板
- 安全响应头、CORS、IP 白名单
- API 速率限制
- 维护模式
- 设置导出/导入与恢复默认值

## 关键默认值

新站点默认：站点名称 `Clouisle`、认证页居中、主题跟随系统、显示图标和名称、允许注册、需要审批、邮箱验证开启、人机验证关闭、SSO 关闭、允许密码登录、会话 `30` 天、密码最短 `8` 位、连续失败 `5` 次锁定 `15` 分钟、知识库单文件上传 `50MB`、审计日志保留 `365` 天。三个网络访问限制默认全部开启。

## 生效时机

页面设置保存后通常立即影响公开站点和后续请求。模型端点、存储和部署相关的配置由服务端读取，按部署方式重启相关服务后生效。保存后建议用隐身窗口验证登录页和注册页。

## 安全原则

- 敏感凭据（邮件密码、SSO 客户端密钥、对象存储密钥、模型 API Key）只保存在服务端，界面不回显。
- 三个网络访问限制默认开启；关闭前确认影响范围，关闭后列表仍保留，可随时恢复。
- 模型端点按完整地址匹配；清空白名单会阻止所有模型请求。
- 沙箱出口白名单只接受精确主机名，空白名单阻断全部外网；它与出站网络白名单互不替代。
- 改为仅 SSO 登录前，先确认至少一个身份源可用，并保留管理员恢复路径。
- 修改审计日志保留天数前，确认归档路径位于持久存储并有备份。

字段级默认值与完整清单见[站点设置参考](../../../reference/site-settings.mdx)。
