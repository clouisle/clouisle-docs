Clouisle 的认证流程可能包含密码、邮箱验证、管理员审批、人机验证、密码修改、TOTP 和 SSO。站点设置决定哪些步骤启用。

## 注册与邮箱验证

Clouisle 支持管理员开启后的自助注册。

### 自助注册

1. 前往登录页 `https://your-domain.com`，点击**注册**。
2. 填写注册表单：
   - **用户名**：唯一标识，最多 50 个字符
   - **邮箱**：有效的邮箱地址
   - **密码**：至少 8 个字符（详见[密码要求](#密码要求)）
   - **确认密码**：重新输入密码
3. 若显示人机验证，点击**点击验证您是人类**完成验证。
4. 点击**注册**提交。
5. 若启用邮箱验证，查收邮件中的验证码或链接完成验证。
6. 验证邮箱后即可登录。

<Callout type="info">
  首个注册用户自动提升为超级管理员。若启用管理员审批（`require_approval`），账户将进入待审核状态，审批前无法登录，管理员会收到全局通知。
</Callout>

<Callout type="note">
  Clouisle 没有邀请注册流程。用户通过自助注册、管理员创建（用户管理）或 SSO 自动创建（启用 `sso_auto_create_users` 时）产生。
</Callout>

## 登录方式

### 密码登录

1. 前往登录页，输入**用户名**或**邮箱**。
2. 输入**密码**。
3. 若显示人机验证，点击**点击验证您是人类**完成验证。
4. 点击**登录**。

### SSO 单点登录

若组织配置了 SSO，可使用企业凭据登录。

1. 前往登录页，点击 SSO 提供商按钮（如「使用 Google 继续」「使用 GitHub 继续」）。
2. 在 SSO 提供商处完成认证。
3. 自动跳转回 Clouisle 并登录。

**首次 SSO 登录：**

- 若邮箱匹配已有账户，SSO 连接会关联到该账户（默认启用邮箱匹配）
- 若无匹配账户，自动创建新账户（需启用 `sso_auto_create_users`）

**支持的 SSO 提供商：**

- OAuth2/OIDC（Google、GitHub、GitLab 等）
- SAML 2.0（Azure AD、Okta、OneLogin）
- CAS（高校系统）

详见 [SSO 配置](./sso.mdx)。

### 首次登录

首次成功登录后：

1. **欢迎界面**：显示欢迎消息
2. **资料设置**：完善个人资料（可选）
3. **团队分配**：可能被分配到默认团队（若配置）或由管理员添加
4. **仪表板访问**：
   - 普通用户看到平台界面
   - 管理员看到管理仪表板

## 登录保护

### 人机验证

登录和注册可能要求点击式验证码。验证码证明默认有效期 `300` 秒（5 分钟）；失败或过期后重新获取。

### 账户锁定

连续失败会触发账户锁定和速率限制：

- 默认 5 次失败后锁定
- 锁定持续 15 分钟（可配置）
- 反复锁定时联系管理员

### 登录异常检测

系统跟踪常用登录位置和设备，从新位置登录时发送安全通知。若看到异常告警，请查看通知。

## 密码管理

### 密码要求

| 要求 | 默认值 |
| --- | --- |
| **最小长度** | 8 个字符（可配置） |
| **大写字母** | 至少 1 个（A-Z） |
| **数字** | 至少 1 个（0-9） |
| **特殊字符** | 默认不要求 |
| **不可重复使用** | 不能重复最近 5 个密码（可配置） |

<Callout type="note">
  无字典/弱密码检查。
</Callout>

**有效密码示例：**
```
MySecure#Pass2026!
```

**弱密码示例：**
```
❌ 12345678       (无字母/大写)
❌ abcdefgh       (无数字)
❌ Pass123        (太短)
```

### 修改密码

1. 打开**个人资料设置**（个人资料菜单）→ **账户** 标签页
2. 找到**修改密码**区域
3. 填写表单：
   - **当前密码**：现有密码
   - **新密码**：新密码
   - **确认新密码**：重新输入新密码
4. 点击**修改密码**
5. 看到成功提示

输入时界面显示密码强度指示器（弱/一般/好/强）。

**强密码建议：**
- 混合使用多种字符类型
- 至少 12 个字符
- 避免个人信息（姓名、生日）
- 考虑使用密码管理器

### 重置忘记的密码

1. 前往登录页，点击**忘记密码？**链接
2. 输入**邮箱地址**
3. 点击**发送重置链接**
4. 查收邮件

邮件内容：
- 主题：「Password Reset Request - Clouisle」
- 含验证码的重置链接（有效期 **10 分钟**）
- 操作说明

5. 点击重置链接/输入验证码
6. 输入**新密码**并确认
7. 点击**重置密码**
8. 看到成功提示后用新密码登录

<Callout type="warn">
  重置链接/验证码 10 分钟后过期。重发限制为每 60 秒一次。
</Callout>

### 密码过期

若管理员启用密码过期策略：

- 密码在配置的天数后过期（如 90 天）
- 过期前收到提醒（默认提前 7 天开始警告）
- 过期后必须先修改密码才能登录

**修改过期密码：**

1. 尝试登录
2. 看到「密码过期」/「需要修改密码」提示
3. 先输入当前密码认证，再输入新密码
4. 用新密码登录

## TOTP 双因素认证

若组织启用 2FA，登录时需输入 TOTP 验证码。

### 设置 TOTP

1. 打开**个人资料设置** → **账户** 标签页，点击**启用双因素认证**（或按管理员强制向导操作）
2. 用身份验证器（Google Authenticator、Authy 等）扫描二维码，或手动输入密钥
3. 输入 6 位验证码确认
4. 下载或复制一次性备份码；每个备份码只能使用一次
5. 点击**启用**

  <img src="https://rustfs-endpoint.yhnotes.com/content/totp-setup-wizard.png" alt="TOTP 设置向导" />
  <figcaption>TOTP 设置向导</figcaption>
</figure>

### 使用 TOTP 登录

1. 输入用户名和密码
2. 输入身份验证器中的 6 位验证码
3. 点击**验证**

### 备份码

- 将备份码保存在安全的地方
- 无法访问身份验证器时使用备份码
- 每个备份码只能使用一次

## 会话管理

### 会话时长

- 会话持续到配置的**会话超时**（`session_timeout_days`，单位天，默认 30 天）
- 没有「记住我」选项，也没有基于非活动状态的注销

### 单会话模式

若管理员启用，每个用户仅允许一个活跃会话——在其他地方登录会使之前的会话失效。

### 注销

1. 点击右上角个人资料图标
2. 选择**注销**
3. 跳转到登录页

注销仅使当前会话/令牌失效。

## 账户安全

### 安全通知

您会收到以下通知：

- 密码修改成功
- 登录失败/账户锁定
- 从新位置/设备登录
- 密码过期提醒

**定期查看通知**以发现未授权访问。

### 账户被盗用

若怀疑未授权访问：

1. **立即修改密码**
2. **启用 2FA**（若尚未启用）
3. **查看登录通知**寻找可疑活动
4. **联系管理员**报告事件

### 管理员重置密码

管理员可从用户管理重置您的密码：

1. 管理员重置您的密码
2. 您收到含临时密码的邮件
3. 用临时密码登录
4. 修改密码

## 故障排除

### 无法访问登录页

1. 检查网络连接
2. 确认 URL 正确
3. 尝试其他浏览器
4. 清除浏览器缓存和 Cookie
5. 联系 IT 管理员

### 忘记密码

1. 点击登录页的**忘记密码？**
2. 输入邮箱地址
3. 查收重置链接邮件
4. 点击链接输入新密码
5. 用新密码登录

详见[密码管理](#密码管理)。

### 账户锁定

1. 等待自动解锁（默认 15 分钟）
2. 联系管理员立即解锁
3. 若忘记密码可使用密码重置

### 未收到验证邮件

1. 检查垃圾邮件/垃圾箱文件夹
2. 等待几分钟（邮件可能延迟）
3. 点击**重新发送验证邮件**
4. 确认邮箱地址正确
5. 若仍未收到联系管理员

### SSO 登录失败

1. 确认使用正确的 SSO 提供商
2. 检查 SSO 账户是否活跃
3. 清除浏览器 Cookie 后重试
4. 联系 SSO 管理员
5. 若可用尝试密码登录

详见 [SSO 配置](./sso.mdx)。

### 账户待审核

- 账户需要管理员审批
- 等待管理员激活账户
- 审批通过后会收到邮件
- 若等待过久联系管理员

### 会话过期

1. 重新登录
2. 联系管理员调整会话超时
3. 检查是否在另一台设备登录（单会话模式）

## 最佳实践

### 安全建议

**✅ 推荐：**
- 使用强且唯一的密码
- 启用双因素认证
- 使用共享电脑后注销
- 保持邮箱地址最新
- 定期查看登录通知
- 优先使用 SSO（更安全）

**❌ 避免：**
- 与他人共享密码
- 与其他服务使用相同密码
- 在公共电脑上保持登录
- 忽略登录异常通知

### 账户管理

**日常任务：**
- 按要求修改密码
- 查看登录通知发现可疑活动
- 保持个人资料信息最新
