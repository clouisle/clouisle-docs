Clouisle 的认证流程由站点设置决定：密码、邮箱验证、管理员审批、人机验证、强制改密、TOTP 与 SSO 可能同时生效。本页按使用顺序说明每个环节的默认值、失败结果与恢复路径；站点级开关的完整清单见[站点设置参考](../../../reference/site-settings.mdx)，登录接口的字段与错误码见 [认证 API](../../../api/auth.mdx)。

## 注册与邮箱验证

### 自助注册

1. 前往登录页 `https://your-domain.com`，点击**注册**。
2. 填写注册表单：

   | 字段 | 约束 |
   | --- | --- |
   | **用户名** | 必填、全局唯一、最多 `50` 字符 |
   | **邮箱** | 必填、全局唯一、需为合法邮箱地址 |
   | **密码** | 按站点密码策略校验（默认至少 `8` 位，见[密码要求](#密码要求)） |
   | **确认密码** | 与密码一致 |

3. 若开启人机验证，点击**点击验证您是真人**完成验证。
4. 若开启「注册需同意条款」，勾选用户协议与隐私政策。
5. 点击**注册**提交。

提交后的结果取决于站点设置：

| 站点设置 | 默认值 | 提交后行为 |
| --- | --- | --- |
| 允许注册 | 开启 | 关闭后注册入口提示注册已禁用 |
| 新账户需要审批 | 开启 | 账户进入**待审批**状态，管理员收到通知；审批前无法登录 |
| 邮箱验证 | 开启 | 须先验证邮箱才能登录 |
| 人机验证 | 关闭 | 开启时注册页显示点击式人机验证 |
| 注册需同意条款 | 关闭 | 开启时必须勾选条款 |
| 首次登录强制改密 | 关闭 | 开启时新用户首次登录被要求立即改密 |

<Callout type="info">
  站点中**第一个**注册的用户会绕过全部限制：直接激活、邮箱标记为已验证，并被赋予 **Super Admin** 角色。因此请先完成首个管理员的注册，再开放注册。
</Callout>

<Callout type="note">
  Clouisle 没有邀请注册流程。账户来自自助注册、管理员创建（[用户管理](./user-management.mdx)）或 SSO 自动创建（[SSO](./sso.mdx)）。
</Callout>

### 邮箱验证

- 验证邮件通过站点配置的邮件服务发送；**未配置邮件服务时发送失败**，页面会提示邮件服务未配置。
- 邮件包含 6 位验证码和验证链接，**有效期 10 分钟**。
- 重新发送的冷却时间为 **60 秒**（同一邮箱 + 用途），冷却中按钮显示剩余秒数。
- 验证码错误或链接过期都会拒绝验证。
- 未验证邮箱登录会被拦下，登录页直接切到验证步骤并自动重发一封验证码。

## 登录方式

### 密码登录

1. 前往登录页，输入**用户名或邮箱**（含 `@` 时按邮箱匹配，邮箱大小写不敏感；不含 `@` 时按用户名精确匹配）。
2. 输入**密码**。
3. 若开启人机验证，点击**点击验证您是真人**。
4. 点击**登录**。

登录时依次检查以下环节，任何一步失败都会中断后续流程：

1. **是否只允许 SSO 登录**：站点关闭密码登录后，密码登录被直接拒绝。
2. **人机验证**（开启时）。
3. **账户存在性**：账号不存在与密码错误返回同一句提示，不泄露账号是否存在。
4. **锁定状态**：仍在锁定期时提示账户已锁定，并给出剩余等待时间。
5. **本地密码存在性**：SSO 自动创建、没有本地密码的账户无法密码登录，同样提示用户名或密码错误。
6. **密码校验**：失败时提示用户名或密码错误，并给出剩余尝试次数；达到阈值转为锁定（见[账户锁定](#账户锁定)）。
7. **账户状态**：被停用提示账户已停用，待审批提示等待审批。
8. **TOTP**：已绑定 TOTP 时进入第二步验证，验证窗口 **5 分钟**。
9. **强制 TOTP**：站点要求全员 2FA 且用户未绑定时，跳转到绑定向导（窗口 **30 分钟**）。
10. **邮箱验证**（开启时；超级管理员豁免该检查）。
11. **密码过期/强制改密**：需要改密时仍会登录，但直接跳转到改密页面，并说明原因（已过期或被要求）。

登录成功后，失败计数与锁定状态会被清零，并刷新最后登录时间。

### SSO 单点登录

若组织配置了 SSO，可使用企业凭据登录。

1. 前往登录页，点击 SSO 提供商按钮（按钮文案取自集成的**Button Text**，如「使用 Google 继续」）。
2. 在身份提供商处完成认证。
3. 自动跳转回 Clouisle 并登录。

**首次 SSO 登录：**

- 开启「按邮箱匹配已有账户」（默认开启）且邮箱已存在时，SSO 连接会关联到该账户。
- 否则在允许自动创建时新建账户。新账户**没有本地密码**、邮箱视为已验证，并按配置进入待审批状态。

支持 OAuth2/OIDC、SAML 2.0、CAS 与飞书（飞书登录需管理员在飞书集成上显式开启才会显示按钮）。配置与排查详见 [SSO 配置](./sso.mdx)。

<Callout type="warn">
  关闭「允许密码登录」会把站点切换成仅 SSO。切换前请确认至少一个超级管理员已完成 SSO 绑定，否则可能无人能登录后台。
</Callout>

### 首次登录

首次成功登录后：

1. **欢迎界面**：显示欢迎消息。
2. **资料设置**：完善个人资料（可选）。
3. **团队分配**：可能被加入默认团队，角色为默认成员角色（默认 Member）。
4. **仪表板访问**：普通用户进入平台界面，管理员还会看到管理入口。

## 登录保护

### 人机验证

开关默认关闭，作用于**登录与注册**两个表单。它验证的是一次真实的点击 + 指针轨迹，而不是输入文字。

- 挑战与凭证保存 **5 分钟**，且**一次性**使用。
- 校验失败会提示验证无效或缺少验证，页面自动重新拉取一个新挑战。
- 登录页只在填写了用户名与密码后才加载验证码，因此打开页面时看不到它是正常的。

### 账户锁定

失败计数**按账户**累计，没有滚动时间窗：

- 默认连续 **5** 次失败即锁定。
- 锁定时长默认 **15 分钟**，锁定期间即使密码正确也会被拒。
- 未达阈值时，错误提示会给出剩余尝试次数。
- 计数**不会随时间自动清零**：要么登录成功，要么锁定到期后的下一次登录尝试（此时才归零）。
- 触发锁定时会向用户发送高优先级安全通知，内容含锁定分钟数。

<Callout type="warn">
  当前版本只按账户锁定，**没有按 IP 的登录限速**。
</Callout>

### 登录异常检测

系统会记录每个账户最近登录过的 IP 与设备（各最多 `10` 条，保留 30 天）：

- 出现过历史记录后，从**新 IP 或新设备**登录会触发高优先级安全通知，内容包含 IP、时间与设备信息。
- 首次登录（还没有历史记录）不会告警，避免每次新账号都误报。

## 密码管理

### 密码要求

| 要求 | 默认值 |
| --- | --- |
| **最小长度** | `8` 个字符（站点设置允许 `6`–`32`） |
| **大写字母** | 至少 1 个（A-Z） |
| **数字** | 至少 1 个（0-9） |
| **特殊字符** | 不要求 |
| **不可复用** | 不能与最近 `5` 个历史密码相同 |
| **最小保留期** | `0` 天（可立即再改） |

<Callout type="note">
  没有字典/弱密码检查，也没有密码强度指示器——校验结果以字段错误的形式返回。
</Callout>

**有效密码示例**（满足默认策略）：

```
MySecure#Pass2026!
```

**无效密码示例**：

```
❌ 12345678       （无大写字母）
❌ abcdefgh       （无数字）
❌ Pass123        （仅 7 位，短于默认 8 位）
```

### 修改密码

1. 打开**个人设置**（头像菜单）→ **账户安全** 标签页。
2. 找到**修改密码**区域，填写**当前密码**、**新密码**、**确认新密码**。
3. 点击**更新密码**。

结果处理：

- 当前密码错误会提示当前密码不正确。
- 未满足最小保留期会提示还需等待的天数。
- 不符合策略或命中历史密码时，逐个字段给出原因。
- 成功后刷新密码时间、按策略重算过期时间、清除强制改密标记，并发送高优先级安全通知。

**强密码建议**：混合多种字符类型、长度至少 12 位、避免个人信息、使用密码管理器。

### 重置忘记的密码

<Callout type="info">
  前置条件：站点必须已配置邮件服务。未配置时「忘记密码」会直接提示邮件服务未配置。
</Callout>

1. 前往登录页，点击**忘记密码？**。
2. 输入**邮箱地址**并点击**发送重置邮件**。为防枚举，无论邮箱是否存在都会返回成功。
3. 查收邮件，两种方式任选：
   - 点击邮件中的**重置链接**；
   - 或在页面上展开**或手动输入验证码**，填入邮件里的 6 位验证码。
4. 输入**新密码**并确认，点击**重置密码**。
5. 用新密码登录。

- 验证码/链接**有效期 10 分钟**；重发冷却 **60 秒**。
- 重置不要求当前密码（凭证本身就是授权），但同样校验密码策略与历史；成功后账户的失败计数与锁定状态会被清除。

### 密码过期

若管理员启用密码过期策略（默认关闭）：

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 密码过期策略 | 关闭 | 策略总开关 |
| 密码有效天数 | `90` | 密码有效期 |
| 到期前提醒窗口 | `7` | 提前多少天开始提醒 |
| 历史密码保留数量 | `5` | 不可复用的历史密码条数 |
| 最短改密间隔 | `0` | 两次改密之间的最短天数 |

**豁免对象**：SSO 账户、被单独标记豁免的用户以及超级管理员，均不参与过期与强制改密。

**时间线**：

- 每天 08:00 运行过期检查：距到期正好 **7 / 3 / 1** 天时发送提醒；已过期则发送过期通知并设置强制改密标记（同一用户每天最多一次提醒）。
- 登录时若已过期，会直接跳转到改密页面并说明原因。
- 个人设置的**账户安全**标签页会展示**密码过期时间**；已过期显示红色告警，剩余不足 7 天显示黄色预警。

## TOTP 双因素认证

### 设置 TOTP

1. 打开**个人设置** → **账户安全** 标签页，点击**启用双因素认证**。
2. 向导第一步说明双因素认证的作用；第二步展示二维码（issuer 为 `Clouisle`），用身份验证器（Google Authenticator、Authy、Microsoft Authenticator、1Password 等）扫码，或**手动输入密钥**。
3. 输入身份验证器当前的 6 位验证码完成校验（校验窗口为 ±1 个周期，即 ±30 秒）。
4. 保存一次性备份码：向导一次生成 **10 个**，格式 `XXXX-XXXX`，可下载（`clouisle-backup-codes.txt`）或复制。
5. 点击**完成**。

向导生成密钥时**尚未启用**，只有校验验证码通过后才真正启用。

  <figcaption>TOTP 设置向导</figcaption>
</figure>

<Callout type="warn">
  TOTP 密钥由平台加密保存。**更换平台的加密密钥会导致所有已绑定的 TOTP 密钥失效**，用户只能由管理员解绑后重新绑定。
</Callout>

### 使用 TOTP 登录

1. 输入用户名和密码，系统要求第二步验证（窗口 5 分钟）。
2. 输入身份验证器中的 6 位验证码（或点击**使用备份码**改输备份码）。
3. 点击**验证**。

验证失败会提示验证码无效；被限速时会提示剩余等待秒数。**限速规则**：自首次失败起 300 秒窗口内累计 **5** 次失败即锁定 **900 秒**（15 分钟）；成功验证后计数清零。

### 备份码

- 一次生成 10 个，格式 `XXXX-XXXX`，**每个只能使用一次**。
- 账户安全标签页显示剩余备份码数量。
- 点击**重新生成备份码**并输入当前 6 位验证码，即可作废旧码、生成新的一批（旧备份码立即失效）。

### 禁用 TOTP 与管理员操作

- **用户自行禁用**：点击**禁用双因素认证**，在确认框中**同时**提供账户密码与当前验证码（或备份码）——两项都必须通过校验。
- **管理员解绑**：超级管理员可直接为某用户关闭 TOTP，用于用户丢失验证器与备份码的场景（该操作目前没有界面入口，需通过管理接口完成，见 [Admin API](../../../api/admin.mdx)）。
- **强制全员 TOTP**：站点设置要求全员 2FA 时，未绑定用户登录会被重定向到绑定向导，不绑定则无法进入系统。

## 会话管理

### 会话时长

- 会话有效期取站点设置中的会话时长（默认 **30 天**），没有空闲超时、也没有「记住我」选项。
- 登录状态保存在当前浏览器中，关闭浏览器后仍有效，直到过期或退出。

### 单会话模式

开启单会话模式后，新登录会尝试让上一个会话失效。

<Callout type="warn" title="已知限制">
  单会话模式实际只在约 **5 秒**内拒绝旧会话，之后旧会话仍可继续使用到自身过期。不要把单会话模式当作踢出会话的安全手段。
</Callout>

### 注销

1. 点击右上角个人资料图标。
2. 选择**退出登录**。
3. 跳转到登录页。

注销会让当前会话尽快失效，但**已复制到别处的同一登录凭证在约 5 秒后仍会被接受**，直到自身过期。真正生效的阻断手段是修改密码（并配合单会话）、停用账户或缩短会话时长。

## 账户安全

### 安全通知

以下事件会产生站内安全通知：

| 事件 | 触发时机 | 级别 |
| --- | --- | --- |
| 密码已修改 | 修改密码成功 | 高 |
| 账户已锁定 | 连续失败触发锁定 | 高 |
| 异常登录 | 新 IP / 新设备登录 | 高 |
| 要求改密 | 管理员要求下次登录改密 | 高 |
| 密码被重置 | 管理员为用户设置了新密码 | 中 |
| 密码即将过期 / 已过期 | 到期前 7/3/1 天 / 已过期 | 中 |

**定期查看[通知中心](./notifications.mdx)** 是发现未授权访问最直接的方式。

### 账户被盗用

若怀疑未授权访问：

1. **立即修改密码**。注意这**不会**作废已登录的会话（见[注销](#注销)），也不会影响已有的 API 密钥。
2. **启用 TOTP**，或重新生成备份码。
3. **查看登录通知**中是否有陌生 IP / 设备，并在[API 密钥](./api-keys.mdx)列表中停用可疑密钥。
4. **联系管理员**停用账户——停用会在认证阶段立刻拒绝该账户的所有请求，是唯一能立即止血的手段。

### 管理员设置新密码

管理员在[用户管理](./user-management.mdx)中可以直接为用户设置新密码：

1. 管理员设置新密码（会按密码策略校验，但**不检查历史密码**）。
2. 系统向该用户发送密码已重置通知——**不会发送含临时密码的邮件**，新密码需要管理员通过安全渠道另行告知。
3. 用户用新密码登录后应立即自行修改。

配套的管理员操作：**强制修改密码**（用户下次登录必须改密）、**重置过期计时**、**免除过期策略**。

## 故障排除

### 无法访问登录页

1. 检查网络连接与 URL 是否正确。
2. 尝试其他浏览器并清除缓存与 Cookie。
3. 确认站点域名配置正确（SSO 回调也会用到）。
4. 联系管理员。

### 登录提示用户名或密码错误

账号不存在、密码错误、SSO 账户尝试密码登录，返回的都是同一句提示——这是反枚举设计，不代表系统故障。

1. 确认使用的是**用户名**（精确匹配）或**邮箱**（大小写不敏感）。
2. 若账户由 SSO 创建且从未设置本地密码，请改用 SSO 登录。
3. 提示中若带剩余尝试次数，注意别再次触发锁定。
4. 使用[忘记密码](#重置忘记的密码)重置。

### 账户已被锁定

1. 等待锁定自动到期（默认 15 分钟）后重新登录，此时失败计数会归零。
2. 管理员的激活/编辑操作**不会**解除锁定，也没有「立即解锁」按钮；若急需恢复访问，可走**忘记密码**重置流程——重置成功会同时清除失败计数与锁定状态。
3. 若反复被锁定，检查是否有旧脚本在重试错误密码。

### 未收到验证/重置邮件

1. 确认站点已配置邮件服务——未配置时发送会直接失败。
2. 检查垃圾邮件文件夹并等待几分钟。
3. 注意 60 秒重发冷却（页面会给出剩余秒数）。
4. 确认邮箱地址与账户上的邮箱一致。

### 未收到验证码导致的邮箱未验证

登录被拦下时会直接进入验证步骤并自动重发一封验证码；页面上的**重新发送**按钮受 60 秒冷却限制。

由于管理端没有「标记邮箱已验证」的开关，若用户始终收不到邮件，请先让管理员确认邮件服务配置；仍不可用时，可临时关闭邮箱验证让该用户先登录，待邮件通道恢复后再重新开启。

### TOTP 无法验证

1. 检查设备时间是否自动同步（±30 秒窗口）。
2. 被限速时按提示等待，最多 15 分钟。
3. 改用一次性**备份码**登录。
4. 备份码用尽时联系管理员解绑后重新绑定。

### 被要求修改密码

说明当前密码已被标记为必须修改（密码过期，或管理员强制）。在改密页面输入当前密码与新密码即可；改密成功后标记自动清除。

### SSO 登录失败

1. 确认使用的提供商与账户状态（停用/待审批会跳转到回调页并显示对应提示）。
2. 检查提供商配置与回调地址（详见 [SSO 配置](./sso.mdx)）。
3. 清除浏览器 Cookie 后重试，或改用密码登录（若站点允许）。

## 最佳实践

**✅ 推荐**

- 使用强而唯一的密码，并开启 TOTP。
- 使用密码管理器，不在多处复用同一密码。
- 保持邮箱地址有效，它是密码恢复的唯一通道。
- 处理安全通知，而不是清空通知列表。
- 优先用 SSO 登录，减少密码暴露面。

**❌ 避免**

- 与他人共享账户或密码。
- 在公共设备上保持登录（退出只影响本机会话，且见[注销](#注销)的限制）。
- 在共享设备上关闭 TOTP。
- 忽略异常登录告警。
