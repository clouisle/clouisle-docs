Administration pages display according to permissions. Super administrators can access all system administration features; team owners and administrators manage team resources; regular members only see the operations granted to them.

## Common scenarios

- **Onboarding**: create accounts, assign a default team and role, then grant model and tool access as needed.
- **Security audit**: review sign-ins, permission changes, and tool approvals to locate unusual activity.
- **External access**: configure SSO, API keys, and integrations so outside systems connect safely.
- **Cost control**: authorize models per team and set quotas so one team cannot exhaust the budget.
