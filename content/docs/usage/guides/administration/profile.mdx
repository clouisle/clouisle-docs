个人设置从右上角头像菜单打开，是一个包含 **Profile** 与 **Account** 两个标签的对话框——没有独立的 `/settings` 或 `/profile` 路由。时区、活跃会话管理、数据导出与隐私开关未实现（Roadmap）。

## Profile 标签

个人资料标签用于管理头像、用户名和邮箱。

| 字段 | 说明 |
| --- | --- |
| 头像 | 通过头像选择器上传头像 URL |
| 用户名 | 唯一用户名，最多 `50` 字符 |
| 邮箱 | 邮箱地址；修改可能要求邮箱验证 |

**修改邮箱**：若站点启用邮箱验证，修改邮箱需先点击**发送邮箱验证**，在新邮箱中收取 6 位验证码后保存。

## Account 标签

账户安全标签用于管理密码、TOTP 双因素认证和已连接账户。

### 修改密码

1. 打开**个人设置** → **Account** 标签。
2. 找到**修改密码**区域。
3. 输入当前密码、新密码并确认新密码。
4. 点击**修改密码**。

密码至少 `8` 个字符；管理员可提高最小长度并要求大写、数字或特殊字符。详见[登录与账户安全](./authentication.mdx)。

### TOTP 双因素认证

**启用 TOTP**：

1. 打开**个人设置** → **Account** 标签。
2. 找到**双因素认证**区域，点击**启用**。
3. 用身份验证器（Google Authenticator、Authy 等）扫描二维码，或手动输入密钥。
4. 输入 6 位验证码确认。
5. 下载或复制一次性备份码；每个备份码只能使用一次。
6. 点击**启用**。

**备份码**：妥善保存，无法使用身份验证器时可用备份码登录。需要时可重新生成。

**禁用 TOTP**：点击**禁用**，用密码或 TOTP 码确认。

### 已连接账户

查看已连接的 SSO 提供商及其上次登录时间。点击**断开**可解除关联。

<Callout type="note">
  用户侧没有「连接」操作——SSO 连接在登录时按邮箱自动关联（详见 [SSO 配置](./sso.mdx)）。
</Callout>

## 偏好设置

### 语言

通过导航栏的**语言切换器**切换界面语言（如 English / 中文），修改立即生效。

### 主题

通过导航栏的**主题切换器**切换主题：

- **浅色**
- **深色**
- **跟随系统**

## API Keys

API Key 在专属页面管理，不在个人设置中：

1. 打开用户菜单（头像）。
2. 选择 **API Keys**。
3. 或直接前往 `/app/api-keys`。

详见 [API Key 管理](./api-keys.mdx)。

## 删除账户

<Callout type="error" title="永久删除">
  删除账户不可恢复。删除前请确认已备份重要数据。
</Callout>

1. 打开**个人设置** → **Account** 标签。
2. 找到**删除账户**区域，点击**删除账户**。
3. 仔细阅读警告。
4. 输入密码确认。
5. 点击**永久删除**。

**删除范围**：个人资料与个人信息、会话与消息、API Key、团队成员身份（非所有者时）、上传的文件。

<Callout type="warn">
  没有临时停用或重新激活流程——删除是永久性的。如果是团队所有者，删除前需先转移所有权。
</Callout>

## 通知中心

通知中心集中显示全站、团队和个人通知，支持搜索、按未读筛选和标记已读。文档处理、工作流运行、Agent 发布、API Key 过期、安全事件等可触发自动通知。

通知偏好（邮件摘要、按类型切换、免打扰时段、推送通知）为全局配置，由管理员管理。详见[通知与外部渠道](./notifications.mdx)。

## 故障排除

### 无法保存个人资料

1. 检查网络连接。
2. 确认所有必填字段已填写。
3. 检查字段验证错误提示。
4. 刷新页面后重试。

### 邮箱验证未收到

1. 点击**发送邮箱验证**获取验证码。
2. 检查收件箱（含垃圾邮件/垃圾箱文件夹）。
3. 输入 6 位验证码。
4. 若未收到，等待一分钟后重新发送。

### TOTP 无法启用或丢失访问

1. 使用备份码登录。
2. 联系管理员禁用 TOTP。
3. 确认身份验证器时间已同步。
4. 尝试其他身份验证器应用。

## 最佳实践

**推荐**：

- 使用强唯一密码并开启 TOTP。
- 保持邮箱地址最新。
- 定期检查已连接的 SSO 账户。
- 及时标记已读通知，安全告警立即处理。

**避免**：

- 共享密码。
- 在共享设备上禁用 TOTP。
- 忽略安全告警。
- 让通知堆积。
