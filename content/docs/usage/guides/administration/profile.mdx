个人设置从右上角头像菜单打开，是一个包含 **Profile** 与 **Account** 两个标签的对话框——没有独立的 `/settings` 或 `/profile` 路由。时区、活跃会话管理、数据导出与隐私开关未实现（Roadmap）。

## Profile 标签

个人资料标签用于管理头像、用户名和邮箱。

| 字段 | 说明 |
| --- | --- |
| 头像 | 通过头像选择器上传头像 URL |
| 用户名 | 唯一用户名，最多 `50` 字符 |
| 邮箱 | 邮箱地址；修改可能要求邮箱验证 |

**修改邮箱**：若站点启用邮箱验证，修改邮箱需先点击**发送邮箱验证**，在新邮箱中收取 6 位验证码后保存。

## Account 标签

账户安全标签用于管理密码、TOTP 双因素认证和已连接账户。

### 修改密码

1. 打开**个人设置** → **Account** 标签。
2. 找到**修改密码**区域。
3. 输入当前密码、新密码并确认新密码。
4. 点击**修改密码**。

密码至少 `8` 个字符；管理员可提高最小长度并要求大写、数字或特殊字符。详见[登录与账户安全](./authentication.mdx)。

### TOTP 双因素认证

**启用 TOTP**：

1. 打开**个人设置** → **账户安全（Account）** 标签。
2. 找到**双因素认证**区域，点击**启用双因素认证**。
3. 弹出 TOTP 设置向导：
   - 用身份验证器（如 Google Authenticator、Authy、1Password）扫描二维码，或手动输入密钥。
   - 输入验证器生成的当前 6 位动态验证码确认。
   - 生成一次性安全备份码（Recovery Codes）。下载或复制保存；每个备份码只能使用一次。
4. 点击**完成启用**。

**查看状态与管理**：
- 启用后卡片显示**双因素认证已启用**、启用具体时间与**剩余备份码数量**（`剩余 {count} 个备份码`）。
- 点击**重新生成备份码**输入当前 6 位验证码，即可批量生成新的一批备份码（旧备份码立即全部作废）。

**禁用 TOTP**：
1. 点击**禁用双因素认证**。
2. 在确认对话框中选择验证方式：输入账户密码确认，或输入当前 6 位 TOTP 验证码。
3. 确认后完成注销解绑，状态恢复为未启用。

### 关联账号（SSO）

在**关联账号**区域查看已连接的单点登录提供商、绑定邮箱及最后登录时间。

- 若用户已设置登录密码或绑定了其他认证方式，可点击**解除关联**解绑该 SSO 提供商。
- 系统具备防自锁保护：**无法解除唯一的认证方式**（当账户未设置独立密码且仅剩该 SSO 关联时，系统禁止解绑）。

<Callout type="note">
  用户侧没有主动创建连接的按钮——SSO 连接在登录时按邮箱自动关联（详见 [SSO 配置](./sso.mdx)）。
</Callout>

## 偏好设置

### 语言

通过导航栏的**语言切换器**切换界面语言（如 English / 中文），修改立即生效。

### 主题

通过导航栏的**主题切换器**切换主题：

- **浅色**
- **深色**
- **跟随系统**

## API Keys

API Key 在专属页面管理，不在个人设置中：

1. 打开用户菜单（头像）。
2. 选择 **API Keys**。
3. 或直接前往 `/app/api-keys`。

详见 [API Key 管理](./api-keys.mdx)。

## 我的记忆

头像菜单中的**我的记忆**（`/app/memories`）打开个人记忆图谱页，标题为**我的记忆**、副标题为「探索 AI 对你的了解」。在这里可以：

- 按关键词搜索记忆实体，或按实体类型筛选。
- 在**网格布局 / 层次布局 / 径向布局**之间切换图谱视图，支持放大、缩小与适应视图。
- 查看实体的属性、出向关系与入向关系、访问次数与最后访问时间。
- 使用**框选模式**批量选择并删除实体（**删除选中**），或编辑单个实体的描述。
- 尚未积累记忆时显示**还没有记忆**空状态，可直接点击**开始对话**去创建。

记忆的提取规则、实体与关系类型、检索与时间衰减算法详见 [记忆与上下文](../agent/memory.mdx)。

## 删除账户

<Callout type="error" title="永久删除">
  删除账户不可恢复。删除前请确认已备份重要数据。
</Callout>

1. 打开**个人设置** → **Account** 标签。
2. 找到**删除账户**区域，点击**删除账户**。
3. 仔细阅读警告。
4. 输入密码确认。
5. 点击**永久删除**。

**删除范围**：个人资料与个人信息、会话与消息、API Key、团队成员身份（非所有者时）、上传的文件。

<Callout type="warn">
  没有临时停用或重新激活流程——删除是永久性的。如果是团队所有者，删除前需先转移所有权。
</Callout>

## 通知中心

通知中心集中显示全站、团队和个人通知，支持搜索、按未读筛选和标记已读。文档处理、工作流运行、Agent 发布、API Key 过期、安全事件等可触发自动通知。

通知偏好（邮件摘要、按类型切换、免打扰时段、推送通知）为全局配置，由管理员管理。详见[通知与外部渠道](./notifications.mdx)。

## 故障排除

### 无法保存个人资料

1. 检查网络连接。
2. 确认所有必填字段已填写。
3. 检查字段验证错误提示。
4. 刷新页面后重试。

### 邮箱验证未收到

1. 点击**发送邮箱验证**获取验证码。
2. 检查收件箱（含垃圾邮件/垃圾箱文件夹）。
3. 输入 6 位验证码。
4. 若未收到，等待一分钟后重新发送。

### TOTP 无法启用或丢失访问

1. 使用备份码登录。
2. 联系管理员禁用 TOTP。
3. 确认身份验证器时间已同步。
4. 尝试其他身份验证器应用。

## 最佳实践

**推荐**：

- 使用强唯一密码并开启 TOTP。
- 保持邮箱地址最新。
- 定期检查已连接的 SSO 账户。
- 及时标记已读通知，安全告警立即处理。

**避免**：

- 共享密码。
- 在共享设备上禁用 TOTP。
- 忽略安全告警。
- 让通知堆积。
