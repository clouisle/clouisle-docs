个人设置从右上角头像菜单打开，是一个包含 **Profile** 与 **Account** 两个标签的对话框——没有独立的 `/settings` 或 `/profile` 路由。时区、活跃会话管理、数据导出与隐私开关未实现（Roadmap）。

## Profile 标签

| 字段 | 说明 |
| --- | --- |
| 头像 | 通过头像选择器上传头像 URL |
| 用户名 | 唯一用户名，最多 `50` 字符 |
| 邮箱 | 邮箱地址；修改可能要求邮箱验证 |

## Account 标签

- **密码**：修改密码（需验证当前密码）。
- **2FA（TOTP）**：绑定或解绑 TOTP 验证器。
- **已连接账户**：查看和管理 SSO 连接。
- **删除账户**：删除当前账户（如有站点级约束会拒绝）。
