个人设置是一个**对话框**，不是独立页面：从右上角头像菜单选择**个人资料**打开，标题为**设置**，内含**个人资料**、**账户安全**、**微信**与**飞书**四个标签页。微信与飞书标签用于个人渠道设置（微信知识采集授权、飞书通知与 Agent 会话个人设置），详见[消息集成](../integrations/index.mdx)。时区、活跃会话列表、数据导出与隐私开关均未实现（**Roadmap**）。

本页只讲界面操作与可见结果；资料、密码与账户接口的字段和错误码见 [Users API](../../../api/users.mdx)。

## 个人资料标签

用于维护头像、用户名与邮箱。

| 字段 | 说明 |
| --- | --- |
| **头像** | 点击上传，推荐 `200x200` 像素，支持 JPG / PNG / GIF |
| **用户名** | 全局唯一，最多 `50` 字符；重名会提示用户名已被占用 |
| **邮箱** | 全局唯一；与他人重复会提示邮箱已被占用 |

**修改邮箱**：仅当站点开启邮箱验证且邮箱确实发生变化时，才需要验证新地址。

1. 修改邮箱输入框内容后，下方出现验证区域。
2. 点击**发送验证码**，新邮箱会收到 6 位验证码。
3. 输入 6 位验证码，再点击**保存更改**。

- 重发冷却 `60` 秒，冷却中按钮显示剩余秒数。
- 验证码错误或过期会拒绝保存，并提示验证码无效。
- 保存成功后该邮箱直接标记为已验证，并写入审计日志。
- 只改用户名或头像时不需要验证码；没有任何改动时点击保存会提示“没有需要保存的更改”。

## 账户安全标签

标签页内自上而下为：**关联账号**（仅在有 SSO 连接时出现）→ **双因素认证** → 密码 → **危险操作**。

### 关联账号（SSO）

卡片列出已连接的 SSO 提供商，显示提供商图标、显示名称与**最后登录**时间。

- 点击**解除关联**并在确认框中确认即可解绑该提供商。
- **防自锁保护**：若账户没有本地密码且只剩这一条 SSO 连接，系统会拒绝解绑并提示不能断开唯一的登录方式。
- **绑定飞书**：卡片下方会列出可关联的飞书登录（管理员启用飞书用户登录后出现），点击**绑定飞书**跳转飞书授权，确认后把飞书身份关联到当前账号，之后可直接用飞书登录。
- 其他登录提供商不会显示绑定按钮：它们的连接在登录时按邮箱自动建立，详见 [SSO 配置](./sso.mdx)。

### 双因素认证（TOTP）

**未启用时**：卡片显示**双因素认证未启用**，点击**启用双因素认证**打开向导：

1. 第一步说明双因素认证的作用。
2. 第二步展示二维码（issuer 为 `Clouisle`），用身份验证器扫码或**手动输入密钥**。
3. 第三步输入当前的 6 位验证码完成校验。
4. 第四步保存一次性备份码——一次生成 **10 个**，格式 `XXXX-XXXX`，可下载或一键复制。
5. 最后一步确认完成。

<Callout type="info">
  向导生成密钥时**尚未启用**双因素认证，只有验证码校验通过后才真正启用。
</Callout>

**已启用时**：卡片显示**双因素认证已启用**、**启用于**时间与剩余备份码数量，并提供两个操作：

- **重新生成备份码**：输入当前 6 位验证码后生成新的一批 10 个，**旧备份码立即全部失效**；新码可在对话框内下载或复制。
- **禁用双因素认证**：确认框需要**同时**提供账户密码与当前验证码（也可切换到备份码输入）。成功后密钥与备份码一并清空，状态回到未启用。

验证码错误、限速与丢失访问的处理见[登录与账户安全](./authentication.mdx)。

### 密码

卡片标题取决于账户类型：

- **修改密码**（账户有本地密码）：需要填写**当前密码**、**新密码**、**确认新密码**，点击**更新密码**。
- **设置密码**（账户通过 SSO 创建、尚无本地密码）：只需填写新密码与确认密码。

**密码状态区块**只对本地账户加载：

- 已过期显示红色告警；剩余不足 7 天显示黄色预警；同时展示**密码过期时间**。
- 被标记为豁免过期策略的用户不显示该区块。

常见结果：

| 情况 | 结果 |
| --- | --- |
| 当前密码错误 | 提示当前密码不正确 |
| 不符合密码策略或复用了历史密码 | 逐条列出原因 |
| 未满足密码最短保留期 | 提示还需等待的天数 |

成功后会刷新密码时间、重算过期时间、清除强制改密标记，并发送密码已修改通知。

<Callout type="warn" title="已知限制：SSO 账户的「设置密码」当前不生效">
  **设置密码**目前不会真正保存：界面会提示成功，但密码并未写入（**Roadmap**）。需要为 SSO 账户设置首个本地密码时，请由管理员在[用户管理](./user-management.mdx)中直接设置。
</Callout>

### 删除账户

<Callout type="error" title="永久删除">
  删除账户不可恢复，且没有临时停用或重新激活流程。删除前请确认重要数据已备份或转移。
</Callout>

入口只在站点开启账户自助删除时出现（关闭时会提示账户删除已禁用）。

1. 在**危险操作**卡片点击**删除账户**。
2. 阅读确认框中的警告。
3. 输入**当前密码**。
4. 点击**删除账户**。

限制与影响：

- **超级管理员不能删除自己**。
- 校验的是本地密码，因此**没有本地密码的 SSO 账户无法自助删除**。这类账户需要由管理员处理（管理员同样不能删除超级管理员）。
- 级联删除：会话与消息、Agent 运行记录、个人记忆、API 密钥、密码历史、SSO 连接、团队成员关系（含 Owner 角色）、用户通知、角色分配。
- **不会删除**：上传的文件，以及 Agent / 工作流 / 知识库 / 工具 / 技能等资源——这些资源的创建者会被置空，资源仍留在团队中；团队本身也会保留，只是失去所有者，**系统不会阻止所有者删除账户，也不会自动转移所有权**，请先手动转移。

删除成功后本地登录状态被清除并跳转到登录页。

## 外观与语言

外观与语言不在个人设置对话框里，而在导航栏的**主题设置**面板中，修改立即生效：

| 区块 | 选项 |
| --- | --- |
| **主题** | 跟随系统 / 浅色 / 深色 |
| **侧边栏** | 默认 / 嵌入式 / 浮动式 |
| **布局** | 默认 / 紧凑 / 全宽 |
| **导航布局** | 默认 / 居中 / 极简 |
| **方向** | 从左到右 / 从右到左 |
| **语言** | English / 中文 |

- 主题、侧边栏、布局、导航布局与方向保存在当前浏览器，只影响这台设备。
- **语言**会写入浏览器偏好（有效期一年）；已登录时会同步到账户，因此换浏览器后依然生效。
- 面板底部的**重置**按钮可恢复默认外观（不改变语言与账户信息）。
- 登录页与注册页的角落另有语言切换器，无需登录即可切换。

## API 密钥

API 密钥在独立页面管理，不在个人设置中：

1. 打开头像菜单，选择 **API 密钥**（仅当账户具备 API 密钥查看权限时显示）。
2. 或直接访问 `/app/api-keys`。

创建、绑定、停用与限制说明见 [API 密钥](./api-keys.mdx)。

## 我的记忆

头像菜单中的**我的记忆**（`/app/memories`）打开个人记忆图谱页，标题**我的记忆**、副标题「探索 AI 对你的了解」。在这里可以：

- 按关键词搜索记忆实体，或按实体类型筛选。
- 在**网格布局 / 层次布局 / 径向布局**之间切换图谱视图，支持放大、缩小与适应视图。
- 查看实体的属性、出向关系与入向关系、访问次数与最后访问时间。
- 使用**框选模式**批量选择实体并**删除选中**，或编辑单个实体的描述、删除单条实体/关系。
- 尚未积累记忆时显示**还没有记忆**空状态，可直接点击**开始对话**去创建。

记忆的提取规则、实体与关系类型、检索与时间衰减说明详见[记忆与上下文](../agent/memory.mdx)。

## 通知中心

通知中心（`/app/notifications`）集中显示全站、团队与个人通知，支持搜索、按未读筛选与标记已读；头像菜单上的铃铛展示未读数量（超过 99 显示 `99+`）。

可触发自动通知的事件包括：文档处理、工作流运行、Agent 发布、API 密钥即将过期/已过期（剩余 7 / 3 / 1 天提醒）、密码过期、账户锁定与新设备登录等安全事件。

<Callout type="warn">
  当前版本**没有面向用户的按类型开关、邮件摘要、免打扰时段或推送偏好**——通知渠道与全局开关由管理员在站点设置中管理。浏览器桌面通知的授权由用户在本机授予。
</Callout>

详见[通知与外部渠道](./notifications.mdx)。

## 故障排除

### 无法保存个人资料

1. 检查网络连接，确认必填字段已填写。
2. 查看字段下方的错误提示（如用户名已被占用、邮箱已被占用）。
3. 修改邮箱时确认已发送并填写 6 位验证码。
4. 刷新页面后重试。

### 收不到邮箱验证码

1. 点击**发送验证码**后检查收件箱与垃圾邮件文件夹。
2. 注意 60 秒重发冷却，冷却结束后再试。
3. 确认输入的是**新邮箱**地址，验证码只发往新地址。
4. 若站点未配置邮件服务，发送会直接失败，需要管理员先配置邮件。

### TOTP 无法启用或丢失访问

1. 确认设备时间已自动同步（校验窗口 ±30 秒）。
2. 试用一次性**备份码**登录。
3. 备份码用尽时联系管理员解绑 TOTP 后重新绑定。
4. 禁用 TOTP 需要密码 + 验证码两项，缺一不可。

### 无法删除账户

1. 若按钮不存在，说明站点关闭了账户自助删除。
2. 超级管理员账户无法自我删除。
3. SSO 自动创建、没有本地密码的账户无法自助删除，请联系管理员。

### 语言切换后界面未变

1. 等待页面刷新完成（切换会触发一次刷新）。
2. 清除站点 Cookie 后重新登录，让语言偏好重新同步。
3. 确认浏览器未通过翻译扩展覆盖界面文案。

## 最佳实践

**推荐**

- 使用强唯一密码并开启 TOTP，备份码离线保存。
- 保持邮箱地址最新——它是密码恢复与通知的唯一通道。
- 定期检查已连接的 SSO 账户与最近登录通知。
- 删除账户前先转移团队所有权、导出需要保留的内容。

**避免**

- 在共享设备上关闭 TOTP。
- 忽略安全类通知。
- 依赖个人设置里的“设置密码”为 SSO 账户建立首个密码（见上文已知限制）。
