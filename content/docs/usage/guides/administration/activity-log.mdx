**活动日志**是管理台的全局视图：它不按单个 Agent 或单个工作流分组，而是把平台上的对话和工作流运行放在同一页。客服要回看某位用户问过什么、运维要确认昨晚的定时任务是否成功、审计要清理一条含敏感信息的对话，都从这里开始。

## 打开活动日志

1. 以管理员身份登录。
2. 在管理台侧边栏选择 **活动日志**（`/activities`）。
3. 顶部四张统计卡显示总对话数、总工作流运行数、今日活动与活跃用户。

页面有两个标签：

- **对话**：平台内所有 Agent 的会话记录。
- **工作流运行**：平台内所有工作流的运行记录。

<Callout type="info">
  可见范围由权限决定。查看对话需要管理台的对话查看权限；查看工作流运行需要工作流查看权限。只有查看权限时看不到删除入口。
</Callout>

## 对话标签

### 筛选与搜索

| 控件 | 作用 |
| --- | --- |
| **搜索对话** | 按会话标题或首条消息内容搜索，输入后自动刷新 |
| **团队** | 按一个或多个团队筛选 |
| **Agent** | 按一个或多个 Agent 筛选 |
| **用户** | 按会话所属用户筛选，支持搜索用户 |

筛选条件会保留在地址栏，刷新页面后仍然生效。

### 表格与详情

| 列 | 说明 |
| --- | --- |
| **活动日志** | 会话标题（通常是首条用户消息），旁边有会话图标 |
| **对话 ID** | 会话 UUID 的前 8 位，点击可复制完整 ID |
| **Agent** | 产生会话的 Agent |
| **用户** | 会话所属用户 |
| **消息数** | 会话内消息总数 |
| **更新时间** | 最后一次消息时间 |

点击任意一行或行尾的 **查看详情** 打开右侧抽屉，显示会话的完整消息、变量、模型与时间信息。抽屉只读；需要修改或删除时回到表格。

### 删除

- 单条删除：行尾菜单选择**删除**，确认后移除会话及其消息。
- 批量删除：勾选多行，点击顶部的**删除所选**，一次移除多条。
- 删除不可恢复。需要保留证据时，先导出或截图。

<Callout type="warn">
  删除对话会同时移除该会话的消息记录，但不会删除 Agent、知识库或工作流本身。由外部渠道（飞书、微信）产生的会话也在这里统一管理。
</Callout>

## 工作流运行标签

### 筛选与搜索

| 控件 | 作用 |
| --- | --- |
| **搜索** | 按运行 ID 或工作流名称搜索 |
| **工作流** | 按工作流筛选 |
| **状态** | 成功、失败、运行中、等待中、等待输入、已取消、超时 |
| **触发类型** | 手动、Webhook、定时 |
| **触发用户** | 按发起运行的用户筛选 |
| **仅调试运行** | 只显示调试模式产生的运行 |
| **仅无标题** | 只显示没有标题的运行 |

### 表格与详情

| 列 | 说明 |
| --- | --- |
| **运行 ID** | 运行 UUID 的前 8 位 |
| **工作流** | 所属工作流 |
| **状态** | 带颜色和图标的状态徽章 |
| **触发类型** | 手动 / Webhook / 定时 |
| **触发用户** | 手动运行的发起人；定时或 Webhook 可能为空 |
| **持续时间** | 从开始到结束的耗时 |
| **创建时间** | 运行创建时间 |

点击行尾的**查看详情**打开运行详情抽屉：基本信息、执行统计、输入/输出、节点执行列表与错误信息。节点列表会标出失败节点和耗时；调试运行会带**调试**标记。

### 删除

勾选一条或多条运行，点击**删除所选**。删除只移除运行记录，不回滚工作流已经产生的外部副作用。

## 与其他入口的区别

| 入口 | 位置 | 范围 | 适合 |
| --- | --- | --- | --- |
| **活动日志** | 管理台 `/activities` | 全平台所有用户 | 审计、客服回看、清理记录 |
| **Agent 日志** | Agent 侧边栏 **日志** | 当前 Agent 下**你自己**的会话 | 调试某个 Agent |
| **工作流日志** | 工作流菜单 **日志** | 当前工作流的运行历史 | 调试某个工作流 |
| **监控 / 可观测性** | Agent **监控**、管理台 **可观测性** | 聚合指标与运行健康度 | 看趋势、延迟、错误率 |

## 常见问题

### 为什么看不到某个对话？

先确认你拥有管理台对话查看权限，并检查团队、Agent、用户筛选是否把目标排除在外。来自共享团队的资源仍会显示，但只读共享不会改变这里的可见范围。

### 删除后还能恢复吗？

不能。对话和运行记录都是硬删除，没有回收站。需要留档时请先导出或保存必要信息。

### 定时任务没有触发用户？

正常。定时和 Webhook 运行没有登录用户，触发用户列会留空；用触发类型和运行时间定位。
