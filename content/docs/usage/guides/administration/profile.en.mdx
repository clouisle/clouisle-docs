Profile settings open from the avatar menu in the top-right corner as a dialog with **Profile** and **Account** tabs — there is no dedicated `/settings` or `/profile` route. Timezones, active-session management, data export, and privacy toggles are not implemented (Roadmap).

## Profile Tab

The Profile tab manages your avatar, username, and email.

| Field | Description |
| --- | --- |
| Avatar | Profile picture URL (upload via the avatar picker) |
| Username | Unique username, max `50` characters |
| Email | Email address; changing it may require email verification |

**Changing email**: If email verification is enabled, click **Send Email Verification** first, then enter the 6-digit code sent to the new address before saving.

## Account Tab

The Account tab manages password, TOTP two-factor authentication, and connected accounts.

### Changing Password

1. Open **Profile Settings** → **Account** tab.
2. Find the **Change Password** section.
3. Enter your current password, new password, and confirm the new password.
4. Click **Change Password**.

Passwords must be at least `8` characters; administrators can require a longer minimum length and mandate uppercase, digits, or special characters. See [Login & Account Security](./authentication.mdx) for details.

### TOTP Two-Factor Authentication

**Enabling TOTP**:

1. Open **Profile Settings** → **Account** tab.
2. In the **Two-Factor Authentication** section, select **Enable Two-Factor Authentication**.
3. The TOTP setup wizard opens:
   - Scan the QR code with an authenticator app (Google Authenticator, Authy, 1Password), or enter the secret manually.
   - Enter the current 6-digit code from the authenticator.
   - Generate the one-time backup codes. Download or copy them; each backup code works only once.
4. Select **Finish enabling**.

**Status and management**:
- Once enabled, the card shows **Two-factor authentication enabled**, the activation timestamp, and the **remaining backup code count** (`{count} backup codes remaining`).
- Select **Regenerate backup codes** and enter the current 6-digit code to issue a fresh batch; all previous codes are invalidated immediately.

**Disabling TOTP**:
1. Select **Disable Two-Factor Authentication**.
2. In the confirmation dialog, verify with either your account password or the current 6-digit TOTP code.
3. Confirm to unlink TOTP; the card returns to the disabled state.

### Connected Accounts

The **Connected Accounts** section lists linked SSO providers with the bound email and last login time.

- Select **Disconnect** to unlink a provider when you have a password or another authentication method configured.
- The system prevents lockout: it **refuses to disconnect your only authentication method** (when no standalone password is set and only one SSO link remains).

<Callout type="note">
  There is no user-side "Connect" action — SSO connections are linked automatically during login when the provider email matches your account (see [SSO Configuration](./sso.mdx)).
</Callout>

### Deleting Your Account

<Callout type="error" title="Permanent Deletion">
  Deleting your account cannot be undone. Back up important data before proceeding.
</Callout>

1. Open **Profile Settings** → **Account** tab.
2. Find the **Delete Account** section and click **Delete Account**.
3. Read the warning carefully.
4. Enter your password to confirm.
5. Click **Permanently Delete**.

**What gets deleted**: Your profile and personal information, conversations and messages, API keys, team memberships (if not owner), and uploaded files.

<Callout type="warn">
  There is no temporary deactivation or reactivation flow — deleting the account is permanent. If you are a team owner, transfer ownership before deleting your account.
</Callout>

## Preferences

### Language

Switch the interface language (e.g., English / 中文) via the **language switcher** in the navigation bar. The change takes effect immediately.

### Theme

Switch the theme via the **theme toggle** in the navigation bar:

- **Light**
- **Dark**
- **System** (follow the system preference)

## API Keys

API keys are managed on a dedicated page, not in profile settings:

1. Open the user menu (profile icon).
2. Select **API Keys**.
3. Or navigate directly to `/app/api-keys`.

See [Managing API Keys](./api-keys.mdx) for details.

## My Memories

The user menu includes **My Memories** (`/app/memories`), with the subtitle "Explore what AI knows about you". Here you can:

- Search memory entities by keyword or filter by entity type.
- Switch the graph canvas across **Grid**, **Hierarchical**, and **Radial** layouts, with zoom and Fit View controls.
- Inspect an entity's properties, outgoing and incoming relations, access count, and last-accessed timestamp.
- Use **Select Mode** to batch-delete entities (**Delete selected**), or edit an entity's description.
- When no memories have been formed yet, an empty state invites you to **Start conversation**.

For extraction rules, entity and relation types, and recency-decay scoring, see [Memory and Context](../agent/memory.mdx).

## Notifications

The notification center aggregates site-wide, team, and personal notifications, with search, unread filtering, and mark-as-read. Document processing, workflow runs, Agent publishing, API Key expiration, and security events can trigger automatic notifications.

Notification preferences (email digests, per-type toggles, quiet hours, push notifications) are global and managed by administrators. See [Notifications & External Channels](./notifications.mdx) for details.

## Troubleshooting

### Cannot Save Profile

1. Check your internet connection.
2. Verify all required fields are filled.
3. Check field validation error messages.
4. Refresh the page and try again.

### Email Verification Not Received

1. Click **Send Email Verification** to get a code.
2. Check your inbox (including spam/junk folder).
3. Enter the 6-digit code.
4. If not received, wait a minute and resend.

### TOTP Cannot Be Enabled or Lost Access

1. Use a backup code to log in.
2. Contact your administrator to disable TOTP.
3. Ensure your authenticator app's time is synced.
4. Try a different authenticator app.

## Best Practices

**Do**:

- Use a strong, unique password and enable TOTP.
- Keep your email address up to date.
- Review connected SSO accounts regularly.
- Mark notifications as read promptly; address security alerts immediately.

**Don't**:

- Share your password.
- Disable 2FA on shared devices.
- Ignore security alerts.
- Let notifications accumulate.
