团队是 Clouisle 的资源隔离边界。团队成员角色为所有者、管理员、成员和观察者。

## 创建和切换团队

1. 前往**团队** > **创建团队**。
2. 填写名称和可选描述、头像。
3. 创建后从工作台团队切换器选择它。
4. 新建 Agent、工作流和知识库时确认当前团队。

## 添加成员与角色

团队管理员选择**添加成员**，搜索用户并指定角色。角色含义：

| 角色 | 主要职责 |
| --- | --- |
| 所有者 | 完整团队控制、所有权转让 |
| 管理员 | 管理成员、模型授权和团队资源 |
| 成员 | 按权限创建和使用资源 |
| 观察者 | 只读查看可访问资源 |

精细操作仍受权限代码控制。改变角色会产生通知和审计记录。

## 模型授权

在团队详情的**模型授权**中选择全局模型，设置 Token/请求配额、启用状态和优先级。参见[管理团队模型](../models/manage-models.mdx)。

## 移除、离开和转让

- 移除成员会立即撤销其团队资源访问。
- 所有者不能被移除，也不能直接离开团队。
- 转让所有权会让原所有者失去所有者权限；确认目标成员后再执行。
- 默认团队不能删除。
