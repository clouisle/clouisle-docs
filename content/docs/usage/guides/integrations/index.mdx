消息集成让外部聊天工具复用 Clouisle 的 Agent 执行能力、知识库和身份体系，而不是在外部平台里再跑一套 Agent。管理员在**站点设置** > **集成**配置共享应用与功能开关；每个用户在**个人设置**里绑定自己的外部身份并选择用途。对外发送结果统一记录在[投递记录](./delivery-log.mdx)。

## 集成与功能开关

飞书与微信 iLink 都是**内置集成**，每类只有一个实例：管理员保存一次应用凭据，全站共用，不能按团队或按用户再建一个。集成页展示的是**功能开关，不是集成总开关**：

| 集成 | 可开启的功能 |
| --- | --- |
| 飞书 | 用户登录、通讯录同步、通知、Agent 会话 |
| 微信 iLink | Agent 会话、知识库采集 |

开启一项不会顺带开启另一项。关闭功能会保留已保存的凭据、个人绑定、历史记录和待处理工作；已经开始的任务仍可能完成。飞书登录是显式选项——只启用飞书集成不会自动开放飞书登录。

集成设置按两个权限域分开：**登录源管理**负责登录方式与全局单点登录策略，**服务设置管理**负责应用凭据、功能开关、同步与 Agent 会话通道。飞书同时涉及两类，只持有一个域的管理员只能修改该域的内容，集成列表也只显示该域可见的部分。

## 管理与个人边界

| 位置 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| **站点设置** > **集成**（`/site-settings/integrations`） | 集成列表与功能入口；飞书、微信、邮件、Webhook 各有独立子页 | 不能替用户选择回复用的 Agent，也不能代替用户扫码授权微信 |
| 飞书子页（`/site-settings/integrations/feishu`） | 应用凭据、登录开关、通讯录范围与同步、通知测试、Agent 会话事件接收方式、知识同步来源 | 不保存个人 Agent 选择；知识同步仅超级管理员可见 |
| 微信子页（`/site-settings/integrations/wechat`） | 平台级的 Agent 会话与知识库采集开关 | 不保存个人微信凭据，也不替用户选择连接用途 |
| **个人设置** > **飞书** / **微信 iLink** | 绑定自己的外部身份、选择 Agent 或知识库目标、个人开关、授权与断开 | 不能绕过管理员关闭的功能，也不能看到其他用户的连接 |

## 能力矩阵

| 能力 | 飞书 | 微信 iLink |
| --- | --- | --- |
| 网页登录 | 支持，需管理员显式开启；同一应用复用身份绑定 | 不支持 |
| 通讯录同步 | 支持，手动单向同步部门成员并创建团队 | 不支持 |
| 通知投递 | 支持，向已建立通讯录绑定的用户发私聊消息 | 不支持 |
| 知识同步 | 支持，飞书 Wiki 空间 → 知识库；仅超级管理员；导入文档本地只读 | 支持，个人微信消息 → 知识库（知识库采集） |
| Agent 会话 | 支持，私聊机器人；每位用户各自选择 Agent | 支持，个人微信连接；一个连接只服务一个已发布 Agent |

两个 Agent 会话都只负责**接入和投递**：消息进入 Clouisle 的 Agent 运行体系，模型、工具、知识库、记忆与配额仍按连接用户自己的权限计算。外部平台不持有 Agent 循环，也不绕过本地授权。

## 投递与排障

两个 Agent 会话共用一个出站记录，在侧边栏**监控** > **投递记录**（`/deliveries`）查看。它记录的是「平台有没有接受回复请求」，不是消息历史；「已发送」不代表对方已读或已下载附件。

- 回复没有到达时，先在投递记录里按 Run ID 筛选该次运行，再核对原始错误。
- [飞书](./feishu.mdx)长连接显示**已连接**只代表连接通了，不代表私聊权限或事件订阅已生效。
- [微信 iLink](./wechat.mdx)不需要单独部署接收服务，接收与投递由平台后台处理；功能关闭或后台未就绪都会表现为「没有新消息」。部署与容量要求见[架构说明](../../../self-host/architecture.mdx)。
