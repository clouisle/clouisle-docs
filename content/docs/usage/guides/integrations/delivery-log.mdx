**投递记录**（Delivery log，`/deliveries`）是飞书 Agent 会话与微信 Agent 会话共用的**出站发送记录**。它回答的是「这次回复或产物有没有送到外部平台」，不是消息历史：「已发送」只表示平台接受了回复请求，不代表接收人已读、打开了卡片或下载了附件。

## 页面用法

页面位于侧边栏**监控**下。

- **集成**筛选：飞书、微信，可多选（多选时匹配任一项）。
- **状态**筛选：待发送、发送中、已发送、失败、不可用、结果未知，可多选。
- 两个筛选之间是「同时满足」。
- 搜索框接受 **Run ID** 或**文件名子串**：输入完整 Run ID 时精确匹配该次运行，否则按文件名做不区分大小写的包含匹配。搜索词保留在页面地址中。
- 默认每页 **20** 行，可切换 `10` / `20` / `50` / `100`。修改任一筛选会回到第 1 页。
- 行按时间**从新到旧**排序。失败行展示平台原始错误；长错误在表格中换行，不截断。

## 表格列

| 列 | 说明 |
| --- | --- |
| 时间 | 记录创建时间（含秒） |
| 集成 | 飞书或微信 |
| 类型 | 文本、Markdown 或产物 |
| 文件 / 事件 | 产物文件名（没有文件名时显示内容类型），下方一行是该记录对应的事件 |
| 状态 | 见下方状态含义 |
| 原始错误 | 平台返回的错误原文；为空时显示稳定的失败标识 |
| 运行 | 来源的 Run ID |

## 状态含义

| 状态 | 含义 |
| --- | --- |
| 待发送 | 已登记，尚未开始发送；重启与功能暂停后仍保留 |
| 发送中 | 正在发送。发送过程被中断时会转为「结果未知」，不会自动重发 |
| 已发送 | 平台接受了回复请求 |
| 失败 | 永久失败，例如平台拒绝或产物不可用 |
| 不可用 | 运行已结束，但回复不应发送（渠道关闭、访问被撤销、缺少会话上下文） |
| 结果未知 | 发送后超时；结果不确定，绝不盲目重发 |

「待发送」「发送中」「结果未知」都是中间状态，不是最终结论。排查时不要只看到「结果未知」就重试；先核对原始错误与对应的运行记录。

失败原因分两层：稳定的失败标识用于判断类别，`error_detail` 保留平台返回的原始文本、HTTP 状态与错误码。页面优先显示 `error_detail`，为空时回退到失败标识。定位权限、参数或大小问题时以原始文本为准。

## 权限与可见性

页面只读，需要集成服务设置的查看权限；超级管理员不受此限制。消息正文、平台的媒体标识、凭据与文件内容都不会显示。

## 排查顺序

固定按三步处理：

1. 用 Run ID 过滤，确认该次运行确实产生了这条投递。
2. 看状态区分「未发送」「发送中」「平台拒绝」「结果不确定」。
3. 读原始错误，定位平台权限、字段或大小限制。

各渠道的具体失败含义见[飞书](./feishu.mdx)与[微信 iLink](./wechat.mdx)。

## 与通知记录的区别

本页只覆盖飞书/微信 Agent 会话的回复与产物。站内通知通过邮件、Webhook 或飞书发出时，记录在通知详情里，状态为待发送、发送中、已发送、发送失败或已跳过；两者是不同的数据，不要混用。微信**不是**通知渠道。见[通知与外部渠道](../administration/notifications.mdx)。
