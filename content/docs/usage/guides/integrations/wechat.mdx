微信 iLink 是**个人授权 + 平台开关**的组合：管理员只决定平台允许哪些用途，每位用户在自己的个人设置里扫码授权、选择用途并配置目标。一个微信连接同一时间只能做一件事——暂不处理消息、知识库采集，或与一个已发布 Agent 对话。Agent 执行由 Clouisle 的 Agent 运行体系完成，微信不持有第二套 Agent 循环。

## 平台开关

打开**站点设置** > **集成** > **微信 iLink**（`/site-settings/integrations/wechat`），按需启用：

| 平台功能 | 作用 |
| --- | --- |
| **智能体对话** | 允许用户把个人微信消息发送给其有权访问的已发布 Agent |
| **知识库采集** | 允许用户把个人微信消息采集到其有写权限的知识库 |

这里**没有集成总开关**，也**不保存个人微信凭据**，不会替任何用户选择连接用途。两个功能都关闭时，个人设置里无法发起二维码授权；已存在的连接仍然可见，历史记录保留。全新安装默认两个功能都关闭。

关闭某个平台功能会暂停对应的收件、执行和回复，但保留个人凭据、历史与待处理记录；已经开始的执行仍可能完成。重新启用后，符合条件的工作继续处理。暂停期间发送的消息是否还能收到，取决于微信一侧的保留策略。

<Callout type="info">
  从旧版本升级时，已有的活跃个人用途会自动保留为对应的平台功能；之后启动不会覆盖管理员的选择。
</Callout>

## 个人授权

1. 打开**个人设置** > **微信 iLink**，选择**使用微信扫码授权连接**。
2. 用微信扫描二维码并确认；如果要求，输入微信中显示的验证码。
3. 授权完成后连接会出现在列表中，并显示授权状态。

每个已验证的微信身份最多对应一个平台连接；不同的人可以各自连接并采集到同一个知识库。**只有二维码不算连接**，授权未完成前平台无法接收或回复消息。连接可以保持空闲，不必立刻选择用途。

**断开连接**会停止接收新消息，并阻止待处理提交继续；已采集的文档保留。重新连接需要重新走一次微信授权。目标写权限丢失、目标被删除或账号被停用都会停止采集；过期的微信授权会在界面中显示。平台不会通过微信向未绑定用户发送提醒。

## 三种用途互斥

| 用途 | 行为 |
| --- | --- |
| **暂不处理消息** | 保留已保存的配置，但不再采集或对话 |
| **知识库采集** | 新消息进入目标知识库；不再进行 Agent 对话 |
| **智能体对话** | 新消息进入所选 Agent 的会话；知识库采集同时停用 |

保存一个用途会激活它并停用另外两个。已保存的配置在未激活时保留，但**不会**让第二个用途同时生效。存在已接受但未完成的工作时，切换用途会被拒绝，需先等待完成或停止当前工作。切换知识库目标不会迁移已导入的文档。

## 知识库采集

选择**知识库采集**后配置：

- 一个**活跃且可写**的目标知识库。只读共享知识库不是有效目标。
- 可选的视觉模型与语音识别模型，必须已授权给目标团队。

保存后立即开始采集。选择**暂不处理消息**可以停止采集，但不会断开连接或删除已保存的目标与识别模型；之后的消息会被忽略，**不会排队等待以后处理**。每条被接受的提交都保留提交者与当时的目标；更换目标不会迁移旧文档。

| 微信内容 | 处理方式 |
| --- | --- |
| 纯文本 | 保存为 Markdown 文档并自动索引 |
| 含 HTTP/HTTPS 链接的文本 | 逐条抓取不同链接；随附文本保留为备注 |
| PDF、DOC/DOCX、XLS/XLSX、PPTX、TXT、Markdown、HTML、CSV、JSON | 下载并解密后走现有文档处理流程；文本格式要求 UTF-8 |
| 图片 | 用所选团队授权视觉模型提取 |
| 语音 | 优先使用微信提供的转写；否则下载音频后用所选语音识别模型转写 |
| 音频文件 | 转换后用语音识别模型转写 |
| 视频 | 有音轨时转写，并最多抽取 12 个带时间标记的帧样本；帧提取需要视觉模型，音轨还需要语音识别模型 |

采集限制：

- 每个附件单独处理；随附件发送的文本作为其说明，不额外生成独立文档。
- 附件大小取「知识库文档上传上限」与 **100 MiB** 中较小者。
- 音频/视频的**可读时长不得超过 30 分钟**。
- 扫描 PDF 能被解析器接受，不代表一定有可提取文本。
- ZIP 压缩包、未知卡片和不支持的格式会产生明确失败回复，不会静默忽略。
- 原生公众号文章卡片不保证暴露文章 URL；把链接作为文本发送才会走受支持的链接路径。
- 视频只做抽帧与音轨转写，不是逐帧视频理解。

**结果与原件：** 只有完成索引才报告成功。微信接受回复**不代表手机已显示**；发送结果不明确时不会盲目重发，平台的提交记录才是权威结果。重放的消息不会重复创建文档；目标知识库内相同提取内容会去重，但提交记录各自保留。个人设置不显示提交历史或原件下载入口；系统保留提交记录和受支持的原件，并只对提交者与目标知识库的授权用户开放。

## Agent 对话

选择**智能体对话**，然后：

1. 选择一个你有权使用的**已发布 Agent**。
2. 填写该 Agent 的必填输入变量。
3. 可选选择一个语音识别模型。
4. 保存后立即生效；知识库采集同时停用。

每个连接拥有自己的会话。重复消息继续同一段对话；切换到不同 Agent 会隔离历史；修改起始变量会创建新会话。会话仍可在网页聊天中按正常授权访问。个人设置只显示当前运行状态与停止按钮，不提供 Agent 活动列表。

如果 Agent 询问问题，下一条普通回答会恢复等待中的运行，而不是启动新任务。普通消息按顺序处理，不会启动相互竞争的运行。`/new` 只在当前任务结束后才会真正重置；否则先等待或停止。工作未完成时不能切换连接用途。

### 命令

| 命令 | 中文别名 | 行为 |
| --- | --- | --- |
| `/new` | `/新对话` | 当前任务完成后开始新会话 |
| `/stop` | `/停止` | 停止当前运行 |
| `/status` | `/状态` | 查看当前运行状态 |
| `/help` | `/帮助` | 列出可用命令 |
| `/agents` | `/智能体` | 列出可访问的已发布 Agent |
| `/use <编号或 UUID>` | `/使用 <编号或 UUID>` | 切换当前连接的 Agent |
| `/skip` | `/跳过` | 跳过等待中的结构化提问 |

`/agents` 的编号按当前名称/ID 顺序生成，Agent 新增或改名后可能变化。`/use` 修改的是与个人设置相同的连接配置；存在运行、其他已接受消息、采集工作或待发送回复时不能切换，需先完成或停止并等待投递，收到成功确认后再发送下一条消息——已接受的消息不会被重新路由。选择当前 Agent 不会产生变化；切换到另一个 Agent 会使用其默认变量并清空语音识别模型选择。

`/skip` 只对等待中的结构化提问有效。它提交的是「跳过」而不是回答；无法跳过时，该命令不会被当作答案提交，也不会错误地恢复运行。

### 输入与输出映射

| 微信输入 | Agent 输入 |
| --- | --- |
| 文本 | 消息正文；上表命令会被拦截 |
| 图片 | 图片内容，使用 Agent 具备视觉能力的聊天模型 |
| 文件 | 会话内的私有文件，加上网页聊天使用的普通文件输入 |
| 语音 | 微信自带转写；否则下载音频后用所选语音识别模型转写 |
| 视频 | 有音轨时转写，并在 Agent 模型支持时加入抽样帧 |

随附件发送的文本作为附件说明。超出 Agent 配置限制、扩展名不允许、模型无法读取的内容会收到明确拒绝回复，不会被静默丢弃。作为普通文件发送的音频按文件处理，不自动转写；只有微信语音消息走上面的转写路径。

生成的图片、视频和文件（包括生成音频——它作为文件而不是语音消息发送）会作为微信原生媒体上传。平台只发送文本与会话内的既有文件，**不会转发公共存储链接**。每条消息的运行与投递结果都有记录，但个人设置不展示列表；发送后超时记为未确认，不会盲目重发。

在准备普通任务的附件或提交运行前，平台会尝试发送一条去重的「🤔思考中…」提示（英文为「🤔Thinking...」），它只确认收到并开始准备，不代表任务完成。排在运行后的消息会收到忙碌提示。命令和结构化提问的回答有自己的响应。微信只会收到状态提示、最终回答和必要的交互提示，不会收到内部推理或工具轨迹。

Agent 使用连接用户自己的身份以及平台现有的模型、工具、知识库与配额权限。权限被撤销或连接断开后，后续执行与投递都会停止。

## 后台处理与部署

微信**不需要单独部署接收服务**：启用任一平台功能后，消息接收、排队与回复投递全部由平台后台自动处理，无需额外组件、命令或配置项。负载高时收到消息的间隔可能变长。

Agent 模式依赖平台的代码沙箱；沙箱未就绪时任务会提示未完成，恢复后重试即可。完整的部署、升级与容量要求见[自托管架构](../../../self-host/architecture.mdx)与[升级指南](../../../self-host/operations/upgrade.mdx)。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 个人设置里无法生成二维码 | 两个平台功能都关闭；先在站点设置启用至少一个 |
| 扫码后没有任何消息被接收 | 授权未完成，或连接用途仍是**暂不处理消息**；完成授权并保存用途 |
| 无法切换用途 | 仍有已接受的采集或 Agent 工作在排队/执行；等待完成或先停止 |
| 消息已发送但没有回复 | 确认对应平台功能已开启；长时间没有回复时，在[投递记录](./delivery-log.mdx)按 Run ID 查看结果 |
| 微信显示发送成功，手机却看不到 | 微信接受回复不等于终端已显示；发送不明确会记为「结果未知」，不会重发 |
| 附件被拒绝 | 超过 100 MiB 或知识库上传上限、音视频超过 30 分钟、ZIP/不支持格式，或模型无法读取 |
| 采集目标突然停止 | 目标知识库被删除、写权限丢失、账号停用或微信授权过期；重新授权或修复目标后继续 |
| Agent 任务提示未完成 | 代码沙箱未就绪或任务中断；稍后重试，持续失败请联系平台管理员 |
