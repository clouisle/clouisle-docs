模型是 Agent、知识库与工作流共同依赖的底层能力。Clouisle 采用**两级管理**：管理员在管理后台的全局模型注册表中登记供应商、端点、凭据与能力标记，再把模型授权给具体团队并设置 Token 与请求配额。
