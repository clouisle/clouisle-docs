Clouisle 通过统一的模型供应商抽象层接入多模态模型。**供应商不是可独立配置的实体**：没有带默认 API Key、超时或重试策略的全局供应商注册表，每个模型自带供应商、请求地址、API Key 和可选的显示名称。因此「配置供应商」实际等于「登记一个带供应商标识的模型」，注册流程见[注册模型与团队授权](./manage-models.mdx)。

## 支持的供应商

登记模型时从下拉列表选择供应商。未填写自定义请求地址时，平台使用该供应商的官方默认地址。

| 供应商 | 说明 |
| --- | --- |
| OpenAI | 官方 Chat Completions 接口 |
| OpenAI Responses | OpenAI Responses 接口，主要用于图片生成 |
| Anthropic | Claude 系列 |
| Google AI | Gemini 系列 |
| Azure OpenAI | 需要管理员填写 Azure Endpoint |
| DeepSeek | 深度求索 |
| Moonshot | 月之暗面 |
| Zhipu AI | 智谱 AI |
| Qwen | 通义千问 |
| Baichuan | 百川智能 |
| MiniMax | MiniMax |
| Volcengine | 火山方舟 |
| SiliconFlow | 硅基流动 |
| xAI (Grok) | xAI |
| Ollama | 本地或自建 Ollama 服务 |
| Runway | 视频生成 |
| Pika | 视频生成 |
| Luma AI | 视频生成 |
| Kling | 可灵，视频生成 |
| Stability AI | 图片生成 |
| Midjourney | 需要自建代理，没有默认地址 |
| TypeSafe AI | 决策模型 |
| OpenAI Compatible | 任意兼容接口，由接入方提供地址 |

请求地址的解析顺序是：模型自填的地址 → 模型类型专属默认地址 → 供应商默认地址。因此清空请求地址不会报错，而是回落到默认值；这也是「同一供应商下的语音模型」与「对话模型」走不同地址的原因。

<Callout type="info">
  除官方默认地址外，还有三个**模型类型专属**默认地址，仅在模型未自填地址时优先命中：火山方舟的语音合成、火山方舟的音频生成，以及 TypeSafe 的决策模型。
</Callout>

### OpenAI 与 OpenAI Responses 的区别

两者默认地址相同，但请求协议不同：

- **OpenAI** 走标准 Chat Completions，是对话、嵌入与语音的常规选择。
- **OpenAI Responses** 走 OpenAI 的 Responses 接口，目前用于**图片生成**（支持尺寸、质量、背景、输出格式等专属参数）。

<Callout type="warn">
  OpenAI Responses 的行为只作用于图片生成。把对话模型配成 OpenAI Responses 时，对话仍按标准兼容方式处理，不会获得 Responses 接口的特有语义；如果上游只需要标准对话补全，直接选 OpenAI。批量发现模型时两者路径相同。
</Callout>

### 供应商在界面上的显示

供应商不需要单独登记：模型卡片、侧栏和节点下拉直接按供应商标识渲染图标与名称。图标来自内置的供应商图形，OpenAI Responses 用 OpenAI 图标、Azure OpenAI 用 Azure 图标；OpenAI Compatible 显示网关图标，并按模型名前缀猜测模型家族。名称使用界面语言（中文如“深度求索”“月之暗面”“智谱 AI”“通义千问”“百川智能”“可灵”“火山方舟”“OpenAI 兼容接口”）；填写了自定义显示名称时以它为准，未知标识直接显示原始代码。

## 模型类型

模型类型共 9 种，与供应商相互独立：

| 模型类型 | 说明 | 运行时支持的供应商 |
| --- | --- | --- |
| 对话 | 对话与文本补全（流式、函数调用） | OpenAI、Anthropic、Google AI、xAI、Azure OpenAI、DeepSeek、Moonshot、智谱 AI、通义千问、百川智能、MiniMax、火山方舟、硅基流动、Ollama、OpenAI Compatible（其余标识按兼容方式处理） |
| 嵌入 | 文本向量嵌入（知识库、记忆检索） | 15 个，包含 OpenAI、Google AI、DeepSeek、Moonshot、智谱 AI、通义千问、百川智能、MiniMax、火山方舟、硅基流动、xAI、Ollama、OpenAI Compatible、Azure OpenAI、OpenAI Responses |
| 重排序 | 检索结果重排序 | 任意；默认经对话模型做重排序，选硅基流动或开启原生重排后改调原生重排接口 |
| 语音合成 | 文本转语音 | OpenAI、Azure OpenAI、火山方舟、MiniMax |
| 语音识别 | 语音转文本 | OpenAI、Azure OpenAI |
| 音频生成 | 提示词生成音频 | 仅火山方舟 |
| 文生图 | 图片生成 | OpenAI、OpenAI Responses、Azure OpenAI、OpenAI Compatible、硅基流动、Google AI、Runway、Luma AI、Stability AI、火山方舟、MiniMax |
| 文生视频 | 视频生成 | Runway、Luma AI、Kling、Pika、硅基流动、火山方舟、MiniMax、通义千问 |
| 决策 | 类型化决策（选择题/评分/是-否，非生成式） | **仅** TypeSafe AI |

创建/更新模型时只会校验两类组合：**嵌入**必须属于上表列出的供应商，**决策**必须为 TypeSafe AI；其余类型选错供应商在保存时**不会**被拒绝：

<Callout type="error">
  例如创建 Anthropic + 嵌入，或 Stability AI + 文生视频，界面会正常保存，但首次实际调用时才会报“供应商不支持”错误。知识库、媒体节点等资源因此可能在保存后才暴露配置错误，务必在注册后立即用**测试连接**验证。
</Callout>

<Callout type="info">
  决策模型是 TypeSafe AI 的专有协议：不做聊天补全，而是接收状态 + 类型化问题，返回带概率分布的答案，供工作流的**决策**节点使用。
</Callout>

## 远程模型发现

**发现模型**在保存前列出供应商真正暴露的模型，避免手写错误的模型名。凭据只在本次发现请求中使用，不会入库。

发现功能支持 **16 个**供应商：OpenAI、OpenAI Responses、Anthropic、Google AI、DeepSeek、Moonshot、智谱 AI、通义千问、百川智能、MiniMax、火山方舟、硅基流动、xAI、Ollama、TypeSafe AI 与 OpenAI Compatible。Azure OpenAI、Runway、Pika、Luma AI、Kling、Stability AI、Midjourney **不支持**发现，点击后会提示该供应商不支持模型发现。除 Ollama 外，所有供应商都必须提供 API Key。

### 发现请求的前提

- **请求地址必须通过站点端点白名单**，否则在发起请求前就被拒绝。
- 地址必须是 `http(s)://主机[:端口]` 形式，不能带查询串、片段、用户名密码、反斜杠或 `//` 开头的路径；末尾 `/` 会被去掉。
- 不跟随重定向，避免凭据被跨域转发。
- 最多返回 **200** 个模型，名称超长或重复的条目会被跳过。
- 结果包含模型名称、上下文长度、最大输出以及能力（视觉、函数调用、流式、JSON 模式），可直接回填到创建表单。

### TypeSafe 走网关时如何发现模型

TypeSafe AI 会把已配置的请求地址当作网关前缀，再在其后拼接模型列表路径；因此 `https://gw.example.com/openai/v1` 与 `https://gw.example.com/api` 都能正常工作，不需要手写完整的发现地址。拼接规则与示例见[模型供应商参考](/reference/model-providers.mdx)。

## 端点白名单

站点设置里的**模型端点白名单**是模型出网的总闸门，发现、测试连接与运行时请求都受它约束。匹配规则：

- 按 **协议 + 主机 + 端口** 精确匹配，**忽略路径**；`https://gateway.example.com/anything` 与 `https://gateway.example.com` 视为同一目标。
- 非默认端口参与匹配：`http://ollama.internal:11434` 与 `http://ollama.internal` 不同。
- 系统预置 20 个官方地址；Midjourney 因需要自建代理没有默认项。
- 白名单上限 200 条；**清空列表会阻止所有模型端点**。
- 移除某个地址会立即阻断后续的发现、测试与运行时请求，无需重启服务。

管理员可以在**站点设置 > 安全**中**关闭白名单校验**，关闭后不再比对白名单，但地址的格式校验仍然执行，已保存的列表也会保留，可随时重新开启。字段细节见[站点设置参考](/reference/site-settings)。

<Callout type="warn">
  关闭白名单校验意味着任何可解析的主机都可以作为模型端点。仅在你信任所有能创建模型的管理员、并接受数据外发风险时关闭；远程端点优先使用 HTTPS，HTTP 仅用于可信私有网络，否则 API Key 与模型流量会以明文传输。
</Callout>
