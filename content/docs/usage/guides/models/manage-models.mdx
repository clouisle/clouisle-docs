Clouisle 的模型分两级：平台管理员先在**管理后台** > **模型**登记全局模型（供应商、模型 ID、凭据、能力、价格），再把模型授权给团队并设置配额。团队看到的**模型**页、Agent 与工作流里的模型选择器，只列出本团队已授权的模型。

<Callout type="info">
自定义 API 地址（自建网关、内网 Ollama 等）必须先加入**站点设置** > **安全** > **模型端点白名单**，否则保存、测试连接和运行时请求都会被拒绝。规则见[端点白名单](./providers.mdx#端点白名单)。
</Callout>

## 登记全局模型

进入**管理后台** > **模型**，点击**添加模型**。表单分**基本信息**、**参数设置**、**高级配置**三块；填完先点**测试连接**，通过后再保存。保存成功后列表出现该模型，默认状态为**已启用**。

### 基本信息

| 界面字段 | 必填 | 取值与默认值 | 说明 |
| --- | --- | --- | --- |
| **模型名称** | 是 | 1–100 个字符 | 模型列表、选择器与用量统计里显示的名称 |
| **供应商** | 是 | 23 个供应商之一，见[支持的供应商](./providers.mdx#支持的供应商) | 决定调用协议与默认 API 地址 |
| **模型类型** | 是 | 对话、嵌入、重排序、决策、语音合成、语音识别、音频生成、文生图、文生视频 | 决定调用方式与可用的测试动作 |
| **模型 ID** | 是 | 1–100 个字符 | 供应商侧真实模型名或部署名，填错会在调用时报找不到模型 |
| **API 地址** | 否 | ≤ 512 个字符 | 留空使用该供应商与类型的默认地址；自定义地址必须在白名单内 |
| **API Key** | 除 Ollama 外必填 | ≤ 1024 个字符 | 加密保存，保存后界面只显示「API Key 已配置」 |
| **供应商 / 网关名称** | 否 | ≤ 100 个字符 | 用「OpenAI 兼容接口」接自建网关时，用它替换列表里显示的供应商名 |

<Callout type="warn">
**供应商**、**模型 ID**、**模型类型**保存后不能修改。要换供应商、换模型 ID 或改类型，只能新建一个模型，再授权给团队，并把引用旧模型的知识库、Agent、工作流改到新模型上。
</Callout>

### 参数设置

- **上下文长度**与**最大输出长度**只用于展示和容量判断，不会强制截断；实际输出上限仍可被 Agent 设置或单次调用覆盖。
- **输入价格**与**输出价格**按「美元 / 百万 Token」记录，只用于展示，不参与计费或配额计算。
- **推理参数**（频率惩罚、存在惩罚、默认最大 Token 数）留空即使用供应商默认值。
- **输入模态**与**输出模态**声明模型能接受、能生成的内容类型（文本、图像、音频、视频、文件）。勾选**图像**输入后，对话里才允许传图；输出模态只是声明，不会自动开启图片或视频生成。
- **模型能力**三个开关见下文[模型能力](#模型能力)。

### 高级配置

按供应商与模型类型出现不同分区：**思考 / 推理**（启用思考、思考预算、推理强度）、**图像生成设置**、**视频生成设置**、**音频设置**、**Azure 配置**（API 版本、部署名称），以及**额外请求体**、**默认参数扩展**、**配置扩展**三个 JSON 输入框，用于补充供应商专属参数。常见组合：

| 场景 | 填法 |
| --- | --- |
| Azure OpenAI | 在 **Azure 配置**里填 API 版本与部署名称，**模型 ID** 也填部署名 |
| 火山方舟 | **API Key** 处分别填写 `X-Api-Key` 与 `X-Api-Resource-Id` |
| 自建网关 | 供应商选 **OpenAI 兼容接口**，填 **API 地址**与**供应商 / 网关名称** |
| 推理模型 | 打开**启用思考**，按需设置**思考预算**或**推理强度** |

精确字段名、取值范围与默认值见[模型定义字段](/reference/model-providers#模型定义字段)。

## 自动发现可用模型

新建模型时，填好**供应商**、**API 地址**与 **API Key**（Ollama 等本地供应商不需要 Key）后，表单会自动向供应商拉取可用模型列表：**模型 ID** 输入框变成可搜索的下拉，展开就能看到供应商返回的模型（显示为「名称 (ID)」）。选中后，模型名称、上下文长度、最大输出长度、输入与输出模态、能力开关都会自动回填，省去手写模型 ID。输入框下方会显示拉取中、成功或失败状态。

- 只在**新增**时自动拉取；编辑已有模型时不会重新拉取。
- 供应商没有模型列表接口时（如 Azure OpenAI、Runway、Pika、Luma、Kling、Stability AI、Midjourney）不会出现列表，手工填写模型 ID 即可。
- 拉取失败只影响便利性：手工填对模型 ID 仍可正常保存和使用。
- 拉取所用凭据只用于本次请求，不会因此被保存。

支持范围、地址规则与失败原因见[远程模型发现](./providers.mdx#远程模型发现)。

## 凭据与请求地址

- **API Key 加密保存**。保存后任何页面都只显示「API Key 已配置」，不再显示明文；轮换时在编辑表单填入新值，留空表示保持不变。
- Key 格式有约定：OpenAI 系需 `sk-` 开头，Anthropic 需 `sk-ant-` 开头；明显不符时**测试连接**会直接提示格式错误。**Ollama** 是唯一不需要 Key 的供应商。
- 实际请求地址按「模型 **API 地址** → 该模型类型的默认地址 → 供应商默认地址」逐级回落，且必须命中[端点白名单](./providers.mdx#端点白名单)。

## 模型能力

三个能力开关决定 Agent 与工作流能不能用上模型的特定行为：

| 开关 | 打开后的效果 | 配错的后果 |
| --- | --- | --- |
| **函数调用** | 允许模型调用工具 | 没打开时 Agent 用不了工具；模型实际不支持却打开，会在工具调用时报协议错误 |
| **流式输出** | 回答边生成边返回 | 关闭后只能一次性返回，长回答的首字等待更明显 |
| **JSON 模式** | 支持结构化 JSON 输出 | 没打开时依赖 JSON 的节点与参数抽取会退化成文本解析 |

给 Agent 启用工具前，先确认所选对话模型真的支持**函数调用**：新建模型时从**模型 ID** 下拉读取供应商声明，再手工校正。

## 测试连接

编辑弹窗里的**测试连接**会用当前表单内容向上游发一次最小请求，结果显示成功或失败，并给出**延迟**：

| 情形 | 测试内容 |
| --- | --- |
| 新建、尚未保存 | 用表单里填写的凭据即时测试，凭据不入库 |
| 编辑已有模型 | 用已保存的配置测试；刚改了 Key 则用新 Key |

不同模型类型的测试动作：

| 模型类型 | 测试做什么 |
| --- | --- |
| 对话 | 发送一句 `Hi`，要求返回非空文本 |
| 嵌入 | 对一段固定文本做嵌入，要求返回向量 |
| 重排序 | 用固定查询与两篇文档排序，要求有结果 |
| 决策 | 向 TypeSafe 发一条最小决策请求，要求有答案 |
| 文生图 | 生成一张测试图 |
| 文生视频 | 真实创建一条视频任务并等待出片 |
| 语音合成 / 音频生成 | 合成一段固定内容的音频 |
| 语音识别 | 只校验 Key 格式，不发起真实转写 |

<Callout type="warn">
- **通过测试不等于配额充足**：上游限流时，除文生视频外仍会提示连接成功，同时附带限流信息。
- **文生视频测试会真实创建任务并产生供应商费用**，默认最多等待 120 秒。供应商出片更慢时会提示测试超时，可在**高级配置** > **配置扩展**里调大等待秒数。
</Callout>

<Callout type="info">
目前只提供单次连接验证，没有多请求压测、并发或 p95 延迟统计。
</Callout>

## 启用、禁用与默认模型

在模型列表的行操作里可以直接**启用** / **禁用**，也可以在编辑弹窗里改**状态**与**设为该类型的默认模型**。

- 禁用是唯一的停用方式：模型从所有选择器里消失，但配置与团队授权都保留，重新启用即恢复。
- **默认模型按类型唯一**：点**设为默认**会清除同类型其他模型的默认标记。知识库的嵌入模型、Agent 未指定模型时的兜底都依赖它。
- 列表支持按状态筛选，也可以批量删除。

## 授权模型给团队

只有超级管理员可以授权。步骤：

1. 进入**管理后台** > **团队**，打开目标团队。
2. 切到**模型授权**标签页，点击**授权模型**。
3. 在下拉里勾选一个或多个全局已启用的模型（已授权的不会重复出现），可一次授权多个。
4. 对每个模型填写每日 / 每月 Token 限额与请求限额，以及优先级；留空表示无限制。
5. 点击**授权**保存。

授权成功后，该团队成员在**模型**页即可看到这个模型。

- 一个团队对同一模型只有一条授权，重复授权会被拒绝。
- 已授权的模型可在**编辑授权配置**里改配额与优先级，或**撤销授权**。
- 团队管理员可以查看**已授权模型**与用量，但授权、改配额、撤销只有超级管理员能完成。

### 团队里能看到什么

- 团队的**模型**页列出全部已授权模型，包括被全局禁用的，可用状态筛选区分。
- Agent、工作流等处的模型选择器只列出「已授权且已启用」的模型。

## 配额与用量

四项限额都可以留空（无限制）；**`0` 是合法值**，等于立刻触顶。

| 限额 | 默认 | 说明 |
| --- | --- | --- |
| 每日 Token 限额 | 无限制 | 每天可用的 Token 总量 |
| 每月 Token 限额 | 无限制 | 每月可用的 Token 总量 |
| 每日请求限额 | 无限制 | 每天可发起的请求数 |
| 每月请求限额 | 无限制 | 每月可发起的请求数 |

判定方式不同，配置时注意：

- **Token 限额**在「已用 + 本次预估」超过限额时才拒绝，恰好等于限额不会立刻失败。
- **请求次数限额**在「已用 ≥ 限额」时拒绝：第 N 次请求（N 等于限额）仍可成功，第 N + 1 次被拒。
- 用量按站点时区重置：每日 0 点、每月 1 日 0 点之后，下一次检查配额时归零。
- 触顶时对话会提示「模型配额已用尽」，需要调大限额或等下次重置。

授权列表里的进度条只按 **Token** 限额计算；请求次数是否超额，需要自己对比已用请求数与每日 / 每月请求限额。

## 优先级

**优先级**默认 `0`，只影响同类型模型在选择器里的排序，不改变可用性：数值越大越靠前。修改配额时会在同一个**编辑授权配置**弹窗里一起改。

## 修改、撤销与删除

| 操作 | 影响 |
| --- | --- |
| 编辑模型 | 可改名称、API Key、API 地址、能力、价格、参数与状态；供应商、模型 ID、模型类型不可改 |
| 禁用模型 | 全局隐藏，团队授权保留，可随时恢复 |
| 撤销团队授权 | 该团队立即失去此模型，对应用量记录一并移除 |
| 删除模型 | 全局注册项被删除，**所有团队对该模型的授权一并删除** |

<Callout type="error">
删除全局模型会连带删除所有团队的授权，且不可恢复。只想让某个团队停用时，请撤销它的授权，不要删除模型。
</Callout>

## 常见问题

### 测试连接失败

1. **检查白名单**：自定义 API 地址的「协议 + 主机 + 端口」是否已在**站点设置** > **安全** > **模型端点白名单**里；非标准端口（如 `:11434`）也会参与比对。
2. **检查 Key 格式**：OpenAI 系需 `sk-` 前缀，Anthropic 需 `sk-ant-` 前缀；确认 Key 未过期且有目标模型权限。
3. **检查供应商与类型是否匹配**：如 Anthropic + 嵌入、Stability + 文生视频，保存时可能通过，调用时才报不支持。
4. **检查网络**：默认 15 秒超时、不跟随重定向；内网地址确认可达。
5. **检查上游状态**：供应商限流或故障也会表现为测试失败，但限流通常仍提示连接成功。

### 提示模型配额已用尽

1. 打开**管理后台** > **团队** > 目标团队 > **模型授权**，看哪个限额触顶。
2. 调大限额、换用未触顶的同类型模型，或等次日 / 次月重置。
3. 若怀疑误判，检查是否有单次超大请求：Token 限额按「已用 + 预估」判断。

### 响应缓慢或超时

1. 核对**上下文长度**与**最大输出长度**，过大的输出上限会明显拉长响应。
2. 降低 Agent 的最大 Token 数、打开**流式输出**，或改用更快的模型。
3. 视频类模型出片慢于测试等待时间时，会在测试阶段报超时。
