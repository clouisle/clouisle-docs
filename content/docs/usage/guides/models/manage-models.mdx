团队模型页展示当前团队获授权的模型。它按模型类型分组，并支持供应商、类型、启用状态和名称筛选。

## 授权模型

1. 前往**团队**，打开目标团队。
2. 选择**模型授权** > **授权模型**。
3. 选择一个或多个全局模型。
4. 填写每日/月度 Token 和请求限额；留空表示无限制。
5. 保存后，成员在**模型**页看到对应模型。

## 限额与优先级

模型授权字段的非负整数限制：`daily_token_limit`、`monthly_token_limit`、`daily_request_limit` 和 `monthly_request_limit`。授权返回当前已用 Token、请求数和百分比。优先级默认为 `0`，同类型模型按优先级降序排列。

## 启用、禁用与撤销

- **禁用**保留授权和用量历史，但团队不能继续选择该模型。
- **撤销授权**移除团队与模型的关联；正在运行的请求按运行时状态处理。
- 达到配额时请求返回"模型配额超限"，错误码为 `6103`。

## 连接测试

管理员模型表单提供连接测试，响应包含成功状态、消息和可选延迟毫秒数。测试失败时先核对端点白名单、凭据、网络访问和模型类型。

## 添加模型

### 添加 OpenAI 模型

1. 点击**添加模型**按钮。
2. 选择供应商：**OpenAI**。
3. 填写模型详情：
   - **名称**：显示名称（如"GPT-4 Turbo"）
   - **模型 ID**：OpenAI 模型 ID（如 `gpt-4-turbo-preview`）
   - **类型**：对话、嵌入或其他支持的类型
   - **描述**：模型描述（通过 `provider_display_name` / config）
4. 配置 API 设置：
   - **API Key**：OpenAI API 密钥
   - **API Base**：（可选，用于自定义端点）
5. 设置能力：
   - **上下文长度**：最大上下文窗口
   - **最大输出 Token**：最大响应长度
   - **能力标记**：流式输出、函数调用、视觉等（JSON）
6. 配置定价：
   - **输入价格**：每百万输入 Token 费用
   - **输出价格**：每百万输出 Token 费用
7. 设置默认参数（JSON，如 `{"temperature": 0.7, "top_p": 0.9}`）
8. 点击**测试连接**
9. 点击**保存模型**

<Callout type="info">
模型没有组织（`org-...`）字段，定价也没有货币字段——价格按每百万 Token 的美元计。
</Callout>

### 添加 Anthropic 模型

1. 点击**添加模型**按钮。
2. 选择供应商：**Anthropic**。
3. 填写模型详情：
   - **名称**："Claude 3.5 Sonnet"
   - **模型 ID**：`claude-3-5-sonnet-20240620`
   - **类型**：对话
4. 配置 API 设置：
   - **API Key**：Anthropic API 密钥
   - **API Base**：（可选）
5. 设置能力和定价（每百万 Token）
6. 测试并保存

### 添加 Azure OpenAI 模型

1. 点击**添加模型**按钮。
2. 选择供应商：**Azure OpenAI**。
3. 填写模型详情：
   - **名称**："GPT-4 (Azure)"
   - **模型 ID**：部署名称
   - **类型**：对话
4. 配置 API 设置：
   - **API Key**：Azure API 密钥
   - **API Base**：Azure 端点 URL
   - **API 版本**：API 版本（如 `2024-02-15-preview`）——通过 config
   - **部署名称**：Azure 部署名称（作为模型 ID）
5. 设置能力和定价
6. 测试并保存

### 添加自定义模型

对于自定义或自托管模型：

1. 点击**添加模型**按钮。
2. 选择供应商：**Custom**。
3. 填写模型详情
4. 配置 API 设置：
   - **端点**：自定义 API 端点
   - **认证**：API Key、Bearer Token 或 Custom
   - **请求头**：自定义请求头
   - **请求格式**：OpenAI 兼容或 Custom
5. 设置能力
6. 测试并保存

## 编辑模型

### 更新模型设置

1. 在列表中找到模型
2. 点击**编辑**按钮
3. 修改设置：
   - 基本信息
   - API 凭据
   - 能力
   - 定价
   - 默认参数
4. 点击**测试连接**
5. 点击**保存更改**

### 轮换 API Key

<Callout type="warn">
定期轮换 API Key 是安全最佳实践。
</Callout>

1. 编辑模型
2. 更新 API Key
3. 测试连接
4. 保存更改
5. 监控错误

### 更新定价

当供应商定价变更时：

1. 编辑模型
2. 更新定价信息：
   - 每百万输入 Token 价格
   - 每百万输出 Token 价格
3. 保存更改

## 测试模型

### 测试模型连接

1. 选择模型
2. 点击**测试**按钮
3. 输入测试提示：
   ```
   Hello, how are you?
   ```
4. 配置测试参数（temperature、max tokens）
5. 点击**运行测试**

测试端点为 `POST /api/v1/admin/models/{model_id}/test`；也可在创建模型前通过 `POST /api/v1/admin/models/test` 测试配置。

**测试结果示例：**

| 字段 | 值 |
|------|-----|
| 状态 | 成功 |
| 响应 | "Hello! I'm doing well, thank you for asking..." |
| 输入 Token | 6 |
| 输出 Token | 18 |
| 总 Token | 24 |
| 响应时间 | 1.2 秒 |

## 模型状态管理

### 模型状态

**已启用：**
- 模型正常运行
- 可供使用
- 出现在模型选择中

**已禁用：**
- 模型已禁用
- 无法使用
- 对用户隐藏
- 保留配置

<Callout type="info">
模型只有单个 `is_enabled` 标志。没有 `testing` 或 `deprecated` 状态，没有弃用消息/终止日期，也没有"替代模型"建议。
</Callout>

### 更改模型状态

**启用模型：**
1. 选择模型
2. 将"启用"设为开启
3. 确认

**禁用模型：**
1. 选择模型
2. 将"启用"设为关闭
3. 确认

## 提供商管理

### 配置提供商

提供商不作为独立实体配置。每个模型携带自己的供应商（`openai`、`anthropic`、`azure_openai`、`ollama`、`custom` 等）、API Key、base URL 和供应商显示名称。没有带默认 API Key、超时或重试策略的全局提供商注册表。

### 更新提供商设置

1. 前往**管理** > **模型**
2. 选择模型
3. 更新其供应商、API Key、base URL 或其他字段
4. 测试连接
5. 保存更改

远程模型发现通过 `POST /api/v1/admin/models/discover` 支持，可在保存前列出提供商配置可用的模型。

### 批准模型 API 源

在保存或测试具有新 API 端点的模型之前：

1. 前往**管理** > **站点设置** > **安全**。
2. 将端点 Origin 添加到**模型端点白名单**，每行一个。
3. 仅包含协议、主机名和非默认端口，例如 `https://gateway.example.com` 或 `http://ollama.internal:11434`。
4. 保存安全设置，然后再次保存或测试模型。

<Callout type="warn">
安全建议：对远程端点优先使用 HTTPS。仅对受信任私有网络上的端点使用 HTTP，否则 API Key 和模型流量将以明文传输。
</Callout>

匹配是精确的。URL 路径被忽略，但协议、主机名和端口必须全部匹配。移除 Origin 会阻止后续的模型发现、连接测试和运行时请求，无需重启服务。

## 故障排除

### 模型连接失败

**症状：**
- 测试连接失败
- 日志中出现 API 错误

**解决方案：**

1. **检查 API Key：**
   - 验证密钥是否有效
   - 检查密钥权限
   - 尝试重新生成密钥

2. **检查端点：**
   - 验证 URL 是否正确
   - 用 curl 测试端点
   - 检查防火墙规则

3. **检查速率限制：**
   - 查看供应商仪表板
   - 检查是否超出配额
   - 等待速率限制重置

4. **检查日志：**
   ```
   管理 → 模型 → 选择模型
   日志 → 查看最近错误
   ```

### 模型成本过高

**症状：**
- 意外的高成本

**解决方案：**

1. **审查用量：**
   - 查看仪表板和审计日志，定位高用量 Agent/团队

2. **优化用量：**
   - 简单任务使用更便宜的模型
   - 减少 max_tokens
   - 优化提示词

3. **审查 Agent：**
   - 检查 Agent 配置
   - 识别低效 Agent
   - 优化系统提示词

<Callout type="info">
未实现 / Roadmap：成本仪表板、每日/月度 Token 限制和成本告警暂不可用。
</Callout>

### 模型响应缓慢

**症状：**
- 响应时间长
- 超时

**解决方案：**

1. **检查配置：**
   - 审查模型的上下文长度和最大输出 Token
   - 确认模型已启用并在需要时设为默认

2. **优化请求：**
   - 减少 max_tokens
   - 使用流式输出
   - 使用更快的模型

3. **检查供应商状态：**
   - 查看供应商状态页
   - 检查是否有服务中断
   - 联系供应商支持

4. **扩展基础设施：**
   - 增加超时时间
   - 添加重试逻辑
   - 使用多个供应商

## 最佳实践

### 模型配置

<Callout type="success">
**推荐做法：**
- 启用前先测试模型
- 设置合理的定价（每百万 Token）
- 配置合理的默认值
- 定期轮换 API Key
- 记录模型用途
- 保持模型更新
</Callout>

<Callout type="error">
**避免：**
- 启用未经测试的模型
- 使用极端参数
- 长期使用静态 API Key
- 跳过文档记录
</Callout>

### 成本管理

<Callout type="info">
成本限制和成本告警未实现。每百万 Token 定价按模型存储供参考；基于用量的成本报告暂不可用。
</Callout>

<Callout type="success">
**推荐做法：**
- 通过仪表板监控用量
- 尽可能使用更便宜的模型
- 优化提示词
- 审查团队模型授权
</Callout>

<Callout type="error">
**避免：**
- 所有任务都使用昂贵模型
- 跳过测试
- 使用冗长提示词
- 向团队授权不必要的模型
</Callout>

### 安全

<Callout type="success">
**推荐做法：**
- 定期轮换 API Key
- 每个环境使用独立密钥
- 按团队限制模型访问
- 启用审计日志
- 监控滥用行为
- 仅使用 HTTPS
</Callout>

<Callout type="error">
**避免：**
- 共享 API Key
- 开发环境使用生产密钥
- 允许无限制访问
- 禁用审计日志
- 忽略可疑活动
- 允许 HTTP 连接
</Callout>

## API 访问

### 通过 API 管理模型

管理员模型端点位于 `/api/v1/admin/models` 下，需要 `admin:model:*` 权限。详见 [Models API](../../api-reference/endpoints/models.md)。

**常用操作：**

```python
# 列出模型（管理员）
models = api.get("/api/v1/admin/models")

# 创建模型
model = api.post("/api/v1/admin/models", json={
    "name": "GPT-4 Turbo",
    "provider": "openai",
    "model_id": "gpt-4-turbo-preview",
    "model_type": "chat",
    "api_key": "sk-...",
    "input_price": 10.0,   # 每百万 Token
    "output_price": 30.0   # 每百万 Token
})

# 测试模型连接
test_result = api.post(f"/api/v1/admin/models/{model_id}/test", json={
    "prompt": "Hello, how are you?",
    "temperature": 0.7
})

# 设置默认模型
api.post(f"/api/v1/admin/models/{model_id}/set-default")

# 发现提供商配置中的模型
discovery = api.post("/api/v1/admin/models/discover", json={...})
```
