打开知识库详情后，选择**上传文档**上传本地文件，或选择**导入网址**添加网页/YouTube URL。当前后端文档类型包括 `pdf`、`docx`、`doc`、`txt`、`markdown`、`html`、`csv`、`xlsx`、`xls`、`json` 和 `url`。

## 上传与状态

1. 选择文件；前端会显示上传进度。
2. 上传成功后文档状态为**等待中**。
3. 选择**开始处理**，必要时先**预览分块**。
4. 处理完成后状态为**已完成**，文档才会参与检索。
5. 失败文档显示错误信息，可选择**重新处理**或仅重试失败分段。

## 上传限制

站点默认单文件限制为 `50MB`，管理员可在**站点设置** > **常规**中调整到 `1-1024MB`。后端会拒绝超过当前设置的文件。不要把旧指南中的固定 `100MB` 当作当前默认值。

## URL 导入

输入完整的 `http://` 或 `https://` 地址和可选文档名称。页面或 YouTube 内容由服务端抓取并进入同一处理队列。外部站点不可访问、内容为空或解析失败时，查看文档错误信息和 API 日志。

<Callout type="warn">
  上传文档与处理文档是两个阶段。文档出现在列表中不代表已经完成嵌入；只有状态为**已完成**才适合绑定到 Agent。
</Callout>
