在知识库详情页选择**上传文档**上传本地文件，或选择**导入网址**添加网页/YouTube URL。上传只是把文件存到知识库并创建一条**待处理**记录；**必须再执行处理**，文档才会被解析、切分、嵌入并进入检索。

## 支持的格式

| 类型 | 扩展名 | 解析方式 |
| --- | --- | --- |
| PDF | `.pdf` | 文档转换器 → Markdown 文本 |
| Word | `.docx`、`.doc` | 文档转换器 → Markdown 文本 |
| Excel | `.xlsx`、`.xls` | 文档转换器 → Markdown 文本 |
| PowerPoint | `.pptx` | 文档转换器 → Markdown 文本 |
| 纯文本 | `.txt` | 按 UTF-8 解码 |
| Markdown | `.md`、`.markdown` | 按 UTF-8 解码，走 Markdown 结构化分块 |
| HTML | `.html`、`.htm` | 文档转换器 → Markdown 文本 |
| CSV | `.csv` | 结构化提取 |
| JSON | `.json` | 结构化提取 |
| 网页 | `url` | 服务端抓取 |

<Callout type="warn" title="不支持的情况">
  旧版 `.ppt`、XML、压缩包（ZIP/TAR/GZ）与文件夹上传均不支持，扫描件/图片也没有 OCR——只包含图片的 PDF 提取结果为空，处理会失败。
</Callout>

Markdown 文件（以及转换后仍保留 Markdown 结构的文档）不走递归字符切分，而是**按结构块切分**：1–2 级标题强制分段、超大表格按行拆分并重复表头、代码块保持完整或补齐闭合围栏，并在分块上记录所属章节与类型。细节与可调参数见[分块与文档处理](./chunking.mdx)。

## 上传文件

1. 在知识库详情页选择**上传文档**。
2. 拖放文件到对话框，或点击选择文件（可多选）。
3. 前端会逐文件校验扩展名与大小，不合格的文件会立即报错并从待上传列表中移除。
4. 点击**上传**，界面显示上传进度。
5. 每个文件生成一条文档，状态为**待处理**。

前端校验只是为了尽早报错，**服务端会再次校验**扩展名与文件大小：超限报文件过大，不支持的格式报类型不支持。

## 上传限制

- 单文件默认上限 **`50MB`**，由站点设置的文档上传上限控制，可调范围 `1-1024MB`。
- 上传对话框会读取该站点设置并显示当前值（`最大文件大小：50MB`），因此在管理员调整后应刷新页面。
- 限制是**单文件**的：可以一次选择多个文件，但每个文件单独计数、单独创建文档。
- 不支持 ZIP 打包上传，也没有知识库级存储配额；存储占用按团队层面观察。

## 状态与处理阶段

```text
上传/导入 → 提取文本 → 清理 → 分块 → 生成嵌入 → 建立全文索引 → 已完成
```

| 状态 | 含义 | 可以做什么 |
| --- | --- | --- |
| **待处理** | 文件已保存，等待处理 | 预览分块、开始处理、快速处理、删除 |
| **处理中** | 正在提取、切分、嵌入或建索引 | 等待完成，可查看进度 |
| **已完成** | 已建立索引，参与检索 | 命中测试、编辑分块、重新处理 |
| **失败** | 处理失败，附错误信息 | 查看错误、重试失败分段、重新处理 |

处理方式有三种，按需要选择：

- **快速处理**：直接按知识库（或文档）现有分块设置处理，不经过预览。
- **开始处理**（预览页）：先用**预览分块**确认甚至编辑分块，再提交这些分块生成嵌入。
- **批量处理**：在文档表格中勾选多个文档，用选择工具栏批量**快速处理**等待中文档。

### 批量预览与完成通知

在批量预览页一次确认多篇文档时，界面会分批提交；整批全部结束后只发出**一条汇总通知**，而不是每篇各发一条。

- 全部成功发索引完成通知；全部失败发失败通知。
- 部分成功时优先按失败通知呈现，并在正文里给出成功/失败篇数；若站点只启用了索引通知，则回退为索引通知。
- 单篇上传或单篇处理仍按文档各自发通知。通知类型由**站点设置 → 自动通知**中的开关控制，关闭后不再发送。

<Callout type="warn">
  上传与处理是两个阶段。文档出现在列表中不代表已经完成嵌入；只有状态为**已完成**的文档才适合在 Agent 中引用，也才会被检索命中。
</Callout>

## 从网址导入

1. 在知识库详情页选择**导入网址**。
2. 填写完整的 `http://` 或 `https://` 地址，以及文档名称（`1-255` 字符）。界面把名称标为可选，但留空提交会被校验拒绝并提示补全，建议一并填写。
3. 点击**导入**——系统先对目标地址做安全校验（拒绝内网、回环与云元数据地址），通过后创建网址类型文档并跳转到预览页。
4. 在预览页生成分块预览后提交处理：URL 内容由服务端在此时抓取，因此**导入不会自动开始处理**。

导入失败时（地址不可达、内容为空、解析失败），文档会保留错误信息，可查看源网址或删除后重试。

## 从微信采集导入

除手动上传与 URL 导入，个人微信也可以直接把消息采集到知识库：**个人设置 → 微信 iLink** 扫码授权，把用途设为**知识采集**并选择一个活跃且可写（非只读共享）的目标知识库。之后发送的文本、链接、文件、图片、语音与视频会按类型解析并自动建文档、自动索引。配置步骤、支持的内容与限制见[微信 iLink 集成](../integrations/wechat.mdx)。

与手动上传不同，采集会自动创建文档并直接进入处理与索引，不需要再点一次「处理」，也没有「预览分块」这一步；处理失败会以失败状态回复到微信。几点边界需要知道：

- **原件保存位置**：支持的附件原件保存在该知识库的受保护文件中，**不提供公开地址**；只能由提交者或有权访问该知识库的人下载。
- **大小上限**：每个附件取「知识库文档上传上限」（默认 `50MB`）与 **100MB** 中较小者；音频/视频时长不超过 30 分钟。
- **去重**：同一知识库内按提取内容去重，重复提交复用已完成的文档，并把该次提交标记为重复（提交记录仍各自保留）。
- **失败提示**：公众号文章正文被拦截、内容类型不支持等情况都会在微信侧明确回复，不会静默丢弃。

## 失败与重试

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 文件过大 | 超过站点上限 | 压缩文件或请管理员提高上限 |
| 类型不支持 | 扩展名或内容类型不在支持列表 | 转换格式 |
| 提取失败 | 文件损坏、加密、纯图片 | 重新导出或解除密码后重传 |
| 全部/部分嵌入失败 | 模型凭据、配额、维度不匹配 | 检查模型授权与维度，然后**重试失败分段** |
| 全文索引不可用 | 检索服务异常 | 联系管理员检查服务状态 |

**重试失败分段**只对状态为**失败**且存在失败分块的文档可用；如果原文本身没问题（例如只是模型临时故障），这比重新处理更省成本，因为不会丢弃已成功的分块。
