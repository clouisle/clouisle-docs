**命中测试**（检索实验室）用于在不直接修改生产配置的前提下比较检索结果。它展示召回、融合、重排序和最终排名的阶段信息。

## 运行查询

1. 打开知识库详情，选择**命中测试**。
2. 输入 `1-1000` 字符查询。
3. 选择检索方式：向量、全文或混合。
4. 设置 Top K（`1-20`，默认 `5`）、稠密阈值（`0-1`，默认 `0`）、权重和 `rrf_k`（`1-1000`，默认 `60`）。
5. 按需覆盖重排序和候选池大小（`1-100`）。

## A/B 对比

A/B 对比最多提交 `10` 个配置，每个配置 ID 必须唯一。结果会保留每侧的成功或失败状态；一侧失败不会隐藏另一侧成功结果。

## 读取诊断

诊断可能指出知识库未启用、缺少嵌入模型、超时或处理失败。阶段耗时分为 `recall`、`rerank`、`context` 与 `total`。混合分数使用加权倒数排名融合：`Σ 权重 × 1/(rrf_k + 排名)`。

## 应用预设

保存本地预设后选择**应用到生产**。应用前确认嵌入模型、索引维度和权重；至少一个混合检索权重必须大于 `0`。

常见故障和恢复步骤见[知识库设置参考](/reference/knowledge-settings)。
