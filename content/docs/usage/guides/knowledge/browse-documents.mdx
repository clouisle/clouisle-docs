在**知识库**里选择一个知识库即可浏览它的文档列表：按名称搜索，按处理状态或文件类型筛选，勾选多行做批量操作。点开文档进入详情页，查看和编辑分块、预览或下载原文件。别队共享进来的知识库带来源徽章，整体只读。

## 文档列表

每行显示文档名称、类型、大小、分块数、处理状态与创建时间，行尾菜单提供这些操作：

| 操作 | 说明 |
| --- | --- |
| **配置** / **快速处理** | 仅未处理的文档：**配置**进入详情页调整分块参数，**快速处理**直接按现有设置开始处理 |
| **管理分段** | 进入文档详情页查看与编辑分块 |
| **重新处理** | 打开分段预览，确认或调整后重新分段入库；手工改过的分块会丢失 |
| **重试失败分段** | 仅失败的文档：只重跑失败的分段 |
| **下载原文件** | 下载上传时的原始文件；URL 导入的文档没有原文件 |
| **查看源网址** | 仅 URL 导入的文档：打开来源地址 |
| 删除 | 删除文档及其全部分块 |

- 顶部**搜索文档**按名称过滤；状态筛选（等待中/处理中/已完成/失败）与类型筛选一次只能选一项。
- 勾选多行后可**批量处理**、**批量重试失败分段**或批量删除。
- 上传后尚未配置分段的文档会在列表顶部提示，点**去批量配置分段**继续。
- 由飞书同步管理的文档带只读标记：原文请在飞书中修改，这里不支持编辑、重新处理或删除。

## 文档详情页

左侧是分块列表，右侧是分块设置。

- 分块列表显示每个分块的序号与内容，可**编辑分块**、新增分块、删除分块；保存时若有未提交的修改会先询问。
- 状态为失败时，可只对失败分段重试，不必整篇重跑。
- 未处理的文档可以在右侧调整**分块大小**（字符数）、**分块重叠**、**自定义分隔符**与**清理文本**，再开始处理。处理完成后再改这些设置只能走**重新处理**。
- 顶部**预览原文件**打开只读预览，见下文。

### 原文件预览

点击**预览原文件**在右侧打开查看器。预览读取的是受保护的原文件，不会绕过分块权限；关闭查看器后回到分块列表。

<figure>
  <img src="/images/document-preview.png" alt="PowerPoint 原文件预览" />
  <figcaption>原文件预览：幻灯片缩略图、页码、缩放与下载，右侧仍可查看分块设置</figcaption>
</figure>

| 文件类型 | 预览能力 |
| --- | --- |
| **PDF** | 页面渲染、缩略图侧栏、页码跳转、缩放、旋转、文本搜索 |
| **DOCX** | 分页显示、缩略图、缩放、文本搜索；支持评论与修订标记 |
| **PPTX** | 幻灯片缩略图、上一页/下一页、页码跳转、缩放 |
| **XLSX** | 按工作表只读展示，支持列排序、搜索与单元格查看 |
| **CSV** | 表格视图与文本搜索，保留 UTF-8 / GB18030 解码回退 |
| **图片** | 直接查看原图 |
| **HTML / Markdown / 文本** | 以只读文本或渲染结果查看 |

- **超过 `20MB`** 的文件不做在线预览，提示**下载原文件**后用本地应用打开。
- 预览器按需加载：第一次打开某类文件时才下载对应组件，不会拖慢文档列表。
- 查看器内的搜索、缩放、下载与关闭按钮会跟随界面语言；深色模式与站点主题同步。
- 没有查看或下载权限、未登录、文件类型不支持或解析失败时，查看器会给出具体原因，而不是空白面板。
- URL 导入的文档没有原文件，只能查看来源地址与分块。

预览打不开时会给出具体原因：文件过大、当前账号没有查看或下载权限、未登录、文件类型不支持或解析失败。权限或登录问题解决后重试；格式问题只能下载后本地打开。

## 文档信息与自动元数据

详情页顶部显示文档名称、所属知识库、文件大小、分块数与处理状态；URL 文档显示来源地址。

系统还会为每个文档和分块自动记录一组信息：文档的格式（是否已转换成 Markdown）、正文字符数、抽取出的内嵌图片，分块所属章节（例如 `第一章 > 第二节`）与分块类型（表格/代码/列表/正文）。这些信息只读、重新处理时整体重算，界面不提供逐字段编辑；它们会随检索结果一起返回，用于在回答里标注来源。

## 共享来源与只读

| 徽章 | 出现条件 | 含义 |
| --- | --- | --- |
| **来自 `{团队}`** | 知识库属于别的团队并共享给你的团队 | 只读：上传、导入、编辑分块、删除与设置入口全部不可用 |
| **已共享 `{N}` 个团队** | 你的团队拥有该知识库，并已共享给 N 个团队 | 你仍可正常读写 |

跨团队共享、只读语义与撤销方式见[创建知识库](./create-knowledge-base.mdx)。

## 改名与其他限制

- 界面目前不提供文档重命名入口，名称只能通过 API 更新，字段说明见[知识库 API](../../../api/knowledge.mdx#更新文档)。
- 标签、分类、目录与逐字段元数据编辑都未实现。
- 检索不支持按元数据过滤或加权，只能把结果限定在指定文档内；调整方式见[检索与质量调优](./retrieval.mdx)。
- 分块里抽出的图片没有公开链接，需要在登录状态下访问。
