分块决定知识库召回的粒度。先预览，再处理；不要在没有验证结果的情况下直接扩大分块或重叠。

## 预览

在文档操作中选择**预览分块**，设置分块大小、重叠、自定义分隔符和文本清理。预览结果显示分块数、字符数、Token 数和重叠长度，不会写入生产索引。

## 处理

对等待中的文档选择**快速处理**或**开始处理**。默认分块大小为 `1000` 字符，重叠为 `100` 字符；分块大小至少 `100`，重叠至少 `0`。后台任务完成后生成嵌入并更新文档统计。

## 重新分块

已处理文档需要选择**重新分块**。系统会删除原分块及其嵌入，再生成新的分块和向量。重新分块期间文档不可视为可检索完成；所有手动编辑都会丢失。

## 编辑分块

选择**编辑分块**可修改内容、在后面新增分块或删除分块。分块内容不能为空。修改后保存会更新该分块的嵌入；如果嵌入失败，使用**重试此分段**。

## 失败处理

- 文本提取失败：检查文件是否损坏、加密或仅包含图片。
- 嵌入失败：检查嵌入模型凭据、配额和向量维度。
- 全文检索不可用：检查 PostgreSQL 与 `pg_search`。
- 大批量任务积压：查看 Worker 队列和 API 日志。
