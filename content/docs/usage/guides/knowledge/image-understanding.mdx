title: 图片与扫描件解析

很多知识并不在可选中的文字里：合同是扫描件，产品说明藏在 PPT 配图里，票据和报表只有截图。**图片解析**会在文档处理时把图片交给视觉模型或 OCR 模型，提取可见文字并生成事实描述，再和正文一起进入检索。

这个能力默认关闭，由站点管理员统一配置；它会把图片发送给外部模型，产生费用并涉及数据出境，开启前请确认合规要求。

## 什么时候用

- **扫描版合同、发票、表单**：没有文本层，普通解析只能得到空白。
- **带说明文字的 PPT / DOCX 图片**：图表、流程图、产品截图里有答案。
- **Excel 中的图片**：单元格旁的产品图、二维码、示意图。
- **用户直接上传的图片**：截图、照片、海报。

如果文档本身有完整文本层，不需要开启；开启后模型仍会分析图片，增加处理时间和费用。

## 管理员配置

1. 以管理员身份登录，打开**站点设置**。
2. 选择**解析**（`/site-settings/parsing`）。
3. 打开**启用文档图片解析**。
4. 选择**视觉模型**：必须是已启用、支持图片输入的对话模型，并且对处理该文档的团队已授权。
5. 可选选择 **OCR 模型**：只负责提取文字。留空时由视觉模型同时做 OCR 和描述。
6. 按需打开**允许获取外部图片**：只影响文档里引用的外部图片地址，默认关闭。
7. 调整资源上限并保存。

| 设置 | 默认值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 启用文档图片解析 | 关闭 | 开/关 | 关闭时图片不会发送给任何模型 |
| 视觉模型 | 空 | 已启用的图片输入模型 | 生成文字与视觉描述 |
| OCR 模型 | 空 | 已启用的图片输入模型 | 可只提取文字；为空时复用视觉模型 |
| 获取外部图片 | 关闭 | 开/关 | 是否抓取文档中引用的外部图片 URL |
| 每篇最大图片数 | `8` | `1-20` | 超过的图片不再分析 |
| 单图最大字节 | `10485760` | `1-52428800` | 超过则拒绝该图片 |
| 单图最大像素 | `20000000` | `1-40000000` | 超过则拒绝该图片 |
| 并发图片请求 | `2` | `1-8` | 单篇文档同时分析的最大请求数 |

<Callout type="warn" title="必须至少配置一个模型">
  开启开关时，视觉模型和 OCR 模型至少要有一个；把最后一个模型清空会保存失败。模型还必须对文档所属团队授权，否则处理时报错而不是跳过。
</Callout>

## 用户怎么用

图片解析是**处理阶段**的能力，不需要在上传时额外勾选：

1. 上传文档（PDF、DOCX、PPTX、XLSX 或图片），或从微信采集。
2. 按正常流程处理：快速处理，或先预览分块再提交。
3. 处理完成后，OCR 文字和图片描述会出现在对应分块里，随检索返回。

### 支持的来源

| 来源 | 处理方式 |
| --- | --- |
| 扫描 PDF / 混合 PDF | 逐页提取文本；需要的页面渲染成图片再分析 |
| DOCX / PPTX | 提取内嵌图片，保留所在段落或幻灯片位置 |
| XLSX | 提取工作表中的图片，记录工作表与锚点 |
| 独立图片 | PNG、JPEG、GIF、WebP，直接作为一篇文档处理 |
| 外部图片 | 文档里引用的 URL；仅在管理员允许时抓取，并经过 SSRF 校验 |

### 结果长什么样

- **文字**：图片中可读的内容，作为分块的一部分参与检索。
- **描述**：对图表、界面、照片的事实性描述，不编造图中没有的信息。
- **来源位置**：分块会保留页码、幻灯片号或工作表位置，回答里可以据此标注来源。
- **图片本身**：仍通过受保护的文件接口展示，索引里不保存原图，也不会生成公开链接。

<Callout type="info">
  模型输出被当作不可信的文档内容：图片里的指令不会被当成系统提示执行；描述会经过清理再入库。
</Callout>

## 成本、隐私与边界

- **费用**：每张图片都会调用视觉或 OCR 模型，按供应商计费；大文档可能显著增加处理时间和 Token。
- **数据出境**：图片会发送给配置的模型供应商。敏感证照、身份证、医疗影像等请先确认组织政策。
- **不是 OCR 的替代品**：手写体、低分辨率、旋转或遮挡严重的图片识别率有限；关键数字请人工复核。
- **重复文本**：混合 PDF 可能同时有文本层和图片 OCR，分块里可能出现重复内容；这是已知限制。
- **外部图片**：默认关闭。开启后仍会拒绝内网、回环和云元数据地址。
- **历史文档**：只对**开启后新处理**的文档生效。已有文档不会自动重跑，需要手动**重新处理**。

## 失败与重试

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 图片被跳过 | 超过数量、字节或像素上限 | 压缩图片，或请管理员调高上限 |
| 独立图片处理失败并提示未提取到文字 | 图片没有可识别文字，且只配置了 OCR 模型 | 配置视觉模型生成描述，或改用可读图片 |
| 模型未授权 / 不可用 | 团队没有该模型授权，或模型被禁用 | 在模型管理中授权或更换模型 |
| 外部图片抓取失败 | URL 不可达、被 SSRF 拦截、超时 | 关闭外部抓取，或把图片上传到文档内 |
| 整篇处理失败 | 模型调用失败、配额不足 | 查看文档错误信息，修复后**重试失败分段** |

<Callout type="warn">
  重试只处理失败的分段；如果修改了站点模型配置，建议对整篇**重新处理**，避免同一文档混用两个模型的输出。
</Callout>
