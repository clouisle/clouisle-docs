---
title: 创建知识库
description: 为团队建立可检索的文档集合并选择索引模型
icon: Database
---

知识库必须归属于一个团队。创建时选择的嵌入模型决定向量维度；文档首次处理后不应更换嵌入模型，若必须更换，需要重建索引。

1. 前往**知识库**，选择**创建知识库**。
2. 填写名称（`1-100` 字符）和描述（最多 `500` 字符）。
3. 选择当前团队。
4. 选择已授权的 `embedding` 模型；可选一个 `rerank` 模型。
5. 设置分块大小（默认 `1000` 字符）和重叠（默认 `100` 字符），保存。
6. 打开知识库详情，确认状态为**启用**。

<Callout type="error">
  嵌入模型不存在、未授权或向量维度与既有索引不匹配时，文档处理和检索会失败。先在[模型指南](../models/manage-models.mdx)确认授权。
</Callout>
