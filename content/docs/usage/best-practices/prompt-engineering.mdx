遵循核心原则与系统设计规范，编写高质量的提示词。

## 核心原则

1. **具体**：提供清晰、详细的指令
2. **上下文**：给出必要的背景信息
3. **定义输出格式**：明确期望的回答结构
4. **使用示例**：通过少量示例让模型快速理解模式

## 系统提示词设计

```
你是一个 [角色]，负责 [目的]。

你的职责：
- [任务 1]
- [任务 2]

准则：
- [准则 1]
- [准则 2]
```

## 常见陷阱

- ❌ 模糊指令
- ❌ 过长的提示词（消耗 Token 额度）
- ❌ 缺少示例
- ✅ 清晰、简洁、带示例的提示词
