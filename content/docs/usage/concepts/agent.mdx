Agent 是面向多轮对话的 AI 应用。它把一个团队授权的对话模型，与系统提示词、变量、知识库、工具、记忆、附件和媒体生成设置组合在一起。

### 编排与运行

Agent 的编辑页由编排表单和实时预览组成。提示词支持 `{{变量名}}`；用户变量可选文本、段落、下拉选项、数字、复选框，以及数组、对象和文件/图片类型（文件类变量用于接收附件）。内置变量 `{{query}}` 表示当前用户输入。

Agent 每轮最多执行 `1-200` 次工具调用，默认 `5` 次。达到上限时本轮停止继续调用工具，而不是无限循环。

运行是异步且可恢复的：发送消息后可以离开页面、刷新或切换会话，回来时仍能看到已生成的内容和后续事件，不需要重新发送。运行也可能停在「等待回答」状态，等待用户在表单里回答模型提出的问题；刷新后表单会恢复。

任务**不会自动重试**。重试会重复执行有副作用的模型调用和工具调用，因此平台只在用户主动重发时重新开始。如果运行长时间停在排队状态没有进展，说明执行服务不可用，应联系运维而不是重复点击发送。

### RAG 模式

| 模式 | 行为 |
| --- | --- |
| 关闭 | 不检索知识库 |
| 自动（Naive RAG） | 每轮在模型调用前自动检索已关联知识库 |
| 智能（默认） | Agent 自行判断何时检索知识库 |

每个知识库关联可独立配置检索方式、Top K 和阈值。检索方式为向量、全文或混合。

### 对话、分支与压缩

会话在首次发送消息时自动创建。用户可以编辑消息或重新生成回复，系统保存多个版本并保留活动分支，切换分支不会丢失其他版本。

长对话在模型调用前会检查上下文预算，必要时压缩早期推理、工具结果和历史轮次，同时保留最近的原始轮次。压缩摘要的目标长度默认 `1000` token（可配 `128-8000`）。用户看到的仍是完整会话，被压缩的只是发送给模型的历史。

### 交互、引用与产物

- **交互式提问**：开启后，模型可以在回答过程中提问并暂停本轮；用户在聊天页的表单里作答后，同一个回答从暂停处继续。提问默认关闭，等待中的提问会随会话保存，刷新或切回会话可恢复。
- **引用**：开启引用后，知识库检索、联网工具与附件解析的来源都可以被模型引用。回答中的引用标记可以点击，界面只列出被实际引用的来源；没有来源编号的内容不会被当作引用展示。
- **附件与产物**：用户上传的附件、生成的图片/视频和代码产物都属于**当前会话**，只能在产生它的会话或工作流运行中访问。文件下载需要当前登录凭证，平台不提供公开链接，也不能把地址复制到其他会话继续使用。
- **执行轨迹**：检索、压缩、推理、工具调用、用户引导与媒体结果会按发生顺序折叠在思考时间线中，刷新后仍可展开查看。
- **展示开关**：隐藏推理、隐藏工具调用、隐藏消息操作和隐藏产物列表只影响界面显示，不改变已保存的数据或访问权限。字段含义见[Agent 配置参考](../../reference/agent-config.mdx)。

### 记忆

记忆默认**关闭**。开启后 Agent 可以跨会话检索用户信息：每次默认注入最多 `10` 条记忆（可配 `1-50`），自动提取默认开启，自动提取的最低重要性默认「中」（可选低、中、高）。关闭自动提取只停止写入，已保存的记忆仍会被检索和注入。

记忆与会话上下文的边界不同：会话上下文只属于一个会话，记忆按**用户**存续，检索时不区分 Agent 和团队。因此同一用户在不同 Agent 中产生的记忆会互相可见；共享账号或一个账号承担多种身份时要谨慎开启。用户可以在**记忆**页查看和删除自己的记忆。

### 发布与可见性

Agent 状态只有**草稿**与**已发布**。可见性为**私有**或**团队**；历史数据中的公开可见性会按团队可见处理。发布后可以使用分享对话页、嵌入页和 API；发布权限与编辑权限分开控制。
