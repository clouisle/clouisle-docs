工具让 Agent 和工作流执行外部动作；Skill 把可复用指令与资源组织成可安装能力。工具有三类形态，其中自定义工具又有三种执行方式。

### 工具的三类形态

| 形态 | 来源 | 归属与权限 |
| --- | --- | --- |
| **内置工具** | 平台提供，随版本更新 | 无需创建，不可删除或共享；部分需要站点开关或凭据 |
| **自定义工具** | 团队创建，分为 HTTP、代码与数据库三种 | 归属团队，可设可见性、可测试、可共享 |
| **MCP 服务** | 接入外部 MCP 服务器 | 归属团队，按传输方式配置连接信息 |

### 内置工具

内置能力包括：当前时间与时间格式化、计算与单位换算、网页搜索、网页抓取、文档转换、订阅源读取，以及沙箱中的产物查看、命令执行与文件读写。

- 网页搜索由管理员在站点能力页统一启用引擎并配置凭据，团队和 Agent 不再保存搜索密钥。只有站点已启用的引擎可用，引擎失败时不会自动切换到其他供应商。
- 图片生成、视频生成与向用户提问由平台实现，但**不会出现在可选工具列表中**：它们分别由工作流媒体节点和 Agent 的提问开关注入。
- 内置文档转换与前台上传的文件解析器会一起出现在文件解析器选择中。

### 自定义工具

- **HTTP 请求**：配置方法、地址、请求头、查询参数、正文模板、超时（默认 `30` 秒，`1-300`）和响应取值路径。地址必须固定，不能包含变量；变量只能放在查询参数、请求头或正文中，含变量的地址在保存或执行时被拒绝。
- **代码**：在受限沙箱中运行 Python 或 JavaScript，可安装**精确固定版本**的依赖（如 `requests==2.32.3`），并在 `/workspace` 下声明产物。
- **数据库**：连接 PostgreSQL、MySQL、Redis 或 MongoDB，保存连接信息与查询。查询超时默认 `15` 秒（`1-120`），最多返回 `100` 条记录（`1-1000`）。保存前可以点击**测试连接**确认网络与凭据可用。

自定义工具保存前可以先用测试功能试跑：参数以 JSON 传入，返回结果、日志、产物与耗时。执行失败时先看测试结果里的错误信息，再检查目标地址是否在出站网络白名单内。

### MCP

MCP 服务支持三种传输方式：`stdio`（本地命令）、`sse` 与 `http`（远程地址）。保存前可以获取服务器工具列表，确认服务可达并检查工具名、说明与参数结构。`stdio` 配置命令、参数与运行环境设置；`sse` 与 `http` 配置地址与可选请求头。

### 可见性与权限

- **私有**：仅创建者可见可用，同团队的其他成员也看不到。
- **团队**：团队成员可以查看和使用；编辑要求创建者本人或团队管理员，普通成员只读。
- **删除**：只有团队管理员或所有者可以删除工具。内置工具是平台资源，不在删除范围内。

### 沙箱边界

代码工具默认超时 `30` 秒，保存的配置允许 `1-600` 秒；直接执行时限制在 `1-60` 秒。默认磁盘 `1024MB`，标准输出和错误各 `256KB`。产物必须写在 `/workspace` 内，写到其他位置会被拒绝。隔离方式与完整限制见[代码沙箱](./sandbox.mdx)。

### 共享

自定义工具可以共享给其他团队，但有几条硬性约束：

1. 只有**工具所属团队的管理员**能发起共享。
2. 私有工具不能共享，也不能共享给自己所属的团队；重复共享会被拒绝。
3. 权限只有两档：**只读**（可查看并使用工具）与**只读并可查看执行结果**。
4. 接收团队在工具的「共享给我」列表中看到这些工具，并显示共享来源与权限；共享是单向的，由工具所属团队建立和撤销。

内置工具不能共享。

### 出网安全

自定义 HTTP 工具、工作流 HTTP 请求节点、知识库网址导入与数据库连接测试都经过统一的外网访问校验：目标属于内网、回环、链路本地或云元数据地址时直接拒绝，只有管理员把目标加入**设置** > **安全** > **出站网络白名单**后才放行。云元数据地址属于永久阻断项，即使配置也无法放行。

<Callout type="warn">
  把内网服务暴露给工具调用时，先确认目标已在出站网络白名单中登记；否则表现为工具执行失败，而不是保存时的配置错误，排查时容易被误判为「代码写错」。
</Callout>
