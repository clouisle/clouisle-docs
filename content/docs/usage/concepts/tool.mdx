工具让 Agent 和工作流执行外部动作；Skill 把可复用指令与资源组织成可安装能力。工具分为内置、自定义和 MCP 三类。

### 内置工具

内置能力包括时间、日期格式化、计算、单位转换、网页搜索、网页抓取、文档转换、图片/视频生成，以及沙箱中的 `artifact`、`bash`、`edit`、`read`、`write`。网页搜索需要配置 `TAVILY_API_KEY`。

### 自定义工具

- **HTTP API**：配置方法、URL、请求头、查询参数、正文模板、超时和响应路径。
- **代码工具**：运行 Python 或 JavaScript，可安装精确固定版本的包，并声明 `/workspace` 下的产物。

### MCP

MCP 服务支持 `stdio`、`sse` 与 `http` 传输。保存前可获取服务器工具列表。`stdio` 配置命令、参数和环境变量；远程传输配置 URL 与请求头。

### 沙箱边界

代码工具默认超时 `30` 秒，持久化配置允许 `1-600` 秒；直接执行接口限制 `1-60` 秒。默认磁盘 `1024MB`，标准输出和错误各 `256KB`。产物路径必须位于 `/workspace`。

### 共享

自定义工具可共享给其他团队，权限为**只读**或**读取并执行**。内置工具不能删除或共享。
