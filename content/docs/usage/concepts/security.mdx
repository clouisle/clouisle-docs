Clouisle 以团队隔离 Agent、工作流、知识库、模型授权、工具与 Skills。当前团队决定平台工作台查询和创建资源的边界。

### 团队隔离

团队是资源和数据的边界：团队资源默认只对团队成员可见，跨团队访问会被拒绝，而不是返回空数据。私有资源还要再窄一层——私有 Agent、工作流和工具只有创建者可用；创建者已不存在的历史私有资源由团队管理员处理。

跨团队共享覆盖工具与知识库：自定义工具可以只读或可查看执行结果的方式共享给其他团队，知识库以只读方式共享；共享都是单向的，由资源所属团队发起和撤销。Agent 和工作流没有按团队逐个授权的共享层级。

### 角色与权限

权限由两层叠加：

- **全局角色**决定「能做什么」——例如能否进入管理台、能否创建 Agent、能否修改站点设置。
- **团队角色**（所有者、管理员、成员、观察者）决定「在哪个团队、以什么级别做」。团队角色本身不带权限；团队管理和删除类动作还要求在该团队内是所有者或管理员。

超级管理员绕过所有检查。系统内置五个角色（Super Admin、Admin、Team Admin、Member、Viewer），也可以创建自定义角色组合权限。授权在服务端强制执行，前端隐藏菜单和按钮只是便利：绕过界面直接请求同样会被拒绝；界面上出现按钮也不代表一定成功。

具体谁能做什么见[角色与权限](../guides/administration/roles-permissions.mdx)；权限目录与角色矩阵见[权限与角色参考](../../reference/permissions.mdx)。

### 会话与数据隔离

普通用户只能查看自己的会话与数据。拥有管理台访问权限的管理员可以查看团队全部会话，团队范围查询还需要团队所有者或管理员角色。API 密钥按用户归属：用户只能查看和管理自己的密钥，只有超级管理员能跨团队查看全部。

### 认证与账户安全

站点可以组合密码登录、邮箱验证、管理员审批、点击式人机验证、密码策略、密码过期、单一会话、TOTP 和 SSO。SSO 支持多个连接，管理员也可以关闭密码登录。有效会话默认 `30` 天。

人机验证是**一次性的点击验证**，不是图片字符验证码：用户点击完成后才能提交登录，验证缺失或过期时登录被拒绝。安全页只有这一个开关，没有失败阈值、有效时长或难度配置——它是降低自动化尝试的补充手段，不能替代登录锁定和 TOTP。

真正拦截暴力破解的是锁定机制：

- 同一账户连续登录失败达到设定次数后锁定一段时间；锁定期间即使密码正确也会被拒绝，并提示剩余时间。
- 登录成功后失败计数清零。
- TOTP 校验连续失败也会短暂锁定，成功后计数清零。

这些阈值都在**设置** > **安全**中调整，见[站点设置](../guides/administration/site-settings.mdx)。

### 出站网络防护

平台对外访问有三套相互独立的防护，都能在**设置** > **安全**中开关，默认全部开启。关闭某个开关不会清空已保存的名单，重新开启后立即恢复拦截。

- **外部抓取防护**：自定义 HTTP 工具、HTTP 请求节点、知识库网址导入和数据库连接默认不能访问内网、回环和云元数据地址。需要访问内网服务时，由管理员把目标加入出站网络白名单；白名单支持单个地址、网段、精确域名和通配域名，最多 `200` 条。云元数据地址和全网通配永远不能加入。关闭开关后不再限制目标，但网址与端口的格式校验仍然执行，格式校验不构成安全边界。
- **模型出口**：注册模型供应商时填写的请求地址必须命中模型端点白名单（协议、主机名和端口精确匹配）。名单预置常见供应商与本机模型地址，最多 `200` 条。模型请求只走这道名单，不受外部抓取防护的网段限制——所以本机运行模型服务只需加入模型端点白名单，不需要放开内网访问。
- **沙箱出口**：只作用于代码沙箱，仅接受精确主机名，默认放行 Python 与 npm 的官方包源，空名单阻断全部外网。它与出站网络白名单互不共享：把内网主机加入出站白名单不会放行沙箱，反之亦然。关闭开关只影响新任务，文件系统隔离与资源限制仍然生效。

三套防护的判断方式不同：外部抓取会先解析域名再按地址判断，避免用别名或 DNS 指向绕过；模型出口按完整地址比对；沙箱出口只允许 HTTPS 访问名单内主机。三个开关若读取失败，一律按「开启」处理，即继续拦截。

精确字段、默认值与匹配规则见[站点设置参考](../../reference/site-settings.mdx)。

### API 密钥

API 密钥以 `clou_` 开头，调用时作为访问凭证发送。密钥可以绑定指定 Agent 与工作流（两个列表都为空表示允许访问全部），可以设置过期时间与启用状态。绑定在服务端校验，密钥访问未授权的 Agent 或工作流会被拒绝。

界面上可以填写每分钟请求上限与作用域，但当前版本不会实际限流，也不会据此收窄权限——不要把它们当成生效的安全措施。密钥按用户管理：用户只能查看和管理自己的密钥，只有超级管理员能跨团队查看全部。

### 审计与通知

管理后台记录资源操作、操作者和变更快照，并支持按事件、用户、团队和时间筛选。敏感字段在记录和展示时自动脱敏，原始密钥不会出现在日志中。

通知可以只显示在站内，也可以通过邮件、Webhook 或飞书外发；钉钉、企业微信与 Slack 渠道已移除。
