Clouisle is a multi-agent collaboration platform and workflow engine: with the team as the resource boundary, it orchestrates published Agents into multi-agent pipelines through visual workflows and combines them with Knowledge Bases, models, tools, and Skills into governable AI applications. Platform users build, debug, and publish applications in the workspace; administrators configure models, permissions, security policies, and runtime monitoring in the admin panel.

## Recommended learning path

1. Start with the [Quick Start](./quick-start.mdx) to confirm your account, team, and model authorization are available.
2. Read the [Agent](./concepts/agent.mdx), [Knowledge Base](./concepts/knowledge-base.mdx), and [Workflow](./concepts/workflow.mdx) concepts.
3. Enter the [Guides](./guides/index.mdx) by task. When you need field defaults, go to [Reference](/reference).
4. After publishing an application, use **Logs** and **Monitoring** in the application to check conversations, Tokens, latency, and failed runs.
