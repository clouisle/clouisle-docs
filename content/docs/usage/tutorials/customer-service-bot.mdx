完成本教程后，你将得到一个能回答产品问题、引用内部文档、在需要时查询网页并显示运行来源的客服 Agent。

<Callout type="info" title="前置条件">
  已登录 Clouisle；当前团队有启用的 `chat` 模型；已有可用知识库，或先按[创建知识库](../guides/knowledge/create-knowledge-base.mdx)建立。网页搜索需要服务端配置 `TAVILY_API_KEY`。
</Callout>

## 最终结果

客服 Agent 处于**已发布**状态，拥有系统提示词、一个关联知识库、网页搜索工具和至少一个建议问题。

## 步骤 1：创建 Agent

<Callout type="info">先建立资源外壳，后续步骤才能在同一 Agent 中配置知识和工具。</Callout>

1. 打开**应用** > **创建应用** > **Agent**。
2. 名称填写 `客服助手`，描述填写服务范围。
3. 选择一个团队已授权的 `chat` 模型。
4. 在**Agent 设置**保存。

  <img src="/images/tutorial-customer-service-create.png" alt="客服 Agent 创建结果" />
  <figcaption>客服 Agent 创建结果</figcaption>

## 步骤 2：编写提示词

<Callout type="info">明确引用优先级和不确定时的升级规则，减少模型在知识库没有答案时编造。</Callout>

在**提示词**填入：

```text
你是 Clouisle 产品客服助手。
优先根据关联知识库回答，并在有来源时给出引用。
知识库没有足够信息时，明确说明不确定，不要编造版本、配置或价格。
只有用户要求最新外部信息时才使用网页搜索。
回复使用简体中文，先给结论，再给步骤。
```

保存并在预览中发送一个产品问题。

## 步骤 3：关联知识库

<Callout type="info">知识库把客服答案绑定到企业可审阅的事实来源。</Callout>

1. 在**知识库**卡片选择**添加**。
2. 选择目标知识库。
3. 使用 `hybrid` 检索，Top K 使用 `5`，阈值使用 `0.3`。
4. 保存。

## 步骤 4：启用网页搜索

<Callout type="info">外部搜索只用于知识库之外的时效信息，避免所有问题都依赖实时网络。</Callout>

1. 在**工具**选择**添加**。
2. 选择内置 `web_search`。
3. 如果显示**需要配置**，联系管理员配置 Tavily API Key。
4. 保存并测试一个需要外部信息的问题。

## 步骤 5：发布并验收

1. 用内部文档问题验证引用。
2. 用时效问题验证工具调用。
3. 用知识库没有覆盖的敏感问题验证拒答或不确定说明。
4. 选择**发布**，打开**公开页面**。
5. 在 Agent **日志**确认会话、来源、工具结果和 Token。

<Callout type="success" title="验收标准">
  内部问题有来源；外部问题只在需要时触发 `web_search`；工具失败显示错误而不是伪造成功；Agent 公开页可以继续多轮对话。
</Callout>
