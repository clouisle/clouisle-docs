本文档记录 Clouisle 项目的所有重要变更。

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [未发布]

### 新增

#### 消息集成
- 登录方式、邮件、Webhook 与飞书目录同步现在集中在同一处「集成」配置中管理；已有的登录提供商、身份连接与回调地址保持不变，密钥加密保存且不会在界面中回显。详见[消息集成](./guides/integrations/index.mdx)。
- 集成的管理权限分为「登录」与「设置」两类，可以分别授予不同管理员；全局单点登录策略移到 **设置** > **安全**，各集成的实例卡片与已开启能力在 **设置** > **集成** 中查看。
- 飞书集成可单独开启网页登录：用户可用飞书账号登录，首次登录按飞书身份自动关联，不要求邮箱一致；开启集成本身不会自动打开登录。
- 飞书集成覆盖登录、通讯录与部门同步、通知（可向指定已绑定用户发送测试消息）、只读知识同步与 Agent 会话；关闭某项能力不会删除已同步的数据和已有绑定，重新开启即可继续。
- 飞书 Agent 会话支持两种接入方式：回调地址（校验签名、300 秒内有效、单条 64 KiB 上限）与长连接。长连接由平台自带的后台任务维护，不需要额外部署服务或执行额外命令。
- 飞书里的 Agent 回答以 Markdown 交互卡片发送；运行中断或重连后仍能找回此前生成的文件与结果。支持中英双语的 `/agents`、`/use`、`/new`、`/stop`、`/status`、`/help` 命令，结构化提问也可直接在会话里作答。详见[飞书集成](./guides/integrations/feishu.mdx)。
- 飞书附件上限为图片 10 MiB、MP4 30 MiB、其他文件 30 MiB；被拒收时按上传失败记录原始错误信息、状态与错误码，可在[投递日志](./guides/integrations/delivery-log.mdx)中查看。
- 新增飞书身份绑定：**账户安全** > **连接账户** > **绑定飞书**。绑定使用仅本人可用的限时授权会话，需要在同一标签页确认，遇到冲突直接拒绝；不会按邮箱自动匹配，也不改变当前登录方式。
- 飞书会话可用的 Agent 改为在个人设置中选择，与 `/use` 命令效果一致；个人开关只暂停新消息接收、排队处理与未发送回复，Agent 选择与会话历史都会保留。
- 新增微信（iLink）站点集成，Agent 会话与知识采集分别开关；个人二维码授权独立于功能配置，一个连接同时只处于「无 / 知识采集 / 单个已发布 Agent」三者之一。
- 微信知识采集支持文本、链接、文档、图片、音频与视频（按时间点抽帧），图片与音频的内容抽取需要团队授权；原始文件保留类型与文件名，只能通过受保护的方式下载，每类附件单独记录成功或失败。自托管部署已内置视频抽帧所需的媒体处理工具，无需额外安装。
- 微信里的 Agent 会话复用平台的持久化运行：支持文本、图片、文件、语音转写与视频输入，输出图片、视频和文件会直接发回微信；每次投递结果都会记录，结果不确定的消息不会自动重发，避免重复打扰。
- 微信消息按到达先后成批收取，积压过多时自动放慢，超时未处理的消息会被丢弃而不是重复处理；无需部署独立的消息接收服务。详见[自托管架构](../self-host/architecture.mdx)。
- 微信命令支持 `/new`（`/新对话`）、`/stop`（`/停止`）、`/status`（`/状态`）、`/help`（`/帮助`）、`/agents`（`/智能体`）与 `/use <n>`（`/使用 <编号>`）；会话忙时拒绝切换，已接收消息仍绑定原运行。
- 飞书与微信的投递记录合并为一份统一的投递日志，升级时自动迁移历史记录并清理旧数据。升级时 API 与后台任务需保持同版本，不能只升级一侧。升级步骤见[升级指南](../self-host/operations/upgrade.mdx)。
- 新增 **投递日志** 页面，可按集成（飞书／微信）、状态（待发送／发送中／已发送／失败／不可用／未知）、运行或文件名筛选；每页 1–100 条（默认 25），仅拥有集成设置查看权限的管理员可见，原始错误直接显示在表格中便于排查。
- 集成相关的定时任务按配置自动增删：开启或关闭某项能力后约 2 秒内生效，无需重启服务；读取配置失败时会暂停集成投递，其他日常维护任务照常运行。

#### Agent 运行时与聊天
- 新增 Agent 向用户提问的能力，替代原先依赖文本标记的提问方式：可以一次提出一个问题或一组问题，会话在提问处暂停，收到回答后从原处继续；每个问题只能回答一次，必填项未完成不会继续运行。
- 提问能力由 Agent 配置中的开关控制（默认关闭）；它与图片生成、视频生成一样属于内置能力，不出现在工具列表中，也无法手动挂载。
- 流式、非流式、编辑与重新生成四条聊天路径统一为同一套执行逻辑：上下文构建、上下文压缩、模型轮次、用量统计、心跳与断线处理、工具事件顺序和最终消息组装在各路径下表现一致。
- 工具调用按共享与独占策略分批调度：可并发的只读内置工具同时执行，其余串行；事件与记录顺序仍与模型的原始调用顺序一致。
- 模型一轮未写完时可自动续写（最多连续 8 次），被截断的工具调用会自动补齐配对；单次运行仍受总时长上限约束。
- 聊天上下文达到预算的 90% 时自动摘要压缩，保留最近一段原文并统计节省的 Token，压缩过程在会话中可见。详见[对话](./guides/agent/conversation.mdx)。
- 供应商返回的缓存命中用量会被记录，并统一计入统计、消息与配额，三处口径一致。
- 高并发下的流式输出更省资源：增量内容按 20 毫秒或 6 个 Token 打包推送，每 15 秒发送一次心跳；运行结束后的事件缓冲从 24 小时缩短到 10 分钟，缓冲上限 64 条以防过载。
- 切换会话后，后台仍在生成的内容会恢复显示；运行页提供运行状态标记与重连按钮，排队中的引导消息显示在输入框上方。
- 新增统一的来源引用：知识库检索、网页搜索与资产都使用同一种引用标记，正文内可点开引用详情；朴素知识库检索结果以可展开的思考步骤呈现。
- 文档附件改为按需读取文本内容，读取与搜索都有篇幅上限，并支持从上次位置继续读取超长内容；移除了会截断内容的旧解析方式与相关文本长度设置。
- 新增资产列表查询：可按文件名搜索、按媒体类型筛选、分页返回（默认 10 条、最多 30 条）；返回结果前先校验权限、有效期与当前分支可见性。
- 输入附件、生成的媒体与沙箱产物统一使用同一种资产引用格式；工具重放只保存引用与元数据，下一轮使用前重新加载并重新校验权限。
- 系统提示词统一由一套按能力生成的管理逻辑注入，聊天与工作流中的 Agent 节点行为一致；工作流 Agent 补齐沙箱、Markdown 与语言指引，并按用户语言归一化。
- 提示词生成器与实际可用能力对齐：会带上提问与引用开关、保留可调用的工具名称、说明知识库模式与记忆读写边界，已关闭的能力不再出现在生成内容中；供应商返回额度不足时提示为模型配额错误。

#### 模型与供应商
- 供应商图标与名称统一显示，覆盖全部 23 个供应商；自定义 OpenAI 兼容网关会按模型名推断所属系列图标（gpt/o 系列、gemini、claude、LongCat、BAAI 等），无法判断时显示中性网关图标。
- 供应商名称优先使用自定义显示名，未设置时回退内置名称；图标与名称统一应用到模型管理、平台目录、团队页、知识库模型选择器以及 Agent/工作流选择器。详见[模型供应商](../reference/model-providers.mdx)。
- 供应商连通性测试会按地址白名单校验目标（默认开启，最多 200 条），并只允许固定的探测路径，被拦截时给出明确错误；配置读取失败时不允许保存空列表。
- 模型统一按条目 ID 解析，不再按「供应商 + 模型名」查找，也不再默认回退到 gpt-4；同一供应商 + 模型名可以配置不同的密钥或接入地址。
- 媒体生成能力扩展：工作流新增媒体节点，支持 OpenAI Responses 图片、更多火山引擎媒体模型与 MiniMax，并可以把会话中的图片作为媒体引用复用。详见[工作流节点](../reference/workflow-nodes.mdx)。
- 向量化用量优先采用上游返回的实际数值而非本地估算；修复了记忆向量删除、向量维度变更与自定义接入地址相关的问题。

#### 知识库与检索
- 新增跨团队知识库共享：共享后目标团队只读查看，计入共享数量，并可在 Agent 编排中选择；操作会记录审计前后差异，不能共享给自己的团队。详见[创建知识库](./guides/knowledge/create-knowledge-base.mdx)。
- Markdown 分块改进：跨块重复表头、保留章节层级、修复表格续行与列表边界；用户填写的换行、制表符等分隔符会先还原为真实字符再用于切分。详见[分块](./guides/knowledge/chunking.mdx)。
- 批量文档处理完成时只发送一条汇总通知；刷新页面丢失进度时提供待处理批次恢复提示；批次标识不再放进地址栏，避免链接过长。
- 检索结果更稳定：以知识库内容为权威来源，语义检索与关键词检索混合召回后统一重排，多知识库的候选一起排序，最后按上下文预算组装结果；混合检索或重排不可用时会给出明确提示。详见[检索](./guides/knowledge/retrieval.mdx)。
- AUTO 模式会结合对话上下文理解提问；混合检索不可用时降级并给出诊断信息；重排失败按检索错误提示，不再透出供应商原始异常。
- 新增可选的灰度观察：可以并行跑一套新检索策略做对比，默认关闭；灰度结果与各阶段指标单独记录，不影响线上返回结果。
- 新增检索实验室：可即时对比两套检索配置，也可保存为评估任务；数据集与用例支持逐条增删改，导出为 JSON/CSV 后可原样导回，编辑冲突会被提示，单个数据集最多 1000 个用例。
- 支持参数扫描调优：一次最多 32 组参数、5000 次评估，任务中断后可恢复；推荐参数必须通过一次验证运行后才能应用。
- 检索评估权限分为平台级与团队级两类，可分别授予；可选的模型预标注默认关闭，需要时手动开启。详见[权限](../reference/permissions.mdx)。
- 记忆改为双轨：既可由 Agent 显式写入，也会在后台异步提取；记忆检索支持按时间窗（天数）、返回条数 1–10 与实体类型过滤，并按 30 天半衰期的时效衰减排序。详见[记忆](./guides/agent/memory.mdx)。

#### 工具
- 新增数据库自定义工具，覆盖 PostgreSQL、MySQL、MongoDB 等常用数据库与键值型缓存数据库；连接配置包含超时与最大返回行数，并可先测试连接再保存。详见[自定义工具](./guides/tools/custom-tools.mdx)。
- SQL 只读校验改为按数据库方言解析语句结构，不再匹配关键字，避免合法查询被误拦；采样前会安全引用从库中发现的表名。
- 新增内置 RSS 订阅阅读工具，空字段直接省略以节省 Token；网页抓取工具增加正文提取，并拒绝本地文件与非 HTTP(S) 地址。详见[内置工具](./guides/tools/built-in.mdx)。
- 新增站点级网页搜索：管理员可选择 Tavily、Bocha、SearXNG 或 DeepSeek 作为搜索引擎，并为每个引擎单独开关；密钥加密保存且保存后不再显示，Agent 与团队不再各自配置搜索凭据。
- 不再提供无需密钥的搜索引擎，也不会在失败时自动切换到其他供应商；SearXNG 支持反向代理子路径与可选的 HTTPS Bearer Token，请求超时 30 秒。详见[站点设置](./guides/administration/site-settings.mdx)。
- Agent 编排与工作流中的网页搜索节点只列出站点已启用的引擎，执行时再次校验站点配置；工具测试页新增搜索引擎选择。
- 工作流工具节点会按声明的类型转换数字、布尔与 JSON 参数，非法值在节点处失败，不再把字符串直接传给工具。
- 工具跨团队共享对话框在没有其他团队可选时显示空状态，并展示已选团队名称，按钮文案统一为 **共享**。
- 工具执行出错时不再把原始异常返回给用户：已知的业务错误显示本地化提示，其余统一显示通用提示。

#### 工作流
- 暂停节点的审批新增「全部批准后继续」策略（默认关闭）：逐位记录每位审批人的决定，全部批准后继续，任一拒绝即结束，并清理各审批人的待处理通知。
- 暂停描述模板支持变量：变量不可用时渲染为空，而不是留下花括号；文件变量显示为上传文件名。
- 暂停节点的请求表单支持全部 11 种参数类型，画布测试运行抽屉可直接填写并提交；历史中等待中的运行可直接取消。
- 迭代与循环变量按作用域就近解析：循环体内可直接用最短名称引用当前项、序号与结果，最内层优先；文件与图片变量仍是列表。
- 工作流运行页改为聊天式布局与纵向轨道时间线，节点详情可折叠查看输入与带类型的输出，支持拖拽上传、上拉加载历史，多输出节点堆叠展示。详见[编排](./guides/workflow/orchestrate.mdx)。
- 工作流 Agent 节点能力对齐：统一附件映射、保留结构化输出、变量约定一致，并提供更详细的运行记录。
- Agent 与工作流的监控仅创建者、团队管理员与超级管理员可见；私有工作流的写操作仅创建者可用。详见[运行监控](./guides/agent/monitor.mdx)。

#### 沙箱与网络
- 每个沙箱任务拥有独立的工作区视图：真实工作区挂载为 `/workspace`，当前目录、命令与环境路径都映射到该目录，`find /` 等根目录扫描也只作用于工作区。详见[沙箱](./concepts/sandbox.mdx)。
- 新增三个独立的网络限制开关：模型地址白名单、外部请求防护与沙箱网络白名单，默认全部开启；关闭后已保存的名单仍然保留，可随时恢复；沙箱开关只影响新任务。详见[安全](./concepts/security.mdx)。
- 审计日志记录字段级修改前后对比，覆盖 22 类资源；超长值截断到 500 字符，密码、Token、邮箱等敏感字段在写入前自动脱敏。详见[审计日志](./guides/administration/audit-logs.mdx)。
- 加固人机验证：点击式验证码的答案与选项都在服务端校验，不会下发到浏览器；修改邮箱需先完成验证，并限制重发频率。

#### 部署、存储与界面
- 新增可配置对象存储：默认使用本地存储，可切换为 S3 兼容对象存储（地址、存储桶、区域与密钥，路径风格与 HTTPS 默认开启）；知识库文档与 Skill 包统一走同一套存储。详见[存储](../self-host/operations/storage.mdx)。
- 支持分布式上传：后台任务不再直接挂载上传目录，而是通过带认证的接口读写文件；补齐了工作流上传路径的权限校验。
- 新增单命令 Kubernetes 安装器与可填充密钥的单文件清单，生成过程不会隐式改动集群，并新增 Sealos 部署选项；Kubernetes 工作负载会等待数据库就绪后再启动。详见[Kubernetes 部署](../self-host/deploy/kubernetes.mdx)。
- 站点设置新增可配置主题色，覆盖主要界面表面与强调色。
- 新增交互式引导：平台 10 步导览，以及模型、知识库、API Key、应用配置、能力与工作流编辑器的导览；支持前置步骤锁定、跨页衔接、一键重放与本地保存进度。
- 新增法务设置：可填写 ICP 备案号、服务条款与隐私政策并在登录、注册页展示，还可要求注册时接受条款。
- 快捷操作跳转后自动打开目标页面的创建对话框，打开后清理地址栏参数；工作台根路径统一跳转到应用列表。
- 高优先级通知改为在工作台以对话框展示，公告固定在通知分页之外；通知详情里的 Markdown 高度受限并可在内部滚动。详见[通知](./guides/administration/notifications.mdx)。

#### 管理后台可观测性
- 可观测性控制台重构为概览、运行、依赖、队列、基础设施与告警六个视图，可统一查看运行结果、追踪详情、模型/工具/检索依赖与运维状态。详见[可观测性](../reference/observability.mdx)。
- 运行详情新增有界的工具与知识检索记录，并在「依赖」视图汇总工具与检索的成功率和延迟。
- 每次运行最多保留 128 条依赖记录，超出时详情会标明追踪已截断；历史运行不回填这些数据。
- 运行的各生命周期状态补齐中英文翻译；遇到将来新增的状态会安全回退显示原始状态值。
- 基础设施依赖新增有界的连通性探测，覆盖数据库、缓存、后台任务与向量检索，展示实测延迟并区分「不可用」与「未配置」。
- 新增每分钟一次的运行收尾核对，按批次修正过期的状态、时间、模型与 Token 统计，不会重放运行；同时修复了导致收尾摘要丢失的查询问题。
- 模型依赖卡片会把遥测中的模型解析为已配置的模型名称与供应商显示名，支持自定义网关名称，同名模型仍分别统计。

- 基础设施健康状态与慢查询统计改为并发采集，缩短等待时间，保留原有探测截止时间、失败降级与缓存行为。
- 新增实例发现：多实例部署时会列出所有保留的实例，展示可读名称、主机资源采样与过期/离线状态；基础设施面板不再只显示当前请求命中的实例。详见[高可用部署](../self-host/operations/high-availability.mdx)。

#### 沙箱会话
- 会话任务改为按执行节点分配并记录绑定关系；过期批次的消息会被拒绝，执行结果不确定的命令不会自动重放。
- 新增执行节点就绪心跳、同节点监督重启与检查点恢复；原节点存储不可用时，会以有界、原子流程切换到新的工作区代际，会话收到重置通知后重新规划，不再复用过期路径或进程状态。
- 每个执行节点的工作区与检查点保留在该节点本地存储（Docker Compose 使用命名卷，Kubernetes 使用节点本地目录）；同节点进程替换可恢复检查点数据，节点或磁盘永久丢失则无法恢复。详见[Kubernetes 部署](../self-host/deploy/kubernetes.mdx)。
- 拒绝符号链接形式的工作区路径，避免借路径绕过隔离。
- 延迟清理与空闲回收的重试不再共用同一个通道，避免其中一个不可用就阻塞后续会话；首次会话分配会在就绪节点间分散，并为绑定与回收保留期设置上限。
- 拒绝将恢复超时设置为零，避免误配置导致会话无法恢复。
- 隔离沙箱与依赖安装的出口改走按任务建立的 HTTPS 代理，按精确主机名放行；被拦截的主机会出现在执行诊断信息中。
- 旧版代码执行与工作流代码节点统一收敛到沙箱之后；运行时被禁用、不可用或失败时直接失败，不在调用方执行负载。
- Python 与 Node 依赖安装默认限制 300 秒；超时的安装会被终止，未完成的环境会被丢弃。
- 沙箱输出在内存中按上限捕获，并对每个进程应用资源限制；直接执行的负载不保留任何系统权限，可信出口在隔离网络中就绪后再收紧权限。自托管部署需为相关后台任务保留网络管理权限。详见[安全清单](../self-host/operations/security-checklist.mdx)。

#### 资源访问与预览
- 为生成图片、生成视频与沙箱产物增加按范围的授权，客户端下载也需通过认证。
- 保留文件过大、未登录、无权限、不支持类型与解析失败等明确的预览状态，不再回退到未受保护的链接。

#### 聊天体验
- Agent 会话在开始发送时（流式输出之前）即固定到最新消息。
- 合并重叠的会话分页，刷新聊天侧栏时保留已加载的分页位置。

#### 依赖兼容

## [0.1.0] - 2025-02-07

Clouisle 首个公开发布版本 - 企业级知识库与 AI Agent 平台。

### 核心功能

#### Agent 系统

- **Agent 类型**：支持聊天 Agent 和工作流 Agent
- **Agent 编排**：现代化三栏布局，实时预览
  - 提示词编辑器，支持 AI 生成
  - 变量配置
  - 知识库关联
  - 工具配置
  - 视觉能力支持
- **Agent 发布**：发布/取消发布工作流，状态管理
- **Agent API 访问**：OpenAI 兼容 API，提供文档和代码示例
- **Agent 监控**：使用统计、对话趋势、Token 用量、响应时间指标

#### 工作流引擎

- **可视化工作流编辑器**：基于 React Flow 的拖拽式工作流构建器
- **节点类型**：
  - 开始/结束节点
  - LLM 节点（支持模型选择和参数调优）
  - 条件节点（分支逻辑）
  - 代码节点（JavaScript/Python 执行）
  - 工具节点（HTTP API、MCP、内置工具）
  - 迭代/循环节点
  - 变量赋值/聚合节点
  - 子工作流节点
  - 问题分类器节点
  - 参数提取器节点
- **变量系统**：上游变量引用与校验
- **执行**：实时流式执行，节点级状态跟踪

#### 知识库

- **文档管理**：
  - 多格式支持：PDF、DOCX、TXT、MD、HTML、CSV、XLSX、JSON、PPTX
  - URL 导入
  - 拖拽批量上传
- **文档处理**：
  - 智能文本分块（可配置 chunk_size、chunk_overlap、separator）
  - 提交前分块预览
  - 文本清洗选项
- **搜索模式**：
  - 向量搜索（语义相似度）
  - 全文搜索（jieba 中文分词）
  - 混合搜索（语义 + 关键词加权融合）
- **动态 Embedding**：支持多种 embedding 维度（768、1024、1536、3072）

#### 聊天系统

- **通用聊天组件**：可复用的聊天组件库
- **消息类型**：文本、推理（思维链）、工具调用、文件、来源
- **流式输出**：实时流式响应，Streamdown 渲染
- **多轮对话**：对话历史管理

#### 工具系统

- **内置工具**：计算器、时间/时区
- **HTTP API 工具**：可配置 URL、方法、Headers、Body 模板
- **MCP 服务器工具**：stdio/sse 传输、命令执行
- **代码工具**：在线 JavaScript/Python 编辑器

### 平台功能

#### 用户管理

- **认证**：用户名/密码、SSO（OIDC、SAML、CAS）
- **注册**：可配置注册、审批流程、邮箱验证
- **密码策略**：可配置强度要求
- **会话管理**：超时、单一会话模式
- **登录安全**：最大尝试次数、锁定、验证码

#### 团队管理

- **多租户**：基于团队的资源隔离

- **用量跟踪**：按团队统计 Token 用量

- **安全**：注册、密码策略、会话、登录安全
