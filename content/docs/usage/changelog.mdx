## [未发布]

### 新增

#### 管理后台可观测性
- 将管理后台可观测性控制台重构为概览、运行、依赖、队列、基础设施和告警六个视图，统一查看运行结果、追踪详情、模型/工具/检索依赖与运维状态。
- 在持久化 AgentRun 详情中增加有界的工具与知识检索跨度，并在“依赖”视图中汇总工具和检索的成功率与延迟。
- 每个 AgentRun 最多保留 128 个依赖跨度；达到上限时详情会标明追踪已截断，历史运行不会回填这些数据。
- 为所有已持久化的 AgentRun 生命周期状态补齐中英文翻译，并在遇到未来新增状态时安全回退为原始状态值。
- 为基础设施依赖增加有界的 PostgreSQL、Redis、Celery Worker 与 Qdrant 连通性探测，展示实测延迟，并区分不可用与未配置状态。
- 新增每分钟执行的单主 AgentRun 终态摘要对账，按有界批次修复过期的状态、时间、模型与 Token 字段，不重放运行；修复导致终态摘要丢失的 ORM 查询。
- 模型依赖卡片会将已有遥测中的 UUID 解析为配置的模型名称与供应商展示名称，支持自定义网关名称，并保留同名模型各自的统计。
- 使用独立 Celery inspector 并发采集运行任务、预取任务、定时任务与活跃队列，降低队列快照延迟，保留现有缓存与异常降级行为。
- 并发采集基础设施健康状态与慢查询统计，并将 Celery 回复收集窗口缩短至 0.5 秒，降低快照延迟，保留现有探测截止时间、异常降级和缓存行为。
- 新增 Redis 共享 API 实例发现，通过实例级上报租约去重，展示可读名称、主机资源采样及过期/离线状态；基础设施面板统一列出各后端的保留实例，不再只显示当前请求命中的实例。
- 为可观测性增加双月日历范围选择器，在弹层底部提供滚动时间预设，支持按本地时区覆盖完整日期、URL 保留，并为概览、运行列表及依赖统计统一应用 UTC 时间过滤。
- 仪表盘同步采用日历区间选择器，在弹层底部提供最近 7／30／90 天和全部时间快捷项；自定义日期统一过滤趋势、排名、模型用量、工作流摘要及对话／消息／Token 摘要与平均值，其他固定累计指标保持原定义。

#### 沙箱出口
- 为沙箱出口精确主机名新增持久化安全设置；更新后新任务直接生效，无需重启 Worker。

#### 沙箱生命周期审计
- 新增沙箱任务启动、完成、失败、取消与恢复的审计事件。条目记录可用的任务/会话/Worker 上下文与安全错误码，不记录代码、参数、输出或原始异常文本。

#### 模型与工作流
- 新增 TypeSafe AI（供应商标识 `typesafe`，默认端点 `https://api.typesafe.ai/v1/systemone`）决策模型供应商和 `decision` 模型类型：它针对给定 `state` 回答带类型的 `choice`（最多 255 个选项）、`score`（2–10 个有序等级）或 `noul`（真/假）问题，并返回带概率分布与置信度的结构化答案。
- 新增 Decision 工作流节点：提出一个带类型的问题，按返回的答案（或概率最高的得分等级）分支，并支持回退分支和可选的置信度阈值。节点输出 `answer`、`selected_handle`、`confidence`、`probabilities` 和用量。

#### 聊天与文件预览
- 新增统一产物列表，显示文件数量、可展开结果，并为常见文档、媒体和代码格式提供共享预览与带认证下载。
- 新增 DOCX 缩略图、页面同步、响应式适应宽度和缩放控制；新增只读 PDF 与电子表格预览控制。
- 新增 Agent **隐藏产物列表**设置，默认关闭；开启后隐藏聊天中助手消息下方的生成文件列表。

#### 记忆与 RAG
- 新增管理后台 `memory` 站点设置分类，可配置后台记忆提取模型、去抖冷却时间和待处理轮次阈值。
- 新增有界的 `get_memory_subgraph` Agent 工具，用于按关系检索记忆。

### 变更

#### 管理后台可观测性

- 将页签和筛选控件统一为项目共享的 Tabs、Select、Input 组件，并统一控件高度。

#### Agent Studio

- 手机端 Agent 预览改为全屏抽屉式面板打开，避免并排显示时压缩编排区。

#### 资源与媒体
- 将生成的图片和视频持久化为带范围的 Asset，并提供会话/工作流范围内供模型使用的媒体引用。
- 更新 CSV 的 GBK/GB18030 编码处理，并移除电子表格查看器中的重复下载入口。

#### Agent 检索与聊天时间线
- 未关联知识库的 Agent 现在会持久化并运行在 `rag_mode: off`；选择知识库前，Agent 编辑器隐藏 RAG 选择器。
- 聊天思考过程按检索、压缩、推理、工具和生成步骤实际发出的顺序渲染。
- 未执行检索时 `rag_context` 保持为 `null`；执行检索但没有上下文时为 `[]`。

### 修复

#### 管理后台可观测性
- 修复工具与检索跨度缺少 Token 计数时“依赖”视图接口报错的问题；此类行现在显示为不可用，而不是令整个响应失败。
- 在 Tortoise 生成模型结构和索引前，为已有 PostgreSQL `observability_runs` 表补充 `model_name` 与 `message_started_at` 列，修复旧数据库升级时的启动及概览查询失败。

#### 沙箱会话
- 会话任务改走按 Worker 划分的 Celery 队列，并持久化带隔离的工作区/存储绑定；过期代际的消息会被拒绝，执行结果不确定的命令不会自动重放。
- 新增 sandbox-worker 就绪心跳、同盘监督重启与检查点恢复；原 Worker 存储不可用时按有界原子流程换绑到新工作区代际，AgentRun 收到 `WORKSPACE_RESET` 后重新规划，不再复用过期路径或进程状态。
- 每个 sandbox-worker 的工作区与检查点保留在 Worker 本地存储（Compose 命名卷、Kubernetes 节点本地 hostPath DaemonSet）；同节点进程替换可恢复检查点数据，节点或磁盘永久丢失则不可恢复。
- 拒绝符号链接工作区路径时使用平台 `ELOOP` 错误码常量。
- 延迟清理与空闲回收重试改走独立 Redis 索引，避免不可用的属主队列阻塞后续会话；首次会话分配在就绪 Worker 间分散，并对绑定/墓碑保留期设界。
- 拒绝值为零的 sandbox-worker 恢复超时。
- 隔离沙箱与依赖安装出口改走按任务 HTTPS 代理，按精确主机名放行；被拦截的主机会出现在执行诊断信息中。
- 旧版代码执行与工作流代码节点收敛到沙箱网关之后；禁用、不可用与失败的运行时直接失败，不在调用方执行负载。
- Python 与 Node 依赖安装默认限制 300 秒；超时的安装进程组会被终止，未完成的安装环境会被丢弃。
- 沙箱输出在内存中设界捕获，并对每个进程应用 `prlimit` 限制。直接负载在 Bubblewrap 中丢弃全部 capability；可信出口桥接在隔离网络命名空间中拉起 loopback，再设置 `no-new-privileges` 并清除负载 capability。交付的 Worker 为该流程保留 `NET_ADMIN` 并保持资源上限。

#### 资源访问与预览
- 为生成图片、生成视频和沙箱产物增加基于范围的授权，并在客户端使用带认证的下载。
- 保留文件过大、未认证、无权限、不支持类型和解析失败等明确预览状态，不再回退到未保护的 URL。

#### Agent 系统

- **Agent 类型**：支持聊天 Agent 和工作流 Agent
- **Agent 编排**：现代化三栏布局，实时预览
  - 提示词编辑器，支持 AI 生成
  - 变量配置
  - 知识库关联
  - 工具配置
  - 视觉能力支持
- **Agent 发布**：发布/取消发布工作流，状态管理
- **Agent API 访问**：OpenAI 兼容 API，提供文档和代码示例
- **Agent 监控**：使用统计、对话趋势、Token 用量、响应时间指标

#### 工作流引擎

- **可视化工作流编辑器**：基于 React Flow 的拖拽式工作流构建器
- **节点类型**：
  - 开始/结束节点
  - LLM 节点（支持模型选择和参数调优）
  - 条件节点（分支逻辑）
  - 代码节点（JavaScript/Python 执行）
  - 工具节点（HTTP API、MCP、内置工具）
  - 迭代/循环节点
  - 变量赋值/聚合节点
  - 子工作流节点
  - 问题分类器节点
  - 参数提取器节点
- **变量系统**：上游变量引用与校验
- **执行**：实时流式执行，节点级状态跟踪

#### 知识库

- **文档管理**：
  - 多格式支持：PDF、DOCX、TXT、MD、HTML、CSV、XLSX、JSON、PPTX
  - URL 导入
  - 拖拽批量上传
- **文档处理**：
  - 智能文本分块（可配置 chunk_size、chunk_overlap、separator）
  - 提交前分块预览
  - 文本清洗选项
- **搜索模式**：
  - 向量搜索（语义相似度）
  - 全文搜索（jieba 中文分词）
  - 混合搜索（RRF 算法）
- **动态 Embedding**：支持多种 embedding 维度（768、1024、1536、3072）

#### 聊天系统

- **通用聊天组件**：可复用的聊天组件库
- **消息类型**：文本、推理（思维链）、工具调用、文件、来源
- **流式输出**：实时流式响应，Streamdown 渲染
- **多轮对话**：对话历史管理

#### 工具系统

- **内置工具**：计算器、时间/时区
- **HTTP API 工具**：可配置 URL、方法、Headers、Body 模板
- **MCP 服务器工具**：stdio/sse 传输、命令执行
- **代码工具**：在线 JavaScript/Python 编辑器
