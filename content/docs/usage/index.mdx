Clouisle 以团队为资源边界，把 Agent、工作流、知识库、模型、工具和 Skills 组合成可治理的 AI 应用。平台用户在工作台构建和测试应用；管理员在管理后台配置模型、权限、安全策略和运行监控。

</Cards>

## 推荐学习路径

1. 先完成[快速开始](./quick-start.mdx)，确认账户、团队和模型授权可用。
2. 阅读 [Agent](./concepts/agent.mdx)、[知识库](./concepts/knowledge-base.mdx)与[工作流](./concepts/workflow.mdx)概念。
3. 按任务进入[操作指南](./guides/index.mdx)。需要字段默认值时转到[参考](/reference)。
4. 发布应用后，使用应用内的**日志**和**监控**检查会话、Token、延迟与失败运行。
