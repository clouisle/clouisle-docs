## 供应商标识

当前枚举值：`openai`、`openai_responses`、`anthropic`、`google`、`azure_openai`、`deepseek`、`moonshot`、`zhipu`、`qwen`、`baichuan`、`minimax`、`volcengine`、`siliconflow`、`xai`、`ollama`、`runway`、`pika`、`luma`、`kling`、`stability`、`midjourney`、`custom`。

## 模型类型

`chat`、`embedding`、`rerank`、`tts`、`stt`、`audio_generation`、`text_to_image`、`text_to_video`。

## 模型字段

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 必填 | 显示名称，`1-100` 字符 |
| `provider` | enum | 必填 | 供应商标识 |
| `model_id` | string | 必填 | 上游模型 ID，`1-100` 字符 |
| `model_type` | enum | 必填 | 模型类型 |
| `provider_display_name` | string/null | null | 面向用户的供应商名称 |
| `base_url` | string/null | null | 自定义 API URL，最长 `512` |
| `api_key` | string/null | null | 本地供应商可为空；服务端加密保存 |
| `context_length` | integer/null | null | 必须 `>=1` |
| `max_output_tokens` | integer/null | null | 必须 `>=1` |
| `input_price` / `output_price` | decimal/null | null | 每百万 Token 价格，非负，最多 6 位小数 |
| `default_params` | object/null | null | 默认推理参数 |
| `capabilities` | object/null | null | 视觉、函数调用、流式等能力标记 |
| `is_enabled` | boolean | true | 是否可授权/使用 |
| `is_default` | boolean | false | 是否为该类型默认模型 |
| `sort_order` | integer | 0 | 列表排序 |

连接测试返回 `success`、`message` 和可选 `latency_ms`。发现模型时凭据只用于请求，不会自动保存。
