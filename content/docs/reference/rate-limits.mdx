API 的限速来自 API Key、团队模型授权和外部模型供应商三层。它们相互独立，排查时先确认是哪一层拒绝了请求。

## API Key 限速

创建 API Key 时 `rate_limit` 默认 `1000`，单位为每分钟请求数；设置为 `0` 表示无限制。达到限速通常返回 HTTP `429` 与业务错误码 `5400`。客户端应指数退避并降低并发，不要立即密集重试。

## 模型配额

团队模型授权可分别设置每日/月度 Token 与请求次数上限。四个字段均为非负整数；留空表示无限制。响应提供当前使用量和百分比。超过模型配额返回 `6103`，模型未被团队授权返回 `6104`。

## 供应商限速

即使 API Key 和团队配额充足，上游模型供应商仍可能返回限速或配额错误。保留供应商响应类别与请求追踪 ID，使用带抖动的指数退避；对流式请求不要从头重复提交带工具副作用的消息。

## 建议配置

生产集成使用单用途 API Key、绑定必要的 Agent/工作流、设置有限过期时间和明确的每分钟限额。把供应商额度、团队配额和 Clouisle API Key 分开告警，避免把所有 429 都归因于同一个组件。

<Callout type="warn">
  `rate_limit=0` 是无限制，不是禁用。需要立即阻断调用时，禁用 API Key 或撤销团队模型授权。
</Callout>
